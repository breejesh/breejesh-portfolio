## Teaching style (system design series)

All `design-*` posts are written for **novices**: everyday analogy first, problem in plain words, define every term when it appears, walk one user request end-to-end, then optional interview depth. Each ends with an "explain to a friend" recap. Locales: en, es, fr, hi.
