> **TL;DR**
> * **El Problema:** Optimización de complejidad temporal y espacial para estructuras de datos clave.
> * **El Enfoque:** Guía en Java, clara y para principiantes, del set clásico de problemas de entrevista estilo CTCI. Cómo funciona la serie y por dónde empezar.
> * **Complejidad:** Relación óptima de tiempo y espacio con gestión de casos límite.

Si te preparas para entrevistas de código, verás las mismas familias de problemas una y otra vez: arrays, strings, listas enlazadas, árboles, recursión, bits, ordenación y un montón de puzzles "moderate" y "hard".

Esta serie es un camino **en Java, pensado para enseñar**, sobre ese set clásico de problemas (el estilo de *Cracking the Coding Interview*, 6.ª edición). Cada artículo es **un problema**. Cada solución se explica para que un principiante la siga sin conocer el "truco" de antemano.

**No** es una copia de ningún libro. Los problemas se plantean en lenguaje claro, las soluciones son explicaciones originales en Java, y el objetivo es entender, no memorizar claves.

## Cómo practicar

1. Lee solo el problema. 10-20 minutos.  
2. Escribe brute force primero.  
3. Abre el artículo y compara el enfoque.  
4. Recodifica al día siguiente de memoria.  
5. Di la complejidad en voz alta.

Empieza por **1.1**: [Is Unique](/blog/es/ctci-1-1-is-unique).
