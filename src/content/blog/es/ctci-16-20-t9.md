> **TL;DR**
> * **El Problema del Libro:** En los telefonos moviles antiguos, los digitos mapeaban a caracteres ($2 \to \text{abc}, 3 \to \text{def}, \dots$). Dada una secuencia de digitos (ej. `"8733"`) y un diccionario, devuelve todas las palabras validas asociadas (ej. `["tree", "used"]`).
> * **Las Soluciones Óptimas:**
>   1. **HashMap Precomputado (Óptimo para Producción)**:
>      * Preprocesar el diccionario convirtiendo cada palabra a su representacion numerica T9.
>      * Almacenar en `Map<String, List<String>>`.
>      * Responder consultas en **tiempo estricto $O(L)$** ($L = \text{longitud de los digitos}$).
>   2. **Búsqueda en Trie**:
>      * Almacenar el diccionario en un arbol Trie y podar ramas no coincidentes con los caracteres de cada digito.
> * **Realidad en Producción:** Marcador telefonico de Android (AOSP Dialer) y arboles de respuesta de voz interactiva (IVR).

## 1. Formulación del Problema del Libro

En *Cracking the Coding Interview* (Problema 16.20), se nos plantea:

*"Implementa la busqueda de palabras predictivas T9 a partir de una secuencia de digitos ingresada por teclado numerico."*

## 2. Preprocesamiento Hash

Indexar previamente cada palabra bajo su firma numerica permite resolver cualquier consulta en $O(L)$ sin evaluar combinaciones exponenciales.

## Implementación de Producción

```java
import java.util.*;

public class T9Lookup {

    private static final int[] CHAR_TO_DIGIT = {
        2, 2, 2,  // a, b, c
        3, 3, 3,  // d, e, f
        4, 4, 4,  // g, h, i
        5, 5, 5,  // j, k, l
        6, 6, 6,  // m, n, o
        7, 7, 7, 7, // p, q, r, s
        8, 8, 8,  // t, u, v
        9, 9, 9, 9  // w, x, y, z
    };

    public static String wordToDigits(String word) {
        StringBuilder sb = new StringBuilder();
        for (char c : word.toLowerCase().toCharArray()) {
            if (c >= 'a' && c <= 'z') {
                sb.append(CHAR_TO_DIGIT[c - 'a']);
            }
        }
        return sb.toString();
    }

    public static Map<String, List<String>> initializeT9Map(String[] dictionary) {
        Map<String, List<String>> map = new HashMap<>();
        for (String word : dictionary) {
            String digits = wordToDigits(word);
            map.computeIfAbsent(digits, k -> new ArrayList<>()).add(word);
        }
        return map;
    }

    public static List<String> getValidWords(String digits, Map<String, List<String>> t9Map) {
        return t9Map.getOrDefault(digits, Collections.emptyList());
    }
}
```
