> **TL;DR**
> * **The Book Problem:** On traditional mobile phone keypads, digits map to characters (e.g., $2 \to \text{abc}, 3 \to \text{def}, \dots, 9 \to \text{wxyz}$). Given a sequence of digits (e.g. `"8733"`) and a dictionary, return all valid words matching that digit sequence (e.g. `["tree", "used"]`).
> * **The Optimal Solutions:**
>   1. **Precomputed Digit-to-Words HashMap (Optimal for Production Lookups)**:
>      * Preprocess the dictionary by converting each word to its T9 numeric fingerprint (e.g., `"tree"` $\to$ `"8733"`).
>      * Store in `Map<String, List<String>>`.
>      * Query in strictly **$O(L)$ time** ($L = \text{digits length}$).
>   2. **Trie Traversal with Branch Pruning (Optimal for Prefix Autocomplete)**:
>      * Store words in a 26-ary Trie.
>      * Traverse only the valid child branches corresponding to each digit's mapped characters.
> * **Production Reality:** Predictive text input engines, contact list T9 dialer search in Android (AOSP Dialer), and IVR phone tree command matching.

## 1. The Book Problem Formulation & Keypad Mappings

In *Cracking the Coding Interview* (Problem 16.20), we are given the standard ITU-T E.161 keypad:

```
[1]          [2] a b c    [3] d e f
[4] g h i    [5] j k l    [6] m n o
[7] p q r s  [8] t u v    [9] w x y z
[*]          [0]          [#]
```

*"Given a string of digits, return all valid dictionary words that can be typed with that sequence."*

## 2. Precomputed HashMap vs. Trie Architecture

```
Dictionary: ["tree", "used", "vote"]

Preprocessing Pipeline:
  "tree" ──> ('t'->8, 'r'->7, 'e'->3, 'e'->3) ──> "8733" ──> Map.get("8733").add("tree")
  "used" ──> ('u'->8, 's'->7, 'e'->3, 'd'->3) ──> "8733" ──> Map.get("8733").add("used")
  "vote" ──> ('v'->8, 'o'->6, 't'->8, 'e'->3) ──> "8683" ──> Map.get("8683").add("vote")

Query("8733") ──> Instant O(L) return: ["tree", "used"]
```

## Production Java Implementation

```java
import java.util.*;

public class T9Lookup {

    private static final char[][] T9_MAP = {
        null,                    // 0
        null,                    // 1
        {'a', 'b', 'c'},         // 2
        {'d', 'e', 'f'},         // 3
        {'g', 'h', 'i'},         // 4
        {'j', 'k', 'l'},         // 5
        {'m', 'n', 'o'},         // 6
        {'p', 'q', 'r', 's'},    // 7
        {'t', 'u', 'v'},         // 8
        {'w', 'x', 'y', 'z'}     // 9
    };

    private static final int[] CHAR_TO_DIGIT = {
        2, 2, 2,  // a, b, c
        3, 3, 3,  // d, e, f
        4, 4, 4,  // g, h, i
        5, 5, 5,  // j, k, l
        6, 6, 6,  // m, n, o
        7, 7, 7, 7, // p, q, r, s
        8, 8, 8,  // t, u, v
        9, 9, 9, 9  // w, x, y, z
    };

    /**
     * Converts a word into its canonical T9 digit string.
     */
    public static String wordToDigits(String word) {
        StringBuilder sb = new StringBuilder();
        for (char c : word.toLowerCase().toCharArray()) {
            if (c >= 'a' && c <= 'z') {
                sb.append(CHAR_TO_DIGIT[c - 'a']);
            }
        }
        return sb.toString();
    }

    /**
     * Precomputes the T9 Dictionary HashMap.
     */
    public static Map<String, List<String>> initializeT9Map(String[] dictionary) {
        Map<String, List<String>> map = new HashMap<>();
        for (String word : dictionary) {
            String digits = wordToDigits(word);
            map.computeIfAbsent(digits, k -> new ArrayList<>()).add(word);
        }
        return map;
    }

    /**
     * Queries T9 dictionary in O(L) time.
     */
    public static List<String> getValidWords(String digits, Map<String, List<String>> t9Map) {
        return t9Map.getOrDefault(digits, Collections.emptyList());
    }
}
```

## Complexity Analysis

| Stage | Algorithm | Time Complexity | Auxiliary Space |
|---|---|---|---|
| **Preprocessing** | Full Dictionary Ingestion | $O(W \cdot K)$ | $O(W \cdot K)$ hash index |
| **Runtime Query** | HashMap Lookup | **$O(L)$** | **$O(1)$** |
| **Trie Query** | Prefix Branch Search | $O(4^L)$ worst-case | $O(W \cdot K)$ tree nodes |

*(Where $W$ = word count, $K$ = average word length, $L$ = query digit length).*

## Real-World Systems Engineering Discussion

### Production Systems Architecture: Android Dialer & Smart Search

1. **AOSP Contact T9 Search:** The Android Open Source Project (AOSP) phone dialer pre-indexes contact names into SQLite FTS (Full-Text Search) tables using numeric T9 projections for instantaneous sub-millisecond autocompletion.
2. **IVR Automated Phone Menus:** Telephony voice response servers convert caller keypad inputs into account queries using T9 hash tables.

## Edge Cases & Production Hardening

1. **Non-Alphabetic Characters:** Filtered out during `wordToDigits` ingestion.
2. **Missing Digit Sequences:** Returns empty list `Collections.emptyList()` cleanly without `NullPointerException`.
