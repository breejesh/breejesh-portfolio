> **टीएल;डीआर**
> * **किताब का सवाल:** काले और सफेद कोशिकाओं वाले $N \times N$ मैट्रिक्स को देखते हुए, सबसे बड़ा उपवर्ग खोजें जिसके चारों बॉर्डर पूरी तरह काले पिक्सेल से भरे हों।
> * **मुख्य समाधान:** **पूर्व-गणित दाएं+नीचे DP के साथ घटते वर्ग स्कैन**:
>   1. **पूर्व-गणना**: प्रत्येक कोशिका `(r, c)` के लिए `right[r][c]` = दाईं ओर लगातार काली कोशिकाएं, `down[r][c]` = नीचे लगातार काली कोशिकाएं।
>   2. **स्कैन**: प्रत्येक कोशिका और घटते वर्ग आकार के लिए, पूर्व-गणित सरणियों का उपयोग करके चारों कोनों की जांच करें।
>   3. समय: **$O(N^3)$** सबसे खराब स्थिति। स्पेस: **$O(N^2)$** DP तालिकाओं के लिए।
> * **रियल-वर्ल्ड सिस्टम:** चिकित्सा छवि ROI पहचान और GPU कर्नेल टाइल सत्यापन।

## १. किताब का सवाल और संदर्भ

*क्रैकिंग द कोडिंग इंटरव्यू* (समस्या १७.२३) में पूछा गया है:

*"एक वर्गाकार मैट्रिक्स की कल्पना करें जहां प्रत्येक कोशिका काली या सफेद है। सबसे बड़े उपवर्ग को खोजने के लिए एक एल्गोरिदम डिजाइन करें जिसके चारों बॉर्डर काले पिक्सेल से भरे हों।"*

## २. DP पूर्व-गणना और कोने सत्यापन

```
मैट्रिक्स (B=काला, W=सफेद):
  B B B B
  B W B B
  B B B B
  B B B B

right[0][0]=4, down[0][0]=4
आकार 3 का सर्व-काला-बॉर्डर वर्ग:
  ऊपर-बाएं=(0,0): right>=3, down>=3
  ऊपर-दाएं=(0,2): down>=3
  नीचे-बाएं=(2,0): right>=3
  => मान्य! आकार-3 वर्ग मिला।
```

## प्रोडक्शन कार्यान्वयन

```java
public class MaxBlackSquare {

    static final int BLACK = 1, WHITE = 0;

    public static int[] findSquare(int[][] matrix) {
        int n = matrix.length;
        int[][] right = new int[n][n];
        int[][] down  = new int[n][n];

        for (int r = n - 1; r >= 0; r--) {
            for (int c = n - 1; c >= 0; c--) {
                if (matrix[r][c] == BLACK) {
                    right[r][c] = (c + 1 < n) ? right[r][c + 1] + 1 : 1;
                    down[r][c]  = (r + 1 < n) ? down[r + 1][c]  + 1 : 1;
                }
            }
        }

        for (int sz = n; sz >= 1; sz--) {
            for (int r = 0; r <= n - sz; r++) {
                for (int c = 0; c <= n - sz; c++) {
                    if (right[r][c] >= sz && down[r][c] >= sz
                            && down[r][c + sz - 1] >= sz
                            && right[r + sz - 1][c] >= sz) {
                        return new int[]{r, c, sz};
                    }
                }
            }
        }
        return null;
    }
}
```

## जटिलता विश्लेषण

| चरण | समय जटिलता | स्पेस |
|---|---|---|
| DP पूर्व-गणना (right + down) | $O(N^2)$ | $O(N^2)$ |
| वर्ग स्कैन | $O(N^3)$ सबसे खराब | $O(1)$ प्रति जांच |
| **कुल** | **$O(N^3)$** | **$O(N^2)$** |

## वास्तविक दुनिया में सिस्टम इंजीनियरिंग उपयोग

१. **चिकित्सा छवि ROI पहचान:** स्वचालित घाव विभाजन के लिए MRI स्कैन में सजातीय काले क्षेत्र टाइल खोजना।
२. **GPU कर्नेल टाइल सत्यापन:** CUDA/Metal कंप्यूट ग्रिड लॉन्च करने से पहले कंप्यूट टाइल सीमाओं का सत्यापन।
