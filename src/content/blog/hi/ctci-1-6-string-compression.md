> **टीएल;डीआर**
> * **किताब का सवाल:** दोहराए जाने वाले वर्णों की संख्या का उपयोग करके बुनियादी स्ट्रिंग संपीड़न करने की विधि लागू करें। यदि संपीड़ित स्ट्रिंग मूल स्ट्रिंग से छोटी नहीं होती है, तो मूल स्ट्रिंग लौटाएं।
> * **मुख्य समाधान:** स्ट्रिंगबिल्डर पूर्व-आवंटन: पहले एक पास में संपीड़ित लंबाई की गणना करें। मेमोरी आवंटन तभी करें जब संपीड़ित लंबाई मूल स्ट्रिंग से छोटी हो।
> * **रियल-वर्ल्ड सिस्टम:** बिटमैप छवियों और स्तंभ डेटाबेस (जैसे पारके और क्लिकहाउस) में रन-लेंथ एन्कोडिंग (RLE)।

## १. किताब का सवाल और संदर्भ

*क्रैकिंग द कोडिंग इंटरव्यू* (समस्या १.६) में पूछा गया है:

*"दोहराए जाने वाले वर्णों की संख्या का उपयोग करके बुनियादी स्ट्रिंग संपीड़न करने की एक विधि लागू करें। उदाहरण के लिए, स्ट्रिंग 'aabcccccaaa' संपीड़ित होकर 'a२b१c५a३' बन जाएगी। यदि संपीड़ित स्ट्रिंग मूल स्ट्रिंग से छोटी नहीं होती है, तो आपकी विधि को मूल स्ट्रिंग ही लौटानी चाहिए।"*

## २. द्विघाती स्ट्रिंग कॉनकेटनेशन से बचाव

लूप के अंदर `str += char + count` का उपयोग करने से हर बार एक नई स्ट्रिंग बनती है, जिससे $O(N^२)$ समय लगता है।

*इष्टतम कार्यान्वयन:* पहले रैखिक स्कैन में संपीड़ित स्ट्रिंग की लंबाई गिनें। यदि संपीड़ित लंबाई मूल स्ट्रिंग की लंबाई से अधिक या बराबर है, तो बिना कोई अतिरिक्त मेमोरी आवंटित किए सीधे मूल स्ट्रिंग लौटाएं। अन्यथा, पूर्व-निर्धारित क्षमता वाले `StringBuilder` का उपयोग करके $O(N)$ समय में परिणाम बनाएं।

## प्रोडक्शन कार्यान्वयन

```java
public class StringCompression {
    public static String compress(String str) {
        if (str == null || str.length() <= 2) return str;

        int finalLength = countCompression(str);
        if (finalLength >= str.length()) return str;

        StringBuilder compressed = new StringBuilder(finalLength);
        int countConsecutive = 0;

        for (int i = 0; i < str.length(); i++) {
            countConsecutive++;
            if (i + 1 >= str.length() || str.charAt(i) != str.charAt(i + 1)) {
                compressed.append(str.charAt(i));
                compressed.append(countConsecutive);
                countConsecutive = 0;
            }
        }
        return compressed.toString();
    }

    private static int countCompression(String str) {
        int compressedLength = 0;
        int countConsecutive = 0;
        for (int i = 0; i < str.length(); i++) {
            countConsecutive++;
            if (i + 1 >= str.length() || str.charAt(i) != str.charAt(i + 1)) {
                compressedLength += 1 + String.valueOf(countConsecutive).length();
                countConsecutive = 0;
            }
        }
        return compressedLength;
    }
}
```

## जटिलता और मेमोरी विश्लेषण

| मापदंड | जटिलता | तकनीकी विवरण |
|---|---|---|
| समय जटिलता | `O(N)` | इनपुट स्ट्रिंग पर दो क्रमिक स्कैन। |
| सहायक मेमोरी | `O(N)` | संपीड़ित स्ट्रिंग के लिए पूर्व-आवंटित बफर। |

## वास्तविक दुनिया में सिस्टम इंजीनियरिंग उपयोग

### प्रोडक्शन सिस्टम आर्किटेक्चर: कॉलमर स्टोरेज इंजन में डेटा संपीड़न

कॉलमर स्टोरेज इंजन (जैसे अपाचे पारके और क्लिकहाउस) डिस्क I/O को ८०% तक कम करने के लिए रन-लेंथ एन्कोडिंग का उपयोग करते हैं।

## सीमा स्थितियां और प्रोडक्शन सुरक्षा

१. बिना किसी दोहराव वाली स्ट्रिंग्स (`"abcdef"`): $O(N)$ में मूल `"abcdef"` लौटाता है।
२. एकल अक्षर `"a"`: बिना आवंटन के `"a"` लौटाता है।
