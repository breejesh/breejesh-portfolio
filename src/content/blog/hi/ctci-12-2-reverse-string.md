> **टीएल;डीआर**
> * **किताब का सवाल:** C या C++ में एक फ़ंक्शन `void reverse(char* str)` लागू करें जो नल-टर्मिनेटेड स्ट्रिंग को इन-प्लेस उलट दे।
> * **मुख्य समाधान:** **टू-पॉइंटर अंकगणित**: (१) `str` के `NULL` होने की जांच करें; (२) `end` पॉइंटर को नल टर्मिनेटर `'\0'` तक आगे बढ़ाएं और फिर एक कदम पीछे `end--` करें; (३) `start = str` सेट करें; (४) जब तक `start < end` हो, `*start` और `*end` को स्वैप करें, `start++` बढ़ाएं और `end--` घटाएं; (५) यह **$O(N)$ समय** और **$O(१)$ स्पेस** में पूरा होता है।
> * **रियल-वर्ल्ड सिस्टम:** नेटवर्क पैकेट एंडियननेस बाइट रिवर्सल और एम्बेडेड सी स्ट्रिंग मैनिपुलेशन।

## १. किताब का सवाल और संदर्भ

*क्रैकिंग द कोडिंग इंटरव्यू* (समस्या १२.२) में पूछा गया है:

*"सी/सी++ में एक नल-टर्मिनेटेड कैरेक्टर स्ट्रिंग को इन-प्लेस उलटने के लिए कुशल फ़ंक्शन लिखें।"*

## २. इन-प्लेस पॉइंटर अंकगणित

सी-स्टाइल स्ट्रिंग अंतिम छोर पर `'\0'` बाइट द्वारा समाप्त होती है:
```
['h', 'e', 'l', 'l', 'o', '\0']
  ▲                   ▲
start                end
```

`end` को `'\0'` तक ले जाकर और फिर दोनों तरफ से अक्षरों को केंद्र की ओर स्वैप करके बिना किसी अतिरिक्त बफर के स्ट्रिंग को उलटा जाता है।

## प्रोडक्शन कार्यान्वयन

```c
#include <stdio.h>

/**
 * नल-टर्मिनेटेड सी-स्ट्रिंग को इन-प्लेस उलटता है।
 * समय जटिलता: O(N)
 * स्पेस जटिलता: O(1)
 */
void reverse(char* str) {
    if (!str) return; // नल पॉइंटर सुरक्षा

    char* end = str;
    char temp;

    // एंड पॉइंटर को नल टर्मिनेटर तक बढ़ाएं
    while (*end) {
        end++;
    }
    end--; // अंतिम गैर-नल अक्षर पर वापस आएं

    char* start = str;
    while (start < end) {
        temp = *start;
        *start = *end;
        *end = temp;

        start++;
        end--;
    }
}
```

## जटिलता और मेमोरी विश्लेषण

| मापदंड | जटिलता | तकनीकी विवरण |
|---|---|---|
| समय जटिलता | `O(N)` | `\0` खोजने के लिए $N$ चरण और $N / 2$ कैरेक्टर स्वैप। |
| सहायक मेमोरी | `O(१)` | केवल पॉइंटर रजिस्टर और एकल टेम्प वेरिएबल। |

## वास्तविक दुनिया में सिस्टम इंजीनियरिंग उपयोग

### प्रोडक्शन सिस्टम आर्किटेक्चर: मेमोरी सेगमेंट सुरक्षा

१. **स्ट्रिंग लिटरल्स बनाम ऐरे:** `reverse("hello")` को कॉल करने पर सेगमेंटेशन फॉल्ट (`SIGSEGV`) होता है क्योंकि लिटरल्स रीड-ओनली `.rodata` मेमोरी में होते हैं। स्ट्रिंग को म्यूट करने योग्य ऐरे (`char str[] = "hello";`) में होना चाहिए।
२. **नेटवर्क बाइट ऑर्डर (Endianness):** बिग-एंडियन और लिटल-एंडियन के बीच बाइट्स को उलटना।

## सीमा स्थितियां और प्रोडक्शन सुरक्षा

१. **नल पॉइंटर (`str == NULL`):** प्रारंभिक जांच द्वारा सुरक्षित।
२. **खाली स्ट्रिंग (`""`):** `end < start` होने पर लूप नहीं चलता।
