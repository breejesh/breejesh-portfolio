> **टीएल;डीआर**
> * **किताब का सवाल:** पूर्णांकों (संभवतः ऋणात्मक) के $M \times N$ मैट्रिक्स को देखते हुए, सबसे बड़ी संभव योग वाला उपमैट्रिक्स खोजें।
> * **मुख्य समाधान:** **पंक्ति-युग्म उपसर्ग योग संकुचन के माध्यम से 2D कदाने का एल्गोरिदम**:
>   1. शीर्ष पंक्ति `r1` और निचली पंक्ति `r2` को तय करें। प्रत्येक स्तंभ `c` के लिए `colSum[c] = sum(matrix[r1..r2][c])` की गणना करें।
>   2. `colSum[]` पर **कदाने का 1D अधिकतम उपसरणी** लागू करें।
>   3. सभी $O(M^2)$ पंक्ति-युग्मों पर पुनरावृत्ति करें, प्रत्येक जोड़े पर $O(N)$ कदाने।
>   4. समय: **$O(M^2 \cdot N)$**। स्पेस: **$O(N)$**।
> * **रियल-वर्ल्ड सिस्टम:** वित्तीय P&L हीटमैप अधिकतम लाभ आयत निष्कर्षण।

## १. किताब का सवाल और संदर्भ

*क्रैकिंग द कोडिंग इंटरव्यू* (समस्या १७.२४) में पूछा गया है:

*"सबसे बड़ी संभव योग वाले उपमैट्रिक्स को खोजने के लिए एक एल्गोरिदम लिखें।"*

## २. 2D कदाने की कार्यप्रणाली

```
मैट्रिक्स:
  [  2  1 -3 -4  3 ]
  [ -3  4  1  2 -1 ]
  [  1  2 -3  2  3 ]
  [ -2  5 -5  3  1 ]

पंक्ति युग्म (r1=1, r2=3):
  colSum = [-4, 11, -7, 7, 3]

colSum पर कदाने: maxSum = 14 (c=1 से c=3: 11-7+7+3=14)
सर्वश्रेष्ठ आयत: पंक्तियां 1-3, स्तंभ 1-3, योग=14
```

## प्रोडक्शन कार्यान्वयन

```java
public class MaxSubmatrix {

    public static int[] maxSubmatrix(int[][] matrix) {
        int rows = matrix.length, cols = matrix[0].length;
        int[] best = {Integer.MIN_VALUE, 0, 0, 0, 0};

        for (int r1 = 0; r1 < rows; r1++) {
            int[] colSum = new int[cols];
            for (int r2 = r1; r2 < rows; r2++) {
                for (int c = 0; c < cols; c++) colSum[c] += matrix[r2][c];
                int[] kadane = kadane(colSum, cols);
                if (kadane[0] > best[0]) best = new int[]{kadane[0], r1, kadane[1], r2, kadane[2]};
            }
        }
        return best;
    }

    private static int[] kadane(int[] arr, int n) {
        int maxSum = Integer.MIN_VALUE, current = 0;
        int start = 0, end = 0, tempStart = 0;
        for (int i = 0; i < n; i++) {
            current += arr[i];
            if (current > maxSum) { maxSum = current; start = tempStart; end = i; }
            if (current < 0) { current = 0; tempStart = i + 1; }
        }
        return new int[]{maxSum, start, end};
    }
}
```

## जटिलता विश्लेषण

| चरण | समय जटिलता | स्पेस |
|---|---|---|
| पंक्ति युग्म पुनरावृत्ति | $O(M^2)$ | — |
| स्तंभ योग अपडेट + कदाने | $O(N)$ प्रति जोड़ा | $O(N)$ |
| **कुल** | **$O(M^2 \cdot N)$** | **$O(N)$** |

## वास्तविक दुनिया में सिस्टम इंजीनियरिंग उपयोग

१. **वित्तीय P&L हीटमैप:** परिसंपत्ति रिटर्न मैट्रिक्स में अधिकतम-लाभ आयताकार उपखिड़कियां खोजना।
२. **चिकित्सा छवि में चमक क्षेत्र:** CT/PET स्कैन स्लाइस में अधिकतम तीव्रता टाइल का पता लगाना।

## सीमा स्थितियां और प्रोडक्शन सुरक्षा

१. **सभी ऋणात्मक:** सबसे कम ऋणात्मक कोशिका लौटाना (कदाने इसे संभालता है)।
२. **एकल पंक्ति/स्तंभ:** 1D कदाने में सुचारू रूप से अवक्रमित।
