> **टीएल;डीआर**
> * **किताब का सवाल:** एक ऐसा मेथड लिखें जो दो संख्याओं में से अधिकतम संख्या ज्ञात करता है। आपको `if-else` या किसी अन्य तुलना ऑपरेटर (`<`, `>`, `==`) का उपयोग नहीं करना चाहिए।
> * **मुख्य समाधान:** **ब्रांचलेस साइन-बिट मल्टीप्लेक्सिंग और ओवरफ्लो सुरक्षा**:
>   1. **साइन निष्कर्षण**: MSB साइन बिट निकालें: `sign(x) = (x >>> 31) ^ 1` (यदि $x \ge 0$ तो $१$, यदि $x < 0$ तो $०$)।
>   2. **ओवरफ्लो का जाल**: जब $a$ और $b$ के विपरीत चिह्न हों, तो $a - b$ में ओवरफ्लो हो सकता है।
>   3. **एकीकृत सूत्र**:
>      * यदि चिह्न भिन्न हैं (`sa ^ sb == 1`): यदि $a$ धनात्मक है तो $a$ चुनें (`k = sa`)।
>      * यदि चिह्न समान हैं (`sa ^ sb == 0`): `sc = sign(a - b)` का उपयोग करें।
>      * गुणांक: `k = (sa ^ sb) * sa + (1 ^ (sa ^ sb)) * sc`।
>   4. **परिणाम**: `return a * k + b * (k ^ 1);`।
>   5. यह **$O(1)$ समय** और **$O(1)$ मेमोरी** में चलता है।
> * **रियल-वर्ल्ड सिस्टम:** साइड-चैनल हमलों से सुरक्षित क्रिप्टोग्राफी और SIMD ऑपरेशंस।

## १. किताब का सवाल और संदर्भ

*क्रैकिंग द कोडिंग इंटरव्यू* (समस्या १६.७) में पूछा गया है:

*"बिना किसी तुलना ऑपरेटर या सशर्त बयानों (if-else) के दो पूर्णांकों में से अधिकतम मान ज्ञात करने के लिए विधि लिखें।"*

## २. बिटवाइज़ लॉजिक और गणित

साइन बिट का उपयोग करके हम एक चयन गुणक $k \in \{०, १\}$ बनाते हैं ताकि बिना किसी सीपीयू जंप के गणना की जा सके।

## प्रोडक्शन कार्यान्वयन

```java
public class NumberMax {

    private static int sign(int a) {
        return (a >>> 31) ^ 1;
    }

    public static int getMax(int a, int b) {
        int sa = sign(a);
        int sb = sign(b);
        int sc = sign(a - b);

        int useSignA = sa ^ sb;
        int useSignC = useSignA ^ 1;

        int k = useSignA * sa + useSignC * sc;
        int q = k ^ 1;

        return a * k + b * q;
    }
}
```

## जटिलता विश्लेषण

| मापदंड | मान | तकनीकी विवरण |
|---|---|---|
| समय जटिलता | `O(1)` | बिना किसी सशर्त ब्रांचिंग के बिटवाइज़ ऑपरेशंस। |
| सहायक स्पेस | `O(1)` | स्थिर मेमोरी उपयोग। |
| ब्रांच मिसप्रेडिक्शन | `०%` | सीपीयू पाइपलाइन में शून्य विलंब। |

## वास्तविक दुनिया में सिस्टम इंजीनियरिंग उपयोग

१. **साइड-चैनल सुरक्षा:** `if` स्टेटमेंट्स सीपीयू कैश टाइमिंग के माध्यम से गुप्त कुंजियों को लीक कर सकते हैं। ब्रांचलेस कोड समय की भिन्नता को समाप्त करता है।
२. **SIMD निर्देश:** कंपाइलर इन ऑपरेशंस को सीधे हार्डवेयर `_mm256_max_epi32` निर्देशों में बदलते हैं।
