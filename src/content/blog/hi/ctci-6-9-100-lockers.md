> **टीएल;डीआर**
> * **किताब का सवाल:** एक दालान में १०० बंद लॉकर हैं। एक आदमी पास १ में सभी १०० लॉकर खोलता है। पास २ में, वह हर दूसरे लॉकर को बदलता है। पास ३ में, हर तीसरे को... पास १०० में, केवल १००वें लॉकर को। १०० पास के बाद कितने लॉकर खुले रहते हैं?
> * **मुख्य समाधान:** **गुणनखंड समता / पूर्ण वर्ग**: लॉकर $k$ को उसके विभाजकों की संख्या के बराबर बार बदला जाता है। चूंकि गुणनखंड जोड़े $(a, b)$ में आते हैं जहां $a \times b = k$, इसलिए कुल गुणनखंड हमेशा **सम** होते हैं, सिवाय इसके कि जब $a = b \implies k = a^2$ (पूर्ण वर्ग)। केवल **पूर्ण वर्गों** के विषम गुणनखंड होते हैं और वे खुले रहते हैं। १ से १०० के बीच $\lfloor \sqrt{100} \rfloor = \mathbf{10}$ पूर्ण वर्ग हैं ($1, 4, 9, 16, 25, 36, 49, 64, 81, 100$)।
> * **रियल-वर्ल्ड सिस्टम:** इराटोस्थनीज की छलनी (Sieve of Eratosthenes) और सीपीयू कैश लाइन बहु-तरफा टकराव।

## १. किताब का सवाल और संदर्भ

*क्रैकिंग द कोडिंग इंटरव्यू* (समस्या ६.९) में पूछा गया है:

*"१०० बंद लॉकर हैं। प्रत्येक पास i में i के गुणज वाले लॉकरों की स्थिति बदली जाती है। १०० पास के बाद कितने लॉकर खुले रहेंगे?"*

## २. गुणनखंड युग्मन गणितीय प्रमाण

१. **टॉगल नियम:** लॉकर $k$ को पास $i$ में केवल तभी बदला जाता है जब $i$, $k$ को विभाजित करता हो।
२. **गुणनखंड युग्म:** प्रत्येक संख्या के गुणनखंड जोड़ों $(a, b)$ में आते हैं:
   * उदाहरण ($k = 12$): $(1, 12), (2, 6), (3, 4) \implies 6$ गुणनखंड (सम $\implies$ बंद)।
३. **पूर्ण वर्ग अपवाद:** यदि $a = b \implies k = a^2$, तो वह गुणनखंड एक ही बार गिना जाता है:
   * उदाहरण ($k = 16$): $(1, 16), (2, 8), (4, 4) \implies \{1, 2, 4, 8, 16\}$ (५ गुणनखंड, विषम $\implies$ खुला)।
४. **खुले लॉकरों की गिनती:**
   $$\{1, 4, 9, 16, 25, 36, 49, 64, 81, 100\} \implies \lfloor \sqrt{100} \rfloor = \mathbf{10}$$

## प्रोडक्शन कार्यान्वयन

```java
import java.util.ArrayList;
import java.util.List;

public class LockersProblem {
    /**
     * खुले लॉकरों की संख्या O(1) में निकालता है।
     */
    public static int countOpenLockers(int n) {
        if (n <= 0) return 0;
        return (int) Math.sqrt(n);
    }

    /**
     * खुले लॉकर नंबरों की सूची लौटाता है।
     */
    public static List<Integer> getOpenLockers(int n) {
        List<Integer> openLockers = new ArrayList<>();
        for (int i = 1; i * i <= n; i++) {
            openLockers.add(i * i);
        }
        return openLockers;
    }
}
```

## जटिलता और मेमोरी विश्लेषण

| मापदंड | जटिलता | तकनीकी विवरण |
|---|---|---|
| गणना समय | `O(१)` | सीधा वर्गमूल `Math.sqrt(n)`। |
| सूची निर्माण | `O(\sqrt{N})` | $\sqrt{N}$ तक लूप निष्पादन। |
| सहायक मेमोरी | `O(१)` | गिनती के लिए शून्य मेमोरी आवंटन। |

### प्रोडक्शन सिस्टम आर्किटेक्चर: गुणनखंड सममिति

१. **इराटोस्थनीज की छलनी (अभाज्य संख्या खोज):** $\sqrt{N}$ तक के कारकों का परीक्षण करके अनावश्यक विभाजनों को समाप्त करना।
२. **सीपीयू कैश लाइन टकराव:** मेमोरी स्ट्राइड एक्सेस पैटर्न।

## सीमा स्थितियां और प्रोडक्शन सुरक्षा

१. **$n = 1$:** १ लौटाता है।
२. **$n \le 0$:** ० लौटाता है।
