> **टीएल;डीआर**
> * **किताब का सवाल:** एक स्टैक को इस प्रकार सॉर्ट करने के लिए एक प्रोग्राम लिखें कि सबसे छोटे तत्व शीर्ष पर हों। आप एक अतिरिक्त अस्थायी स्टैक का उपयोग कर सकते हैं, लेकिन तत्वों को किसी अन्य डेटा संरचना में कॉपी नहीं कर सकते।
> * **मुख्य समाधान:** अस्थायी स्टैक `r` को एक सॉर्टेड बफर (शीर्ष पर सबसे बड़े तत्व) के रूप में रखें। `s` से `tmp` निकालें। जब तक `!r.isEmpty() && r.peek() > tmp`, तत्वों को `r` से वापस `s` में डालें, फिर `tmp` को `r` में डालें। अंत में `r` से सभी तत्वों को `s` में स्थानांतरित करें ($O(N^२)$ समय और $O(N)$ स्पेस)।
> * **रियल-वर्ल्ड सिस्टम:** सीमित मेमोरी वाले माइक्रोकंट्रोलर और रिवर्स पॉलिश नोटेशन (RPN) कैलकुलेटर।

## १. किताब का सवाल और संदर्भ

*क्रैकिंग द कोडिंग इंटरव्यू* (समस्या ३.५) में पूछा गया है:

*"एक स्टैक को इस तरह से सॉर्ट करने के लिए एक प्रोग्राम लिखें कि सबसे छोटे तत्व शीर्ष पर हों। आप एक अतिरिक्त अस्थायी स्टैक का उपयोग कर सकते हैं, लेकिन किसी अन्य संरचना की अनुमति नहीं है।"*

## २. स्टैक इंसर्शन सॉर्ट कार्यप्रणाली

हम एक सहायक स्टैक `r` का उपयोग करते हैं जिसमें सबसे बड़े तत्व शीर्ष पर होते हैं:
१. `s` के शीर्ष तत्व को एक चर `tmp = s.pop()` में निकालें।
२. जब तक `r` खाली न हो और `r.peek() > tmp`:
   * `r` से तत्व निकालें और वापस `s` में डालें (`s.push(r.pop())`)।
३. `tmp` को `r` में डालें।
४. जब तक `s` खाली न हो जाए, यह प्रक्रिया दोहराएं।
५. अंत में, `r` के सभी तत्वों को वापस `s` में डालें। चूंकि `r` में सबसे बड़े तत्व शीर्ष पर थे, इसलिए `s` में जाने पर सबसे छोटे तत्व शीर्ष पर आ जाते हैं।

## प्रोडक्शन कार्यान्वयन

```java
import java.util.Stack;

public class SortStack {
    /**
     * स्टैक s को सॉर्ट करता है ताकि सबसे छोटे तत्व शीर्ष पर हों।
     * समय जटिलता: O(N^2)
     * स्पेस जटिलता: O(N)
     */
    public static void sort(Stack<Integer> s) {
        Stack<Integer> r = new Stack<>();

        while (!s.isEmpty()) {
            int tmp = s.pop();
            while (!r.isEmpty() && r.peek() > tmp) {
                s.push(r.pop());
            }
            r.push(tmp);
        }

        // r से तत्वों को वापस s में डालें
        while (!r.isEmpty()) {
            s.push(r.pop());
        }
    }
}
```

## जटिलता और मेमोरी विश्लेषण

| मापदंड | जटिलता | तकनीकी विवरण |
|---|---|---|
| समय जटिलता | `O(N^२)` | $N$ तत्वों में से प्रत्येक के लिए स्टैक्स के बीच अधिकतम $N$ ट्रांसफर हो सकते हैं। |
| सहायक मेमोरी | `O(N)` | अधिकतम $N$ तत्वों को स्टोर करने वाला एकल सहायक स्टैक। |

## वास्तविक दुनिया में सिस्टम इंजीनियरिंग उपयोग

### प्रोडक्शन सिस्टम आर्किटेक्चर: सीमित मेमोरी वातावरण

१. **एम्बेडेड माइक्रोकंट्रोलर:** जहां डायनामिक हीप उपलब्ध नहीं होता, वहां स्टैक-आधारित इन-सीटू सॉर्टिंग मेमोरी सुरक्षा सुनिश्चित करती है।
२. **आरपीएन कैलकुलेटर:** हार्डवेयर स्टैक रजिस्टरों पर अंकगणितीय गणनाओं का निष्पादन।

## सीमा स्थितियां और प्रोडक्शन सुरक्षा

१. **पहले से सॉर्टेड स्टैक:** बिना किसी बैक-ट्रांसफर के $O(N)$ समय में पूरा होता है।
२. **डुप्लिकेट मान (`5, 5, 5`):** `r.peek() > tmp` की सख्त तुलना के कारण सुरक्षित रूप से प्रबंधित।
३. **खाली या एकल तत्व स्टैक:** $O(१)$ में समाप्त।
