> **टीएल;डीआर**
> * **किताब का सवाल:** बताएं कि निम्नलिखित कोड क्या करता है: `((n & (n - 1)) == 0)`।
> * **मुख्य व्याख्या:** $n$ से १ घटाने पर सबसे निचला १-बिट `0` में बदल जाता है और उसके बाद के सभी शून्य `1` में बदल जाते हैं। यदि $n$ में ठीक एक १-बिट है (यानी $n$, २ की घात है), तो $n$ और $n - 1$ में कोई भी साझा १-बिट नहीं होता, जिससे $n \ \& \ (n - 1)$ का मान `0` हो जाता है। अतः, यह व्यंजक जांचता है कि क्या $n$, **२ की घात** (या $0$) है ($O(१)$ समय और $O(१)$ स्पेस)।
> * **रियल-वर्ल्ड सिस्टम:** रिंग बफ़र्स में मॉड्यूलो इंडेक्सिंग और हैश टेबल बकेट साइजिंग (Java `HashMap`)।

## १. किताब का सवाल और संदर्भ

*क्रैकिंग द कोडिंग इंटरव्यू* (समस्या ५.५) में पूछा गया है:

*"बताएं कि निम्नलिखित कोड क्या करता है: `((n & (n - 1)) == 0)`"*

## २. बिटवाइज़ गणितीय विश्लेषण

जब आप किसी पूर्णांक $n$ से १ घटाते हैं:
१. **यदि $n$ के अंत में १ है:**
   * $n = \text{abc}1$
   * $n - 1 = \text{abc}0$
   * $n \ \& \ (n - 1) = \text{abc}0$ (सबसे निचला १-बिट साफ़ हो जाता है)।
२. **यदि $n$ के अंत में शून्य हैं:**
   * $n = \text{abc}1000$
   * $n - 1 = \text{abc}0111$
   * $n \ \& \ (n - 1) = \text{abc}0000$।

यह ऑपरेशन $n \ \& \ (n - 1)$ **हमेशा $n$ के सबसे निचले सेट १-बिट को साफ़ कर देता है**।

### यह शून्य कब देता है?
यह केवल तभी `0` देता है जब उच्च बिट्स न हों ($\text{abc} = 0$), यानी $n$ में **अधिकतम एक १-बिट** हो:
* यदि $n = 0$: $0 \ \& \ -1 = 0 \implies \text{true}$।
* यदि $n = 2^k$ (२ की घात): एकल १-बिट साफ़ हो जाता है $\implies \text{true}$।
* यदि $n$ में २ या अधिक १s हैं: $\text{false}$।

निष्कर्ष:
$$\text{isPowerOfTwo}(n) \iff n > 0 \text{ और } ((n \ \& \ (n - 1)) == 0)$$

## प्रोडक्शन कार्यान्वयन

```java
public class Debugger {
    /**
     * जांचता है कि क्या धनात्मक पूर्णांक २ की घात है।
     * समय जटिलता: O(1)
     * स्पेस जटिलता: O(1)
     */
    public static boolean isPowerOfTwo(int n) {
        return n > 0 && ((n & (n - 1)) == 0);
    }

    /**
     * सबसे निचले १-बिट को साफ़ करता है (ब्रायन कर्निंगन एल्गोरिदम)।
     */
    public static int clearLowestSetBit(int n) {
        return n & (n - 1);
    }
}
```

## जटिलता और मेमोरी विश्लेषण

| मापदंड | जटिलता | तकनीकी विवरण |
|---|---|---|
| समय जटिलता | `O(१)` | घटाव और बिटवाइज़ AND ऑपरेशन (१ सीपीयू चक्र)। |
| सहायक मेमोरी | `O(१)` | शून्य मेमोरी आवंटन। |

## वास्तविक दुनिया में सिस्टम इंजीनियरिंग उपयोग

### प्रोडक्शन सिस्टम आर्किटेक्चर: २ की घात का अनुकूलन

१. **सर्कुलर रिंग बफर (Disruptor / Netty):** $C = 2^k$ होने पर `index % C` को `index & (C - 1)` से बदल दिया जाता है।
२. **हैश मैप (Java `HashMap`):** त्वरित बकेट इंडेक्स गणना के लिए तालिका क्षमता को २ की घात में रखना।

## सीमा स्थितियां और प्रोडक्शन सुरक्षा

१. **$n = 0$:** `true` देता है। अतः धनात्मक २ की घातों के लिए `n > 0` लगाना आवश्यक है।
२. **ऋणात्मक संख्याएं:** टू-कॉम्प्लिमेंट में `Integer.MIN_VALUE` में एक ही १ होता है; `n > 0` इसे रोकता है।
