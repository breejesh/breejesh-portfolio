> **टीएल;डीआर**
> * **किताब का सवाल:** $n$ पूर्णांकों का एक क्रमबद्ध ऐरे दिया गया है जिसे अज्ञात बार घुमाया गया है। ऐरे में किसी तत्व को खोजने के लिए कोड लिखें।
> * **मुख्य समाधान:** **संशोधित बाइनरी सर्च और सॉर्टेड हाफ इनवेरिएंट**: (१) कम से कम एक आधा भाग ($[left, mid]$ या $[mid, right]$) हमेशा सामान्य रूप से क्रमबद्ध होता है; (२) यदि $A[left] < A[mid]$ है, तो बायां भाग क्रमबद्ध है: यदि लक्ष्य $x \in [A[left], A[mid]]$ है तो बाईं ओर खोजें, अन्यथा दाईं ओर; (३) यदि $A[mid] < A[left]$ है, तो दायां भाग क्रमबद्ध है; (४) यदि $A[left] == A[mid]$ (डुप्लिकेट्स) है, तो आवश्यक होने पर दोनों भागों की खोज करें; (५) यह **औसत $O(\log N)$ समय** और सबसे खराब स्थिति में $O(N)$ समय में चलता है।
> * **रियल-वर्ल्ड सिस्टम:** रिंग बफ़र्स (Apache Kafka) और नेटवर्क पैकेट कतारों में ऑफसेट खोज।

## १. किताब का सवाल और संदर्भ

*क्रैकिंग द कोडिंग इंटरव्यू* (समस्या १०.३) में पूछा गया है:

*"एक अज्ञात बिंदु पर घूमे हुए क्रमबद्ध ऐरे में दिए गए तत्व की स्थिति ज्ञात करने के लिए कुशल एल्गोरिदम लिखें।"*

## २. सॉर्टेड हाफ इनवेरिएंट

प्रत्येक विभाजन पर:
* यदि $A[left] < A[mid]$ है, तो बायां भाग सामान्य आरोही क्रम में है।
* यदि $A[mid] < A[left]$ है, तो दायां भाग सामान्य आरोही क्रम में है।
* यदि $A[left] == A[mid]$ है, तो डुप्लिकेट तत्वों के कारण $A[right]$ की जांच करें या दोनों दिशाओं में खोजें।

## प्रोडक्शन कार्यान्वयन

```java
public class SearchInRotatedArray {
    /**
     * घूर्णित ऐरे में x खोजता है।
     * समय जटिलता: O(log N) औसत, O(N) सबसे खराब स्थिति (डुप्लिकेट)।
     * स्पेस जटिलता: O(log N)
     */
    public static int search(int[] a, int left, int right, int x) {
        if (right < left) return -1;

        int mid = left + (right - left) / 2;
        if (a[mid] == x) {
            return mid;
        }

        // स्थिति 1: बायां भाग सामान्य रूप से क्रमबद्ध है
        if (a[left] < a[mid]) {
            if (x >= a[left] && x < a[mid]) {
                return search(a, left, mid - 1, x); // बाईं ओर खोजें
            } else {
                return search(a, mid + 1, right, x); // दाईं ओर खोजें
            }
        }
        // स्थिति 2: दायां भाग सामान्य रूप से क्रमबद्ध है
        else if (a[mid] < a[left]) {
            if (x > a[mid] && x <= a[right]) {
                return search(a, mid + 1, right, x); // दाईं ओर खोजें
            } else {
                return search(a, left, mid - 1, x); // बाईं ओर खोजें
            }
        }
        // स्थिति 3: डुप्लिकेट तत्व
        else {
            if (a[mid] != a[right]) {
                return search(a, mid + 1, right, x);
            } else {
                int result = search(a, left, mid - 1, x);
                if (result == -1) {
                    return search(a, mid + 1, right, x);
                }
                return result;
            }
        }
    }
}
```

## जटिलता और मेमोरी विश्लेषण

| स्थिति | समय जटिलता | सहायक मेमोरी | तकनीकी विवरण |
|---|---|---|---|
| अद्वितीय पूर्णांक | `O(\log N)` | `O(\log N)` | मानक बाइनरी सर्च जो खोज स्थान को आधा करता है। |
| डुप्लिकेट (सबसे खराब स्थिति) | `O(N)` | `O(\log N)` | सभी तत्व समान होने पर ($[2, 2, 2, 2]$)। |

## वास्तविक दुनिया में सिस्टम इंजीनियरिंग उपयोग

### प्रोडक्शन सिस्टम आर्किटेक्चर: रिंग बफर ऑफसेट खोज

१. **काफ्का लॉग सेगमेंट्स:** चक्रीय रूप से घूमने वाले बफर में संदेशों के टाइमस्टैम्प की खोज बिना डेटा कॉपी किए बाइनरी सर्च से की जाती है।
२. **डेटाबेस पार्टिशनिंग:** घूर्णित कुंजी सीमाओं में लक्षित नोड की पहचान।

## सीमा स्थितियां और प्रोडक्शन सुरक्षा

१. **अनुपस्थित तत्व:** सुरक्षित रूप से `-1` लौटाना।
२. **बिना घूमा हुआ ऐरे:** मानक बाइनरी सर्च की तरह निर्बाध निष्पादन।
