> **टीएल;डीआर**
> * **किताब का सवाल:** एक ८x८ चेसबोर्ड है जिसमें से दो विपरीत कोनों को काट दिया गया है। आपको ३१ डोमिनोज़ दिए गए हैं, और एक डोमिनोज़ ठीक दो आसन्न वर्गों को ढक सकता है। क्या आप पूरे बोर्ड को ढकने के लिए ३१ डोमिनोज़ का उपयोग कर सकते हैं?
> * **मुख्य समाधान:** **द्विदलीय इनवेरिएंट प्रमाण**: एक पूर्ण ८x८ बोर्ड में ३२ सफेद और ३२ काले वर्ग होते हैं। तिरछे विपरीत कोने हमेशा **एक ही रंग** (उदा. दोनों सफेद) साझा करते हैं। उन्हें हटाने पर ३० सफेद और ३२ काले वर्ग बचते हैं (कुल ६२ वर्ग)। चूंकि प्रत्येक २x१ डोमिनोज़ अनिवार्य रूप से ठीक १ सफेद और १ काला वर्ग ढकता है, इसलिए ३१ डोमिनोज़ को ३१ सफेद और ३१ काले वर्ग चाहिए। अतः बोर्ड को पूरी तरह ढकना गणितीय रूप से **असंभव** है।
> * **रियल-वर्ल्ड सिस्टम:** द्विदलीय ग्राफ अधिकतम मिलान (Hopcroft-Karp) और संसाधन आवंटन गतिरोध प्रमाण।

## १. किताब का सवाल और संदर्भ

*क्रैकिंग द कोडिंग इंटरव्यू* (समस्या ६.३) में पूछा गया है:

*"एक ८x८ चेसबोर्ड से दो विपरीत कोने हटा दिए गए हैं। क्या ३१ डोमिनोज़ से बोर्ड को ढका जा सकता है?"*

## २. द्विदलीय रंगाई और समता प्रमाण

१. **मानक चेसबोर्ड रंगाई:** ३२ काले और ३२ सफेद वर्ग।
२. **विपरीत कोनों की समता:** शीर्ष-बाएं $(0, 0)$ और नीचे-दाएं $(7, 7)$ दोनों का रंग समान होता है।
३. **शेष वर्ग:** ३० वर्ग एक रंग के और ३२ वर्ग दूसरे रंग के।
४. **डोमिनोज़ की विशेषता:** प्रत्येक डोमिनोज़ हमेशा ठीक १ सफेद और १ काला वर्ग ढकता है।
५. **निष्कर्ष:** ३१ डोमिनोज़ को ३१ सफेद और ३१ काले वर्ग चाहिए। चूंकि $31 \ne 30$, इसलिए यह असंभव है।

## प्रोडक्शन कार्यान्वयन

```java
public class DominosChessboard {
    /**
     * सत्यापित करता है कि क्या कटे हुए बोर्ड को डोमिनोज़ से ढका जा सकता है।
     * समय जटिलता: O(1)
     * स्पेस जटिलता: O(1)
     */
    public static boolean canTileMutilatedBoard(int rows, int cols, int removedR1, int removedC1,
                                                int removedR2, int removedC2) {
        int totalSquares = (rows * cols) - 2;
        if (totalSquares % 2 != 0) return false;

        int color1 = (removedR1 + removedC1) % 2;
        int color2 = (removedR2 + removedC2) % 2;

        // यदि हटाए गए दोनों वर्ग समान रंग के हैं, तो टाइलिंग असंभव है
        return color1 != color2;
    }
}
```

## वास्तविक दुनिया में सिस्टम इंजीनियरिंग उपयोग

### प्रोडक्शन सिस्टम आर्किटेक्चर: द्विदलीय मिलान इनवेरिएंट

१. **कुबेरनेट्स टास्क शेड्यूलर:** नोड एफिनिटी नियमों को सत्यापित करने और आवंटन गतिरोध को रोकने के लिए द्विदलीय इनवेरिएंट का उपयोग करता है।
२. **मेमोरी बैंक इंटरलीविंग:** बस टकराव को खत्म करने के लिए मेमोरी एक्सेस लाइनों का सम-विषम विभाजन।

## सीमा स्थितियां और प्रोडक्शन सुरक्षा

१. **१ सफेद और १ काला कोना हटाना:** गोमोरी के प्रमेय (Gomory's Theorem) के अनुसार बोर्ड को ढका जा सकता है।
२. **विषम ग्रिड ($7 \times 7$):** कुल विषम वर्ग, कभी नहीं ढका जा सकता।
