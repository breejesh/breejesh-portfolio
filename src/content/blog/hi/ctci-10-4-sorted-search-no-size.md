> **टीएल;डीआर**
> * **किताब का सवाल:** आपको एक ऐरे जैसी डेटा संरचना `Listy` दी गई है जिसमें `size()` विधि नहीं है, लेकिन इसमें `elementAt(i)` विधि है जो $O(१)$ समय में इंडेक्स $i$ पर तत्व लौटाती है (सीमा से बाहर होने पर `-1` लौटाती है)। क्रमबद्ध धनात्मक पूर्णांकों वाले `Listy` में तत्व $x$ का इंडेक्स खोजें।
> * **मुख्य समाधान:** **घातीय दोहरीकरण खोज + बाउंडेड बाइनरी सर्च**: (१) `index = 1` से शुरू करें और `index *= 2` करते जाएं जब तक कि `elementAt(index) == -1` या `elementAt(index) >= value` न हो जाए; (२) बाउंडेड विंडो $[index / 2, index]$ में बाइनरी सर्च निष्पादित करें; (३) `-1` मान मिलने पर बाईं ओर खोजें; (४) यह **इष्टतम $O(\log p)$ समय** (जहाँ $p$ तत्व का इंडेक्स है) और **$O(१)$ स्पेस** में पूरा होता है।
> * **रियल-वर्ल्ड सिस्टम:** काफ्का (Kafka) स्ट्रीम्स में टाइमस्टैम्प ऑफसेट खोज और मेमोरी-मैप्ड फाइल्स (`mmap`)।

## १. किताब का सवाल और संदर्भ

*क्रैकिंग द कोडिंग इंटरव्यू* (समस्या १०.४) में पूछा गया है:

*"अज्ञात आकार वाली क्रमबद्ध डेटा संरचना Listy में किसी तत्व x का सूचकांक ज्ञात करें, जो सीमा से बाहर होने पर -1 लौटाती है।"*

## २. घातीय खोज की कार्यप्रणाली ($O(\log p)$)

१. **घातीय दोहरीकरण चरण:** सूचकांकों $1, 2, 4, 8, \dots, 2^k$ की जांच करें जब तक कि लक्ष्य मान से बड़ी संख्या या `-1` न मिल जाए। यह ठीक $\lceil \log_2 p \rceil$ चरणों में पूरा होता है।
२. **बाउंडेड बाइनरी सर्च:** अंतराल $[2^{k-1}, 2^k]$ में $O(\log p)$ समय में बाइनरी सर्च चलाएं।

## प्रोडक्शन कार्यान्वयन

```java
public class SortedSearchNoSize {
    public static class Listy {
        private final int[] array;

        public Listy(int[] arr) { this.array = arr; }

        public int elementAt(int i) {
            if (i < 0 || i >= array.length) return -1;
            return array[i];
        }
    }

    /**
     * Listy में मान खोजता है।
     * समय जटिलता: O(log p) जहाँ p लक्ष्य तत्व का इंडेक्स है।
     * स्पेस जटिलता: O(1)
     */
    public static int search(Listy list, int value) {
        int index = 1;
        while (list.elementAt(index) != -1 && list.elementAt(index) < value) {
            index *= 2;
        }
        return binarySearch(list, value, index / 2, index);
    }

    private static int binarySearch(Listy list, int value, int low, int high) {
        int mid;

        while (low <= high) {
            mid = low + (high - low) / 2;
            int middle = list.elementAt(mid);

            if (middle > value || middle == -1) {
                high = mid - 1;
            } else if (middle < value) {
                low = mid + 1;
            } else {
                return mid;
            }
        }
        return -1;
    }
}
```

## जटिलता और मेमोरी विश्लेषण

| मापदंड | जटिलता | तकनीकी विवरण |
|---|---|---|
| समय जटिलता | `O(\log p)` | $\log_2 p$ दोहरीकरण चरण + $\log_2 p$ बाइनरी सर्च चरण। |
| सहायक मेमोरी | `O(१)` | निरंतर मेमोरी में चलने वाला पुनरावृत्त एल्गोरिदम। |

## वास्तविक दुनिया में सिस्टम इंजीनियरिंग उपयोग

### प्रोडक्शन सिस्टम आर्किटेक्चर: असीमित स्ट्रीम ऑफसेट

१. **काफ्का स्ट्रीम ऑफसेट खोज:** उपभोक्ता समूह निरंतर चलने वाले डेटा स्ट्रीम में टाइमस्टैम्प ऑफसेट खोजने के लिए घातीय प्रोबिंग का उपयोग करते हैं।
२. **वर्चुअल मेमोरी फाइलें:** अनपेक्षित मेमोरी एक्सेस को बिना क्रैश किए सेंटिनल मानों द्वारा हल करना।

## सीमा स्थितियां और प्रोडक्शन सुरक्षा

१. **इंडेक्स ० पर तत्व:** प्रारंभिक लूप शर्त `[0, 1]` रेंज को सही ढंग से संभालती है।
२. **अनुपस्थित तत्व:** सुरक्षित रूप से `-1` लौटाना।
