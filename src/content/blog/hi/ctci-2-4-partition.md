> **टीएल;डीआर**
> * **किताब का सवाल:** एक लिंक्ड लिस्ट को मान $x$ के चारों ओर विभाजित करने के लिए कोड लिखें, ताकि $x$ से छोटे सभी नोड्स $x$ से बड़े या बराबर सभी नोड्स से पहले आएं।
> * **मुख्य समाधान:** दो पॉइंटर्स `head` और `tail` रखें। लिस्ट को स्कैन करते समय, $x$ से छोटे तत्वों को शुरुआत (`head`) में और $x$ से बड़े या बराबर तत्वों को अंत (`tail`) में जोड़ें, जिससे $O(N)$ समय और $O(१)$ स्पेस में विभाजन पूरा होता है।
> * **रियल-वर्ल्ड सिस्टम:** लिंक्ड लिस्ट के लिए क्विकसॉर्ट विभाजन और नेटवर्क पैकेट प्राथमिकता कतारें।

## १. किताब का सवाल और संदर्भ

*क्रैकिंग द कोडिंग इंटरव्यू* (समस्या २.४) में पूछा गया है:

*"एक लिंक्ड लिस्ट को मान x के चारों ओर विभाजित करने के लिए कोड लिखें, ताकि x से छोटे सभी नोड्स x से बड़े या बराबर सभी नोड्स से पहले आएं। यदि x लिस्ट में मौजूद है, तो x के मान केवल x से छोटे तत्वों के बाद होने चाहिए।"*

**उदाहरण:**
* इनपुट: `3 -> 5 -> 8 -> 5 -> 10 -> 2 -> 1` [विभाजन मान = `5`]
* आउटपुट: `1 -> 2 -> 3 -> 5 -> 8 -> 5 -> 10` (या `3 -> 1 -> 2 -> 10 -> 5 -> 5 -> 8`)

## २. हेड / टेल वृद्धि विभाजन तकनीक

यदि मूल सापेक्ष क्रम को बनाए रखना अनिवार्य नहीं है, तो हम लिस्ट को दोनों सिरों से एक साथ बढ़ा सकते हैं:
१. प्रारंभिक नोड को `head` और `tail` दोनों पर सेट करें।
२. प्रत्येक अगले नोड के लिए:
   * यदि `current.data < x`, तो इसे `head` से पहले जोड़ें (`current.next = head; head = current;`)।
   * यदि `current.data >= x`, तो इसे `tail` के बाद जोड़ें (`tail.next = current; tail = current;`)।
३. अंत में `tail.next = null` सेट करें।

## प्रोडक्शन कार्यान्वयन

```java
public class PartitionList {
    public static class LinkedListNode {
        public int data;
        public LinkedListNode next;
        public LinkedListNode(int d) { this.data = d; }
    }

    /**
     * मान x के आधार पर लिंक्ड लिस्ट को विभाजित करता है।
     * समय जटिलता: O(N)
     * स्पेस जटिलता: O(1) सहायक स्पेस
     */
    public static LinkedListNode partition(LinkedListNode node, int x) {
        if (node == null) return null;

        LinkedListNode head = node;
        LinkedListNode tail = node;

        LinkedListNode current = node;
        while (current != null) {
            LinkedListNode next = current.next;
            if (current.data < x) {
                // नोड को हेड पर जोड़ें
                current.next = head;
                head = current;
            } else {
                // नोड को टेल पर जोड़ें
                tail.next = current;
                tail = current;
            }
            current = next;
        }
        tail.next = null;

        return head;
    }
}
```

## जटिलता और मेमोरी विश्लेषण

| मापदंड | जटिलता | तकनीकी विवरण |
|---|---|---|
| समय जटिलता | `O(N)` | लिंक्ड लिस्ट के सभी $N$ नोड्स का एकल पास। |
| सहायक मेमोरी | `O(१)` | बिना किसी अतिरिक्त डेटा संरचना के इन-प्लेस पॉइंटर संशोधन। |

## वास्तविक दुनिया में सिस्टम इंजीनियरिंग उपयोग

### प्रोडक्शन सिस्टम आर्किटेक्चर: क्विकसॉर्ट और कतार प्राथमिकता वर्गीकरण

१. **लिंक्ड लिस्ट क्विकसॉर्ट:** क्विकसॉर्ट का पार्टीशन चरण बिना नए एरे आवंटित किए सीधे पॉइंटर्स को पुनर्व्यवस्थित करता है।
२. **नेटवर्क क्वालिटी ऑफ सर्विस (QoS) कतारें:** राउटर आने वाले पैकेट्स को प्राथमिकता थ्रेशोल्ड के आधार पर तत्काल अलग-अलग कतारों में विभाजित करते हैं।

## सीमा स्थितियां और प्रोडक्शन सुरक्षा

१. **खाली लिस्ट या एकल नोड:** $O(१)$ में सुरक्षित रूप से संभाला जाता है।
२. **सभी तत्व $x$ से छोटे या बड़े होना:** अंतिम `tail.next = null` चक्र बनने से रोकता है।
३. **विभाजन मान $x$ का लिस्ट में न होना:** तुलना शर्त `< x` के कारण सही रूप से कार्य करता है।
