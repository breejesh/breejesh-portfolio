> **टीएल;डीआर**
> * **किताब का सवाल:** मान लें कि आपके पास `isSubstring` नाम की एक विधि है जो जांचती है कि क्या एक शब्द दूसरे शब्द का सबस्ट्रिंग है। दो स्ट्रिंग्स `s1` और `s2` दिए जाने पर, केवल एक बार `isSubstring` को कॉल करके यह जांचने के लिए कोड लिखें कि क्या `s2`, `s1` का रोटेशन है (जैसे `'waterbottle'`, `'erbottlewat'` का रोटेशन है)।
> * **मुख्य समाधान:** यदि `s2`, `s1` का रोटेशन है, तो `s1` को दो भागों $x$ और $y$ में विभाजित किया जा सकता है जहां $s_1 = xy$ और $s_2 = yx$। `s1` को स्वयं के साथ जोड़ने पर ($s_1s_1 = xyxy$), $yx$ ($s_2$) हमेशा $s_1s_1$ का एक निरंतर सबस्ट्रिंग होगा।
> * **रियल-वर्ल्ड सिस्टम:** लिनक्स कर्नेल में रिंग बफर, नेटवर्क टोकन रिंग प्रोटोकॉल और कम्प्यूटेशनल बायोलॉजी में सर्कुलर डीएनए जीनोम अलाइनमेंट।

## १. किताब का सवाल और गणितीय प्रमाण

*क्रैकिंग द कोडिंग इंटरव्यू* (समस्या १.९) में पूछा गया है:

*"मान लें कि आपके पास isSubstring नाम की एक विधि है जो जांचती है कि क्या एक शब्द दूसरे शब्द का सबस्ट्रिंग है। दो स्ट्रिंग्स s1 और s2 दिए जाने पर, केवल एक बार isSubstring को कॉल करके यह जांचने के लिए कोड लिखें कि क्या s2, s1 का रोटेशन है (जैसे 'waterbottle', 'erbottlewat' का रोटेशन है)।"*

**गणितीय आधार:**
यदि $s_2$, $s_1$ का चक्रीय रोटेशन है, तो एक विभाजन बिंदु मौजूद होता है जो $s_1$ को दो हिस्सों में बांटता है:
* $s_1 = x + y$ (उदाहरण: $x = \text{"wat"}$, $y = \text{"erbottle"}$)
* $s_2 = y + x$ (उदाहरण: $y = \text{"erbottle"}$, $x = \text{"wat"}$)

अब $s_1$ को स्वयं से जोड़ने पर ($s_1s_1$):
$$s_1s_1 = s_1 + s_1 = (x + y) + (x + y) = x + (y + x) + y = x + s_2 + y$$

चूंकि $s_2 = yx$, इसलिए $s_2$ स्वाभाविक रूप से $s_1s_1$ का एक हिस्सा (सबस्ट्रिंग) बन जाता है। इस प्रकार `isSubstring(s1s1, s2)` केवल एक कॉल में सत्यापन कर देता है।

## २. सरल दृष्टिकोण और इसकी कमियां

एक सरल तरीका $s_1$ के सभी $N$ चक्रीय रोटेशन उत्पन्न करके प्रत्येक की तुलना $s_2$ से करना होगा:
* **समय जटिलता:** $O(N^2)$ क्योंकि प्रत्येक $N$ रोटेशन के लिए $O(N)$ तुलना की आवश्यकता होती है।
* **मेमोरी जटिलता:** $O(N)$ प्रत्येक रोटेटेड स्ट्रिंग आवंटित करने के लिए।

यह प्रक्रिया सीपीयू चक्रों को व्यर्थ करती है और `isSubstring` को केवल एक बार कॉल करने के नियम का उल्लंघन करती है।

## ३. इष्टतम कार्यप्रणाली

१. जांचें कि क्या दोनों स्ट्रिंग्स समान और गैर-शून्य लंबाई की हैं। यदि लंबाई भिन्न है या शून्य है, तो $O(१)$ में तुरंत `false` लौटाएं।
२. $s_1$ को स्वयं के साथ जोड़ें: `String s1s1 = s1 + s1`।
३. `isSubstring(s1s1, s2)` को कॉल करें और बूलियन परिणाम लौटाएं।

## प्रोडक्शन कार्यान्वयन

```java
public class StringRotation {
    /**
     * जांचता है कि क्या s2, s1 का चक्रीय रोटेशन है।
     * समय जटिलता: O(N) यदि isSubstring O(N + M) समय में चलता है।
     * स्पेस जटिलता: O(N) दोगुनी स्ट्रिंग s1s1 को स्टोर करने के लिए।
     */
    public static boolean isRotation(String s1, String s2) {
        int len = s1 != null ? s1.length() : 0;

        // सुनिश्चित करें कि s1 और s2 समान और गैर-शून्य लंबाई के हैं
        if (len == s2.length() && len > 0) {
            String s1s1 = s1 + s1;
            return isSubstring(s1s1, s2);
        }

        return false;
    }

    public static boolean isSubstring(String big, String sub) {
        return big.contains(sub);
    }
}
```

## जटिलता और मेमोरी विश्लेषण

| मापदंड | जटिलता | तकनीकी विवरण |
|---|---|---|
| समय जटिलता | `O(N)` | $s_1s_1$ बनाने में $O(N)$ समय लगता है। सबस्ट्रिंग खोज $O(२N + N) = O(N)$ में पूरी होती है। |
| सहायक मेमोरी | `O(N)` | $२N$ लंबाई की स्ट्रिंग $s_1s_1$ के लिए हीप आवंटन। |

## वास्तविक दुनिया में सिस्टम इंजीनियरिंग उपयोग

### प्रोडक्शन सिस्टम आर्किटेक्चर: रिंग बफर और चक्रीय संरचनाएं

१. **लॉक-फ्री रिंग बफर (एलमैक्स डिसरप्टर / लिनक्स के-फाइफो):** रिंग बफर में डेटा ओवरफ्लो को संभालने के लिए मेमोरी को डबल-मैप किया जाता है ताकि बिना किसी ब्रांचिंग के निरंतर रीड्स संभव हो सकें।
२. **सर्कुलर डीएनए और बायोइन्फॉर्मेटिक्स:** बैक्टीरिया का डीएनए गोलाकार होता है। जीन संरेखण उपकरण शुरुआत और अंत की पहचान के लिए दोगुनी स्ट्रिंग तकनीक का उपयोग करते हैं।
३. **नेटवर्क टोकन रिंग:** चक्रीय रूटिंग में टोकन सत्यापन।

## सीमा स्थितियां और प्रोडक्शन सुरक्षा

१. **भिन्न लंबाई (`"water"`, `"waterbottle"`):** $O(१)$ में `false` लौटाता है।
२. **खाली स्ट्रिंग्स (`""`, `""`):** `len > 0` द्वारा `false` लौटाता है।
३. **समान स्ट्रिंग्स (`"apple"`, `"apple"`):** शून्य रोटेशन, `true` लौटाता है।
४. **एकल अक्षर वाली स्ट्रिंग्स (`"a"`, `"a"`):** `true` लौटाता है।
५. **शून्य मान (Null):** शुरुआती सुरक्षित जांच द्वारा नियंत्रित।
