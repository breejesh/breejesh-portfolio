> **टीएल;डीआर**
> * **किताब का सवाल:** आप एक ऐसा स्टैक कैसे डिजाइन करेंगे जिसमें पुश और पॉप के अलावा एक फ़ंक्शन `min` हो जो न्यूनतम तत्व लौटाता हो? पुश, पॉप और मिन तीनों को $O(१)$ समय में काम करना चाहिए।
> * **मुख्य समाधान:** सहायक मिन-स्टैक: पिछले न्यूनतम तत्वों को ट्रैक करने वाला एक समानांतर स्टैक रखें। जब कोई मान वर्तमान न्यूनतम से छोटा या बराबर हो, तो उसे `minStack` में डालें। पॉप करते समय मान के न्यूनतम के बराबर होने पर `minStack` से भी पॉप करें ($O(१)$ समय)।
> * **रियल-वर्ल्ड सिस्टम:** स्लाइडिंग विंडो न्यूनतम कतारें और ऑडियो डीएसपी सिग्नल बफर।

## १. किताब का सवाल और संदर्भ

*क्रैकिंग द कोडिंग इंटरव्यू* (समस्या ३.२) में पूछा गया है:

*"आप एक ऐसा स्टैक कैसे डिजाइन करेंगे जिसमें push और pop के अलावा एक function min हो जो न्यूनतम तत्व लौटाता हो? push, pop और min सभी को O(1) समय में चलना चाहिए।"*

## २. स्कैनिंग की विफलता और सहायक मिन-स्टैक तकनीक

प्रत्येक `min()` कॉल पर पूरे स्टैक को स्कैन करने में $O(N)$ समय लगता है। प्रत्येक नोड में न्यूनतम मान स्टोर करने में $O(N)$ अतिरिक्त मेमोरी लगती है।

*इष्टतम डिजाइन:* एक द्वितीयक `minStack` रखें जो केवल तभी मान दर्ज करता है जब वह वर्तमान न्यूनतम से छोटा या बराबर हो। चूंकि न्यूनतम मान बार-बार नहीं बदलते, इसलिए दूसरे स्टैक की मेमोरी खपत बहुत कम होती है।

## प्रोडक्शन कार्यान्वयन

```java
import java.util.Stack;

public class StackWithMin extends Stack<Integer> {
    private final Stack<Integer> minStack = new Stack<>();

    public void push(int value) {
        if (value <= min()) {
            minStack.push(value);
        }
        super.push(value);
    }

    public Integer pop() {
        int value = super.pop();
        if (value == min()) {
            minStack.pop();
        }
        return value;
    }

    public int min() {
        if (minStack.isEmpty()) {
            return Integer.MAX_VALUE;
        } else {
            return minStack.peek();
        }
    }
}
```

## जटिलता और मेमोरी विश्लेषण

| मापदंड | जटिलता | तकनीकी विवरण |
|---|---|---|
| push(x) समय | `O(१)` | सीधा पुश और शर्त आधारित मिन-स्टैक पुश। |
| pop() समय | `O(१)` | सीधा पॉप और शर्त आधारित मिन-स्टैक पॉप। |
| min() समय | `O(१)` | मिन-स्टैक के शीर्ष की त्वरित जांच। |
| सहायक मेमोरी | `O(M)` | अवरोही न्यूनतम तत्वों की संख्या के अनुपात में मेमोरी ($M \le N$)। |

## वास्तविक दुनिया में सिस्टम इंजीनियरिंग उपयोग

### प्रोडक्शन सिस्टम आर्किटेक्चर: स्लाइडिंग विंडो मॉनिटरिंग

ऑडियो डिजिटल सिग्नल प्रोसेसिंग (DSP) और वित्तीय ऑर्डर बुक मॉनिटरिंग रोलिंग विंडो में निरंतर समय में न्यूनतम खोजने के लिए दोहरे स्टैक दृष्टिकोण का उपयोग करते हैं।

## सीमा स्थितियां और प्रोडक्शन सुरक्षा

१. **डुप्लिकेट न्यूनतम मान (`push(2), push(2)`):** दोनों को मिन-स्टैक में रखा जाता है ताकि समय से पहले निष्कासन से बचा जा सके।
२. **खाली स्टैक पर min():** `Integer.MAX_VALUE` लौटाता है।
