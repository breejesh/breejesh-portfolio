> **टीएल;डीआर**
> * **किताब का सवाल:** सिंगली लिंक्ड लिस्ट में मध्य के किसी नोड (पहला और अंतिम नोड छोड़कर कोई भी नोड) को हटाने के लिए एक एल्गोरिदम लिखें, जब आपको केवल उसी नोड का एक्सेस दिया गया हो।
> * **मुख्य समाधान:** अगले नोड के डेटा और पॉइंटर को वर्तमान नोड में कॉपी करें (`n.data = n.next.data; n.next = n.next.next;`), जिससे अगला नोड स्वतः हट जाता है और यह कार्य $O(१)$ समय व $O(१)$ स्पेस में पूरा होता है।
> * **रियल-वर्ल्ड सिस्टम:** लॉक-फ्री सिंगली लिंक्ड कतारें, इवेंट लूप टाइमर रद्दीकरण और मेमोरी रीसाइक्लिंग।

## १. किताब का सवाल और संदर्भ

*क्रैकिंग द कोडिंग इंटरव्यू* (समस्या २.३) में पूछा गया है:

*"सिंगली लिंक्ड लिस्ट में मध्य के किसी नोड को हटाने के लिए एक एल्गोरिदम लिखें, जब आपको केवल उसी नोड का एक्सेस प्राप्त हो।"*

**उदाहरण:**
* इनपुट: लिंक्ड लिस्ट `a -> b -> c -> d -> e -> f` में से नोड `c`
* परिणाम: कोई मान नहीं लौटाया जाता, लेकिन लिंक्ड लिस्ट `a -> b -> d -> e -> f` बन जाती है।

## २. मुख्य चुनौती और समाधान की आवश्यकता

पारंपरिक लिंक्ड लिस्ट में नोड हटाने के लिए शुरुआत (`head`) से ट्रैवर्स करके पिछले नोड (`prev`) को ढूंढना पड़ता है ताकि `prev.next = current.next` किया जा सके, जिसमें $O(N)$ समय लगता है।

लेकिन जब हमारे पास **केवल लक्ष्य नोड `n`** का संदर्भ होता है, तो हम पीछे नहीं जा सकते क्योंकि लिंक्स एकतरफा (Unidirectional) होते हैं।

## ३. मान कॉपी करने की इष्टतम कार्यप्रणाली

लक्ष्य नोड `n` को हटाने के बजाय, हम अगले नोड के मान और पॉइंटर को `n` में कॉपी कर लेते हैं:
१. डेटा कॉपी करें: `n.data = n.next.data`।
२. अगले नोड को छोड़ें: `n.next = n.next.next`।

यह प्रक्रिया लक्ष्य नोड पर उसके पड़ोसी का डेटा लिख देती है और पड़ोसी को लिंक से बाहर कर देती है। यह कार्य बिना किसी ट्रैवर्सल के शुद्ध $O(१)$ समय में पूरा होता है।

## प्रोडक्शन कार्यान्वयन

```java
public class DeleteMiddleNode {
    public static class LinkedListNode {
        public int data;
        public LinkedListNode next;
        public LinkedListNode(int d) { this.data = d; }
    }

    /**
     * केवल नोड का संदर्भ होने पर उसे हटाता है।
     * समय जटिलता: O(1)
     * स्पेस जटिलता: O(1)
     */
    public static boolean deleteNode(LinkedListNode n) {
        if (n == null || n.next == null) {
            return false; // नल या अंतिम नोड को नहीं हटाया जा सकता
        }

        LinkedListNode next = n.next;
        n.data = next.data;
        n.next = next.next;
        return true;
    }
}
```

## जटिलता और मेमोरी विश्लेषण

| मापदंड | जटिलता | तकनीकी विवरण |
|---|---|---|
| समय जटिलता | `O(१)` | बिना किसी लूप के सीधे फील्ड असाइनमेंट। |
| सहायक मेमोरी | `O(१)` | मौजूदा नोड्स में इन-प्लेस बदलाव। |

## वास्तविक दुनिया में सिस्टम इंजीनियरिंग उपयोग

### प्रोडक्शन सिस्टम आर्किटेक्चर: कर्नेल इंट्रूसिव लिस्ट और इवेंट टाइमर

१. **लिनक्स कर्नेल इंट्रूसिव लिस्ट (`struct list_head`):** मेमोरी बाधाओं में एकल-लिंक्ड नोड्स पर डेटा ओवरराइटिंग द्वारा तत्काल नोड हटाया जाता है।
२. **इवेंट लूप टाइमर व्हील:** टाइमर कैंसिल होने पर पूरे क्यू को स्कैन किए बिना $O(१)$ में कॉलबैक नोड हटाना।

## सीमा स्थितियां और प्रोडक्शन सुरक्षा

१. **लक्ष्य नोड नल होना:** `if (n == null) return false;` द्वारा सुरक्षित।
२. **अंतिम नोड होना (`n.next == null`):** यदि लक्ष्य नोड टेल (अंतिम नोड) है, तो इसे इस विधि से हल **नहीं** किया जा सकता क्योंकि पिछले नोड का संदर्भ `null` नहीं किया जा सकता। यह सीमा इंटरव्यूअर को स्पष्ट रूप से बतानी चाहिए।
