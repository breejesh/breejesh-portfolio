> **टीएल;डीआर**
> * **किताब का सवाल:** $n$ आकार की सरणी से $m$ पूर्णांकों का एक यादृच्छिक सेट उत्पन्न करने के लिए एक विधि लिखें। प्रत्येक तत्व के चुने जाने की संभावना समान ($m/n$) होनी चाहिए।
> * **मुख्य समाधान:** **रिज़र्वॉयर सैंपलिंग (Reservoir Sampling)**:
>   1. पहले $m$ तत्वों को `subset` रिज़र्वॉयर सरणी में कॉपी करें।
>   2. $i = m$ से $n - 1$ तक लूप चलाएं:
>      * $[0, i]$ में एक यादृच्छिक पूर्णांक $k$ चुनें।
>      * यदि $k < m$, तो `subset[k] = array[i]` को बदलें।
>   3. **गणितीय प्रमाण**: चरण $i$ पर, प्रत्येक तत्व के रिज़र्वॉयर में रहने की संभावना ठीक $m / (i + 1)$ होती है, जो अंत में $m/n$ बन जाती है।
>   4. यह **$O(N)$ समय** और **$O(M)$ सहायक स्पेस** में चलता है।
> * **रियल-वर्ल्ड सिस्टम:** Envoy नेटवर्क प्रॉक्सी में पैकेट सैंपलिंग और PostgreSQL `ANALYZE` में टेबल आँकड़े।

## १. किताब का सवाल और संदर्भ

*क्रैकिंग द कोडिंग इंटरव्यू* (समस्या १७.३) में पूछा गया है:

*"N आकार की सरणी में से M तत्वों का एक उपसमूह निष्पक्ष रूप से चुनें ताकि प्रत्येक तत्व की चयन संभावना m/n हो।"*

## २. रिज़र्वॉयर सैंपलिंग का गणितीय आगमन

मौजूदा तत्व के बचने की संभावना $1 - \frac{1}{i+1} = \frac{i}{i+1}$ होती है, जिससे संचयी प्रायिकता $\frac{m}{i} \times \frac{i}{i+1} = \frac{m}{i+1}$ सिद्ध होती है।

## प्रोडक्शन कार्यान्वयन

```java
import java.util.Random;

public class RandomSet {

    private static final Random RNG = new Random();

    public static int[] pickMRecursively(int[] array, int m) {
        if (array == null || m <= 0 || m > array.length) {
            return new int[0];
        }

        int[] subset = new int[m];
        System.arraycopy(array, 0, subset, 0, m);

        for (int i = m; i < array.length; i++) {
            int k = RNG.nextInt(i + 1);
            if (k < m) {
                subset[k] = array[i];
            }
        }

        return subset;
    }
}
```

## जटिलता और मेमोरी विश्लेषण

| मापदंड | जटिलता | तकनीकी विवरण |
|---|---|---|
| समय जटिलता | `O(N)` | इनपुट सरणी का एकल रैखिक स्कैन। |
| सहायक स्पेस | `O(M)` | ठीक M तत्वों का रिज़र्वॉयर बफर। |
| स्ट्रीमिंग समर्थन | `असीमित डेटा` | डेटा की कुल लंबाई जाने बिना काम करने में सक्षम। |

## वास्तविक दुनिया में सिस्टम इंजीनियरिंग उपयोग

### प्रोडक्शन सिस्टम आर्किटेक्चर: वितरित टेलीमेट्री और डेटाबेस

१. **Envoy टेलीमेट्री सैंपलिंग:** नेटवर्क प्रॉक्सी लाखों अनुरोधों में से डिस्क को ओवरलोड किए बिना प्रति मिनट निश्चित $M = 1,000$ ट्रेस संग्रहीत करने के लिए रिज़र्वॉयर सैंपलिंग का उपयोग करते हैं।
२. **PostgreSQL एनालाइज़:** टेराबाइट तालिकाओं में से सांख्यिकीय हिस्टोग्राम तैयार करना।

## सीमा स्थितियां और प्रोडक्शन सुरक्षा

१. **$M > N$ या $M \le 0$:** सुरक्षित रूप से खाली सरणी लौटाना।
