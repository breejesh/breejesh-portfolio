> **टीएल;डीआर**
> * **किताब का सवाल:** एक ऐसा फ़ंक्शन लिखें जो दो संख्याओं को जोड़ता है। आपको `+` या किसी अन्य अंकगणितीय ऑपरेटर का उपयोग नहीं करना चाहिए।
> * **मुख्य समाधान:** **बिटवाइज़ हाफ-एडर रिपल कैरी (Half-Adder)**:
>   1. **बिना कैरी के जोड़**: `sum = a ^ b` (XOR बाइनरी जोड़ करता है: $०+०=०, १+०=१, ०+१=१, १+१=०$)।
>   2. **कैरी जनरेशन**: `carry = (a & b) << 1` (AND टकरावों का पता लगाता है और बाईं ओर शिफ्ट करता है)।
>   3. **पुनरावृत्ति**: $a = \text{sum}$ और $b = \text{carry}$ सेट करें जब तक कि $\text{carry} == 0$ न हो जाए।
>   4. यह **$O(1)$ समय** (३२-बिट पूर्णांक के लिए अधिकतम ३२ चक्र) और **$O(1)$ सहायक स्पेस** में चलता है।
> * **रियल-वर्ल्ड सिस्टम:** सिलिकॉन स्तर पर एएलयू (ALU) और कैरी-लुकअहेड एडर्स (CLA)।

## १. किताब का सवाल और संदर्भ

*क्रैकिंग द कोडिंग इंटरव्यू* (समस्या १७.१) में पूछा गया है:

*"बिना किसी अंकगणितीय ऑपरेटर (+, -, *, /) के केवल बिटवाइज़ ऑपरेटरों द्वारा दो पूर्णांकों को जोड़ने के लिए कोड लिखें।"*

## २. हाफ-एडर डिजिटल सर्किट सिद्धांत

यह प्रक्रिया डिजिटल इलेक्ट्रॉनिक्स में बाइनरी जोड़ के लॉजिक गेट्स की नकल करती है।

## प्रोडक्शन कार्यान्वयन

```java
public class AddWithoutPlus {

    /**
     * बिटवाइज़ ऑपरेटरों द्वारा O(1) समय में जोड़।
     */
    public static int add(int a, int b) {
        while (b != 0) {
            int sum = a ^ b;            // बिना कैरी के बिट्स जोड़ना
            int carry = (a & b) << 1;   // कैरी की गणना और शिफ्टिंग
            a = sum;
            b = carry;
        }
        return a;
    }

    /**
     * रिकर्सिव कार्यान्वयन।
     */
    public static int addRecursive(int a, int b) {
        if (b == 0) return a;
        int sum = a ^ b;
        int carry = (a & b) << 1;
        return addRecursive(sum, carry);
    }
}
```

## जटिलता विश्लेषण

| मापदंड | जटिलता | तकनीकी विवरण |
|---|---|---|
| समय जटिलता | `O(1)` | अधिकतम ३२ पुनरावृत्तियाँ। |
| सहायक स्पेस | `O(1)` | स्थिर रजिस्टर मेमोरी। |
| ऋणात्मक संख्याएं | समर्थित | टू-कॉम्प्लीमेंट प्रणाली द्वारा स्वतः समर्थित। |

## वास्तविक दुनिया में सिस्टम इंजीनियरिंग उपयोग

### प्रोडक्शन सिस्टम आर्किटेक्चर: सिलिकॉन एएलयू सर्किट

१. **कैरी-लुकअहेड एडर्स (CLA):** आधुनिक सीपीयू पाइपलाइन में लीनियर देरी को समाप्त करने के लिए $O(\log N)$ गेट गहराई के साथ समानांतर में कैरी बिट्स की गणना की जाती है।
२. **साइड-चैनल सुरक्षा:** क्रिप्टोग्राफी में टाइमिंग हमलों से बचने के लिए ब्रांचलेस बिटवाइज़ जोड़।

## सीमा स्थितियां और प्रोडक्शन सुरक्षा

२. **शून्य जोड़ना:** लूप में प्रवेश किए बिना तुरंत परिणाम देना।
