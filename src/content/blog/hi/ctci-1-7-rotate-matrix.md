> **टीएल;डीआर**
> * **किताब का सवाल:** N x N मैट्रिक्स द्वारा दर्शाई गई एक छवि दी गई है, जहां प्रत्येक पिक्सेल ४ बाइट्स का है। छवि को इन-प्लेस ९० डिग्री दक्षिणावर्त घुमाने के लिए एक विधि लिखें।
> * **मुख्य समाधान:** परत-दर-परत ४-तरफा अदला-बदली: सबसे बाहरी परत से अंतरतम परत तक जाएं। प्रत्येक सूचकांक के लिए, ऊपर, दाएं, नीचे और बाएं किनारों के बीच ४-तरफा चक्रीय स्वैप करें।
> * **रियल-वर्ल्ड सिस्टम:** जीपीयू फ्रेमबफर ट्रांसफॉर्मेशन, इमेज प्रोसेसिंग पाइपलाइन और जीआईएस रैंडरिंग।

## १. किताब का सवाल और संदर्भ

*क्रैकिंग द कोडिंग इंटरव्यू* (समस्या १.७) में पूछा गया है:

*"N x N मैट्रिक्स द्वारा दर्शाई गई एक छवि दी गई है, जहां प्रत्येक पिक्सेल ४ बाइट्स का है। छवि को इन-प्लेस ९० डिग्री दक्षिणावर्त घुमाने के लिए एक विधि लिखें।"*

## २. परत-दर-परत इन-प्लेस स्वैपिंग कार्यप्रणाली

बिना किसी दूसरी मैट्रिक्स को आवंटित किए इन-प्लेस घुमाने के लिए हमें संकेंद्रित छल्लों (परतों $०$ से $N/२$) पर कार्य करना होता है:
* शीर्ष मान सुरक्षित करें: `int top = matrix[first][i]`
* बायां $\to$ शीर्ष: `matrix[first][i] = matrix[last - offset][first]`
* निचला $\to$ बायां: `matrix[last - offset][first] = matrix[last][last - offset]`
* दायां $\to$ निचला: `matrix[last][last - offset] = matrix[i][last]`
* शीर्ष $\to$ दायां: `matrix[i][last] = top`

## प्रोडक्शन कार्यान्वयन

```java
public class RotateMatrix {
    public static boolean rotate(int[][] matrix) {
        if (matrix == null || matrix.length == 0 || matrix.length != matrix[0].length) return false;

        int n = matrix.length;
        for (int layer = 0; layer < n / 2; layer++) {
            int first = layer;
            int last = n - 1 - layer;

            for (int i = first; i < last; i++) {
                int offset = i - first;
                int top = matrix[first][i]; // शीर्ष मान सुरक्षित करें

                // बायां -> शीर्ष
                matrix[first][i] = matrix[last - offset][first];

                // निचला -> बायां
                matrix[last - offset][first] = matrix[last][last - offset];

                // दायां -> निचला
                matrix[last][last - offset] = matrix[i][last];

                // शीर्ष -> दायां
                matrix[i][last] = top;
            }
        }
        return true;
    }
}
```

## जटिलता और मेमोरी विश्लेषण

| मापदंड | जटिलता | तकनीकी विवरण |
|---|---|---|
| समय जटिलता | `O(N^२)` | N x N मैट्रिक्स के प्रत्येक पिक्सेल को ठीक एक बार स्वैप किया जाता है। |
| सहायक मेमोरी | `O(१)` | मौजूदा २D एरे में इन-प्लेस संशोधन। |

## वास्तविक दुनिया में सिस्टम इंजीनियरिंग उपयोग

### प्रोडक्शन सिस्टम आर्किटेक्चर: ग्राफिक्स ड्राइवर और जीपीयू पाइपलाइन

ग्राफिक्स ड्राइवर स्क्रीन डिस्प्ले ओरिएंटेशन बदलने के लिए सीधे वीआरएएम फ्रेमबफर पर ट्रांसपोज-और-रिफ्लेक्ट ऑपरेशन लागू करते हैं।
