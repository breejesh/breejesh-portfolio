> **टीएल;डीआर**
> * **किताब का सवाल:** पूर्णांकों के एक ऐरे में, एक "शिखर" (Peak) वह तत्व है जो अपने आस-पास के तत्वों से $\ge$ है, और एक "घाटी" (Valley) वह तत्व है जो अपने आस-पास के तत्वों से $\le$ है। दिए गए ऐरे को चोटियों और घाटियों के प्रत्यावर्ती अनुक्रम ($\text{peak} \ge \text{valley} \le \text{peak} \ge \text{valley} \dots$) में व्यवस्थित करें।
> * **मुख्य समाधान:** **स्थानीय अधिकतम विंडो स्वैपिंग**: (१) $O(N \log N)$ में सॉर्ट करने के बजाय, विषम सूचकांकों `for (int i = 1; i < array.length; i += 2)` पर पुनरावृति करें; (२) ३-तत्वों की विंडो $\{A[i-1], A[i], A[i+1]\}$ की जांच करें; (३) विंडो में सबसे बड़े तत्व का सूचकांक खोजें और उसे स्थान $i$ के साथ स्वैप करें; (४) यह स्वैप पिछले शिखर $A[i-2]$ की स्थिति को कभी नहीं तोड़ता; (५) यह **$O(N)$ समय** और **$O(१)$ स्पेस** में निष्पादित होता है।
> * **रियल-वर्ल्ड सिस्टम:** सिग्नल प्रोसेसिंग वेवफ़ॉर्म स्मूथिंग और वित्तीय ज़िगज़ैग (ZigZag) चार्टिंग संकेतक।

## १. किताब का सवाल और संदर्भ

*क्रैकिंग द कोडिंग इंटरव्यू* (समस्या १०.११) में पूछा गया है:

*"पूर्णांकों के एक ऐरे को चोटियों (Peaks) और घाटियों (Valleys) के वैकल्पिक अनुक्रम में पुनर्व्यवस्थित करें।"*

## २. ग्रीडी O(N) इनवेरिएंट

ऐरे को $O(N \log N)$ में सॉर्ट करके जोड़ियों को बदलना अप्रभावी है।

विषम सूचकांकों पर ३-तत्वों की विंडो $\{A[i-1], A[i], A[i+1]\}$ की जांच करके:
* अधिकतम तत्व को $A[i]$ पर ले जाने से $A[i] \ge A[i-1]$ और $A[i] \ge A[i+1]$ सुनिश्चित होता है।
* चूंकि $A[i-1]$ का मान केवल घट सकता है, पिछला संबंध $A[i-2] \ge A[i-1]$ पूरी तरह सुरक्षित रहता है।

## प्रोडक्शन कार्यान्वयन

```java
public class PeaksAndValleys {
    /**
     * ऐरे को वैकल्पिक चोटियों और घाटियों में पुनर्गठित करता है।
     * समय जटिलता: O(N)
     * स्पेस जटिलता: O(1)
     */
    public static void sortValleyPeak(int[] array) {
        for (int i = 1; i < array.length; i += 2) {
            int biggestIndex = maxIndex(array, i - 1, i, i + 1);
            if (i != biggestIndex) {
                swap(array, i, biggestIndex);
            }
        }
    }

    private static int maxIndex(int[] array, int a, int b, int c) {
        int len = array.length;
        int aValue = a >= 0 && a < len ? array[a] : Integer.MIN_VALUE;
        int bValue = b >= 0 && b < len ? array[b] : Integer.MIN_VALUE;
        int cValue = c >= 0 && c < len ? array[c] : Integer.MIN_VALUE;

        int max = Math.max(aValue, Math.max(bValue, cValue));
        if (aValue == max) return a;
        if (bValue == max) return b;
        return c;
    }

    private static void swap(int[] array, int left, int right) {
        int temp = array[left];
        array[left] = array[right];
        array[right] = temp;
    }
}
```

## जटिलता और मेमोरी विश्लेषण

| मापदंड | जटिलता | तकनीकी विवरण |
|---|---|---|
| समय जटिलता | `O(N)` | $N / 2$ स्थानीय विंडो जांच और इन-प्लेस स्वैप। |
| सहायक मेमोरी | `O(१)` | स्रोत ऐरे के अतिरिक्त शून्य मेमोरी आवंटन। |

### प्रोडक्शन सिस्टम आर्किटेक्चर: डिजिटल सिग्नल प्रोसेसिंग (DSP)

१. **ध्वनि और भूकम्पीय तरंग संपीड़न:** निरंतर एनालॉग सिग्नलों को संपीड़ित करने के लिए स्थानीय एक्सट्रीमा का निष्कर्षण।
२. **वित्तीय ज़िगज़ैग संकेतक:** बाज़ार मूल्य उतार-चढ़ाव में शोर को दूर करना।

## सीमा स्थितियां और प्रोडक्शन सुरक्षा

१. **छोटे ऐरे ($N \le 2$):** बिना किसी इंडेक्स एरर के सुरक्षित संचालन।
२. **समान मान वाले तत्व:** बिना किसी अनावश्यक स्वैप के सही निष्पादन।
