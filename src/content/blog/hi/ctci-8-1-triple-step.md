> **टीएल;डीआर**
> * **किताब का सवाल:** एक बच्चा $n$ सीढ़ियों पर दौड़ रहा है और एक बार में १, २ या ३ सीढ़ियां कूद सकता है। बच्चा कितनी संभावित तरीकों से सीढ़ियां चढ़ सकता है, इसकी गणना के लिए एक विधि लागू करें।
> * **मुख्य समाधान:** **ट्रिबोनैकी पुनरावृत्ति (Tribonacci Recurrence)**: $n$वीं सीढ़ी पर पहुंचने के तरीके $W(n) = W(n - 1) + W(n - 2) + W(n - 3)$ होते हैं, जहाँ आधार स्थितियां $W(0) = 1, W(1) = 1, W(2) = 2$ हैं। ३ रोलिंग चरों का उपयोग करने से सरणी आवंटन बचता है, जिससे $O(N)$ समय और $O(१)$ स्पेस प्राप्त होता है।
> * **रियल-वर्ल्ड सिस्टम:** मार्कोव निर्णय प्रक्रियाओं में पथ संयोजन और पूर्णांक ओवरफ्लो नियंत्रण।

## १. किताब का सवाल और संदर्भ

*क्रैकिंग द कोडिंग इंटरव्यू* (समस्या ८.१) में पूछा गया है:

*"एक बच्चा १, २, या ३ कदम कूदकर n सीढ़ियां कितने तरीकों से चढ़ सकता है?"*

## २. पुनरावृत्ति संबंध और रोलिंग चर

$n$वीं सीढ़ी पर पहुंचने के लिए अंतिम छलांग अवश्य होनी चाहिए:
* सीढ़ी $n - 1$ से (१ कदम की छलांग)
* सीढ़ी $n - 2$ से (२ कदम की छलांग)
* सीढ़ी $n - 3$ से (३ कदम की छलांग)

$$W(n) = W(n - 1) + W(n - 2) + W(n - 3)$$

**आधार स्थितियां:**
* $W(0) = 1$
* $W(1) = 1$
* $W(2) = 2$
* $W(3) = 4$

## प्रोडक्शन कार्यान्वयन

```java
public class TripleStep {
    /**
     * O(1) मेमोरी में n सीढ़ियां चढ़ने के तरीकों की गणना करता है।
     * समय जटिलता: O(N)
     * स्पेस जटिलता: O(1)
     */
    public static int countWays(int n) {
        if (n < 0) return 0;
        if (n == 0 || n == 1) return 1;
        if (n == 2) return 2;

        int a = 1; // W(0)
        int b = 1; // W(1)
        int c = 2; // W(2)

        for (int i = 3; i <= n; i++) {
            int d = a + b + c;
            a = b;
            b = c;
            c = d;
        }

        return c;
    }
}
```

## जटिलता और मेमोरी विश्लेषण

| मापदंड | जटिलता | तकनीकी विवरण |
|---|---|---|
| समय जटिलता | `O(N)` | $N - 2$ स्केलर जोड़ ऑपरेशन। |
| सहायक मेमोरी | `O(१)` | केवल ३ रजिस्टर पूर्णांक चर। |

## वास्तविक दुनिया में सिस्टम इंजीनियरिंग उपयोग

### प्रोडक्शन सिस्टम आर्किटेक्चर: पूर्णांक ओवरफ्लो और मैट्रिक्स घातांक

१. **पूर्णांक ओवरफ्लो:** अनुक्रम $O(1.839^n)$ की दर से बढ़ता है, जिससे $n = 37$ पर ३२-बिट पूर्णांक ओवरफ्लो हो जाता है। बड़े $n$ के लिए ६४-बिट `long` या मॉड्यूलर अंकगणित का उपयोग किया जाता है।
२. **मैट्रिक्स घातांक:** विशाल $N$ के लिए $O(\log N)$ समय में गणना को सक्षम बनाता है।

## सीमा स्थितियां और प्रोडक्शन सुरक्षा

१. **$n = 0$:** १ लौटाता है।
२. **$n < 0$:** ० लौटाता है।
