> **टीएल;डीआर**
> * **किताब का सवाल:** एक पोस्ट-एपोकैलिप्टिक दुनिया में, रानी का आदेश है कि सभी परिवारों को तब तक बच्चे पैदा करते रहना चाहिए जब तक कि उनके पास एक लड़की न हो जाए, जिसके बाद उन्हें तुरंत रुकना होगा। नई पीढ़ी का लिंग अनुपात क्या होगा? (मान लें कि लड़का या लड़की होने की संभावना समान है)।
> * **मुख्य समाधान:** लिंग अनुपात कड़ाई से **५०:५० (१:१)** ही रहेगा। प्रत्येक जन्म $P(\text{लड़की}) = 0.5$ के साथ एक स्वतंत्र बर्नौली परीक्षण (Bernoulli Trial) है। परिवारों के रुकने का नियम सिक्का उछालने की अंतर्निहित संभावना को नहीं बदल सकता। प्रति परिवार लड़कों का अपेक्षित मूल्य $E[\text{लड़के}] = \sum_{k=0}^{\infty} k(1/2)^{k+1} = 1.0$ है, जो प्रति परिवार ठीक १ लड़की के बराबर है।
> * **रियल-वर्ल्ड सिस्टम:** मार्टिंगेल स्टॉपिंग थ्योरम और ऑनलाइन ए/बी टेस्टिंग में अर्ली स्टॉपिंग पूर्वाग्रह।

## १. किताब का सवाल और संदर्भ

*क्रैकिंग द कोडिंग इंटरव्यू* (समस्या ६.७) में पूछा गया है:

*"एक नई दुनिया में, जब तक लड़की न हो जाए तब तक परिवार बच्चे पैदा करते रहते हैं। नई पीढ़ी में लड़के और लड़कियों का अनुपात क्या होगा?"*

## २. गणितीय प्रमाण

१. **स्वतंत्र परीक्षण:** प्रत्येक जन्म में लड़की होने की स्वतंत्र संभावना ५०% होती है। रुकने का नियम केवल परिवारों को समूहों में बांटता है, व्यक्तिगत जन्म संभावना को नहीं बदलता।
२. **अपेक्षित मूल्य की गणना:**
   $$E[\text{लड़के}] = 0 \cdot \frac{1}{2} + 1 \cdot \frac{1}{4} + 2 \cdot \frac{1}{8} + 3 \cdot \frac{1}{16} + \dots = 1.0$$
३. चूंकि प्रत्येक परिवार में ठीक १ लड़की और औसतन १ लड़का होता है:
   $$\text{लिंग अनुपात} = \frac{1}{1} = \mathbf{50\% \text{ लड़कियां}, 50\% \text{ लड़के}}$$

## प्रोडक्शन कार्यान्वयन (मोंटे कार्लो सिमुलेशन)

```java
import java.util.Random;

public class ApocalypseRatio {
    /**
     * n परिवारों का सिमुलेशन चलाकर 50:50 अनुपात की पुष्टि करता है।
     * समय जटिलता: O(N)
     * स्पेस जटिलता: O(1)
     */
    public static double runSimulation(int numFamilies) {
        int boys = 0;
        int girls = 0;
        Random random = new Random();

        for (int i = 0; i < numFamilies; i++) {
            while (true) {
                if (random.nextBoolean()) {
                    girls++;
                    break;
                } else {
                    boys++;
                }
            }
        }

        return (double) girls / (girls + boys);
    }
}
```

## जटिलता और मेमोरी विश्लेषण

| मापदंड | जटिलता | तकनीकी विवरण |
|---|---|---|
| सैद्धांतिक अनुपात | `O(१)` | स्थिर १:१ अनुपात। |
| मोंटे कार्लो सिमुलेशन | `O(N)` | सिमुलेटेड परिवारों की संख्या में रैखिक। |
| सहायक मेमोरी | `O(१)` | स्थानीय काउंटर रजिस्टर। |

## वास्तविक दुनिया में सिस्टम इंजीनियरिंग उपयोग

### प्रोडक्शन सिस्टम आर्किटेक्चर: मार्टिंगेल स्टॉपिंग इनवेरिएंट

१. **मात्रात्मक वित्त (Quantitative Finance):** मार्टिंगेल वैकल्पिक रोक प्रमेय दर्शाता है कि समय-आधारित निकास रणनीतियाँ निष्पक्ष स्टोकेस्टिक प्रक्रियाओं के अपेक्षित मूल्य को नहीं बदलती हैं।
२. **ए/बी टेस्टिंग:** समय से पहले प्रयोग रोकने से बचने के लिए सांख्यिकीय सुधार।
