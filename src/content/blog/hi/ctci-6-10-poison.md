> **टीएल;डीआर**
> * **किताब का सवाल:** आपके पास १००० सोडा की बोतलें हैं और ठीक १ जहरीली है। आपके पास जहर का पता लगाने के लिए १० टेस्ट स्ट्रिप्स हैं। एक भी बूंद स्ट्रिप को सकारात्मक बना देती है। परिणाम आने में ७ दिन लगते हैं। यथासंभव कम से कम दिनों में जहरीली बोतल का पता कैसे लगाएं?
> * **मुख्य समाधान:** **बाइनरी प्रतिनिधित्व एन्कोडिंग (७ दिन / १ राउंड)**: बोतलों को ० से ९९९ तक नंबर दें। चूंकि $2^{10} = 1024 > 1000$, प्रत्येक बोतल को १० बाइनरी बिट्स ($b_9 \dots b_0$) द्वारा दर्शाया जा सकता है। दिन ० पर, यदि बोतल $k$ का $i$-वां बिट १ है, तो स्ट्रिप $i$ पर एक बूंद डालें। दिन ७ पर, सकारात्मक स्ट्रिप्स मिलकर जहरीली बोतल का सटीक बाइनरी इंडेक्स बनाती हैं।
> * **रियल-वर्ल्ड सिस्टम:** महामारी विज्ञान में ग्रुप टेस्टिंग (डॉर्फ़मैन पूलिंग) और हाई-थ्रूपुट नेटवर्क लिंक डायग्नोस्टिक्स।

## १. किताब का सवाल और संदर्भ

*क्रैकिंग द कोडिंग इंटरव्यू* (समस्या ६.१०) में पूछा गया है:

*"१००० बोतलों में से १ जहरीली बोतल को १० टेस्ट स्ट्रिप्स का उपयोग करके न्यूनतम समय में कैसे खोजें, जहां परिणाम में ७ दिन लगते हैं?"*

## २. बाइनरी ड्रॉप आवंटन प्रोटोकॉल

१. **सूचना क्षमता:** १० बाइनरी स्ट्रिप्स $2^{10} = 1024$ स्थितियां बना सकती हैं ($1024 \ge 1000$)।
२. **दिन ०:** बोतल $k$ के लिए, यदि उसका $i$-वां बिट १ है, तो स्ट्रिप $i$ पर एक बूंद डालें।
३. **दिन ७:** सभी १० स्ट्रिप्स की जांच करें; सकारात्मक स्ट्रिप्स बाइनरी संख्या के १-बिट्स दर्शाती हैं।

## प्रोडक्शन कार्यान्वयन

```java
import java.util.ArrayList;
import java.util.List;

public class PoisonDetection {
    public static class TestStrip {
        private final int id;
        private final List<Integer> drops = new ArrayList<>();

        public TestStrip(int id) { this.id = id; }
        public void addDrop(int bottleId) { drops.add(bottleId); }
        public boolean isPositive(int poisonedId) { return drops.contains(poisonedId); }
    }

    public static int findPoisonedBottle(int poisonedBottleId, int totalBottles, int totalStrips) {
        List<TestStrip> strips = new ArrayList<>();
        for (int i = 0; i < totalStrips; i++) {
            strips.add(new TestStrip(i));
        }

        // दिन 0: बाइनरी बिट्स के आधार पर बूंदें डालें
        for (int bottle = 0; bottle < totalBottles; bottle++) {
            for (int bit = 0; bit < totalStrips; bit++) {
                if (((bottle >> bit) & 1) == 1) {
                    strips.get(bit).addDrop(bottle);
                }
            }
        }

        // दिन 7: सकारात्मक स्ट्रिप्स से बाइनरी संख्या बनाएं
        int resultBottleId = 0;
        for (int bit = 0; bit < totalStrips; bit++) {
            if (strips.get(bit).isPositive(poisonedBottleId)) {
                resultBottleId |= (1 << bit);
            }
        }

        return resultBottleId;
    }
}
```

## जटिलता और मेमोरी विश्लेषण

| मापदंड | जटिलता | तकनीकी विवरण |
|---|---|---|
| कुल विलंबता | `७ दिन` | केवल एक समानांतर परीक्षण राउंड। |
| सहायक मेमोरी | `O(S)` | १० बूलियन परिणाम। |

## वास्तविक दुनिया में सिस्टम इंजीनियरिंग उपयोग

### प्रोडक्शन सिस्टम आर्किटेक्चर: ग्रुप टेस्टिंग

१. **चिकित्सा महामारी विज्ञान (डॉर्फ़मैन पूलिंग):** बड़े पैमाने पर परीक्षण लागत को लघुगणकीय रूप से कम करने के लिए जैविक नमूनों का सम्मिश्रण।
२. **नेटवर्क स्विच डायग्नोस्टिक जांच:** मल्टीप्लेक्स पैकेट परीक्षण द्वारा दोषपूर्ण ऑप्टिकल लिंक की पहचान।

## सीमा स्थितियां और प्रोडक्शन सुरक्षा

१. **बोतल ० (सभी बिट्स ०):** कोई भी स्ट्रिप सकारात्मक नहीं होती, जो सही ढंग से ० को इंगित करती है।
