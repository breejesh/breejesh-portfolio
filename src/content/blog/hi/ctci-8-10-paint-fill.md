> **टीएल;डीआर**
> * **किताब का सवाल:** इमेज एडिटिंग प्रोग्राम्स में देखा जाने वाला "पेंट फिल" (बाल्टी टूल) फ़ंक्शन लागू करें। २D स्क्रीन सरणी, एक बिंदु $(r, c)$ और एक नया रंग `ncolor` दिए जाने पर, आसपास के क्षेत्र को तब तक भरें जब तक कि रंग मूल रंग से बदल न जाए।
> * **मुख्य समाधान:** **DFS फ्लड फिल एल्गोरिदम**: (१) मूल रंग $O = screen[r][c]$ सहेजें; (२) यदि $O == ncolor$ है, तो अनंत पुनरावृत्ति से बचने के लिए तुरंत वापस आएं; (३) $screen[r][c] = ncolor$ बदलें; (४) सभी ४ मुख्य दिशाओं (ऊपर, नीचे, बाएं, दाएं) में पुनरावृत्ति करें ($O(R \times C)$ समय और स्पेस)।
> * **रियल-वर्ल्ड सिस्टम:** फोटोशॉप पेंट बकेट टूल और कंप्यूटर विज़न में कनेक्टेड कॉम्पोनेंट विश्लेषण (OpenCV)।

## १. किताब का सवाल और संदर्भ

*क्रैकिंग द कोडिंग इंटरव्यू* (समस्या ८.१०) में पूछा गया है:

*"२D स्क्रीन पर किसी बिंदु से जुड़े समान रंग के पूरे क्षेत्र को नए रंग से भरने के लिए पेंट फिल एल्गोरिदम लागू करें।"*

## २. पुनरावर्ती DFS फ्लड फिल विधि

१. **प्रारंभिक शर्त:** यदि मूल रंग पहले से ही नए रंग के समान है, तो तुरंत रुकें।
२. **सीमा जांच:** यदि $(r, c)$ स्क्रीन सीमाओं से बाहर है, तो वापस आएं।
३. **रंग बदलना:** पिक्सेल को अपडेट करें और ४ आसन्न पड़ोसियों में पुनरावृत्ति करें।

## प्रोडक्शन कार्यान्वयन

```java
public class PaintFill {
    public enum Color { Black, White, Red, Yellow, Blue, Green }

    /**
     * समान रंग के सन्निहित क्षेत्र को नए रंग से भरता है।
     * समय जटिलता: O(R * C)
     * स्पेस जटिलता: O(R * C)
     */
    public static boolean paintFill(Color[][] screen, int r, int c, Color ncolor) {
        if (screen == null || r < 0 || r >= screen.length || c < 0 || c >= screen[0].length) {
            return false;
        }
        if (screen[r][c] == ncolor) {
            return false;
        }
        return paintFillHelper(screen, r, c, screen[r][c], ncolor);
    }

    private static boolean paintFillHelper(Color[][] screen, int r, int c,
                                          Color ocolor, Color ncolor) {
        if (r < 0 || r >= screen.length || c < 0 || c >= screen[0].length) {
            return false;
        }

        if (screen[r][c] == ocolor) {
            screen[r][c] = ncolor;
            paintFillHelper(screen, r - 1, c, ocolor, ncolor);
            paintFillHelper(screen, r + 1, c, ocolor, ncolor);
            paintFillHelper(screen, r, c - 1, ocolor, ncolor);
            paintFillHelper(screen, r, c + 1, ocolor, ncolor);
        }

        return true;
    }
}
```

## जटिलता और मेमोरी विश्लेषण

| मापदंड | जटिलता | तकनीकी विवरण |
|---|---|---|
| समय जटिलता | `O(R * C)` | प्रत्येक जुड़े हुए पिक्सेल को ठीक एक बार देखा और बदला जाता है। |
| सहायक मेमोरी | `O(R * C)` | सबसे खराब स्थिति में कॉल स्टैक गहराई। |

## वास्तविक दुनिया में सिस्टम इंजीनियरिंग उपयोग

### प्रोडक्शन सिस्टम आर्किटेक्चर: स्कैनलाइन फ्लड फिल

१. **स्कैनलाइन ऑप्टिमाइज़ेशन (Photoshop):** पिक्सेल-दर-पिक्सेल के बजाय क्षैतिज खंडों को भरकर स्टैक गहराई को $O(R \times C)$ से घटाकर $O(R)$ करना।
२. **कंप्यूटर विज़न (OpenCV):** द्विआधारी छवियों में अलग-अलग भौतिक वस्तुओं को अलग करना।
