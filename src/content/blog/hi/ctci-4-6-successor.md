> **टीएल;डीआर**
> * **किताब का सवाल:** बाइनरी सर्च ट्री (BST) में दिए गए नोड का 'अगला' नोड (यानी इन-ऑर्डर उत्तराधिकारी) खोजने के लिए एक एल्गोरिदम लिखें। आप मान सकते हैं कि प्रत्येक नोड के पास उसके माता-पिता (पैरेंट) का लिंक है।
> * **मुख्य समाधान:** (१) यदि नोड का दायां बच्चा है, तो उत्तराधिकारी **दाएं सबट्री का सबसे बायां नोड** है; (२) अन्यथा, पैरेंट पॉइंटर्स के माध्यम से ऊपर जाएं जब तक हमें ऐसा पैरेंट न मिल जाए जिसके लिए वर्तमान नोड **बाएं सबट्री** में था ($O(H)$ समय और $O(१)$ स्पेस)।
> * **रियल-वर्ल्ड सिस्टम:** डेटाबेस बी-ट्री कर्सर इटरेटर (`cursor.next()`) और स्टैंडर्ड लाइब्रेरी ऑर्डर्ड मैप्स।

## १. किताब का सवाल और संदर्भ

*क्रैकिंग द कोडिंग इंटरव्यू* (समस्या ४.६) में पूछा गया है:

*"बाइनरी सर्च ट्री में किसी दिए गए नोड का इन-ऑर्डर उत्तराधिकारी खोजने के लिए एक एल्गोरिदम लिखें। प्रत्येक नोड के पास अपने पैरेंट का लिंक है।"*

## २. स्थिति विश्लेषण और कार्यप्रणाली

दो मुख्य स्थितियां बनती हैं:

### स्थिति १: नोड के पास दायां सबट्री है
यदि `node.right != null`, तो उत्तराधिकारी दाएं सबट्री का सबसे छोटा तत्व होगा:
* एक बार दाएं जाएं: `curr = node.right`।
* जितना हो सके बाएं जाएं: `while (curr.left != null) curr = curr.left;`।

### स्थिति २: नोड के पास कोई दायां सबट्री नहीं है
यदि `node.right == null`, तो हमें पूर्वजों में खोजना होगा:
* पैरेंट श्रृंखला में ऊपर जाएं जब तक कि हम किसी पैरेंट के **बाएं बच्चे** के रूप में न हों।
* यदि बिना ऐसी स्थिति के हम रूट तक पहुंच जाते हैं, तो नोड पेड़ का अधिकतम तत्व था और कोई उत्तराधिकारी नहीं है (`null`)।

## प्रोडक्शन कार्यान्वयन

```java
public class Successor {
    public static class TreeNode {
        public int val;
        public TreeNode left;
        public TreeNode right;
        public TreeNode parent;

        public TreeNode(int x) {
            this.val = x;
        }
    }

    /**
     * BST में नोड का इन-ऑर्डर उत्तराधिकारी खोजता है।
     * समय जटिलता: O(H) जहां H पेड़ की ऊंचाई है।
     * स्पेस जटिलता: O(1)
     */
    public static TreeNode inorderSucc(TreeNode n) {
        if (n == null) return null;

        // स्थिति 1: दायां बच्चा मौजूद है -> दाएं सबट्री का सबसे बायां नोड
        if (n.right != null) {
            return leftMostChild(n.right);
        } else {
            // स्थिति 2: ऊपर जाएं जब तक हम पैरेंट के बाएं न हों
            TreeNode q = n;
            TreeNode x = q.parent;

            while (x != null && x.left != q) {
                q = x;
                x = x.parent;
            }
            return x;
        }
    }

    private static TreeNode leftMostChild(TreeNode n) {
        if (n == null) return null;
        while (n.left != null) {
            n = n.left;
        }
        return n;
    }
}
```

## जटिलता और मेमोरी विश्लेषण

| मापदंड | जटिलता | तकनीकी विवरण |
|---|---|---|
| समय जटिलता | `O(H)` | सबसे बाईं पत्ती तक नीचे जाना या पूर्वज श्रृंखला में ऊपर जाना (ऊंचाई $H$ तक सीमित)। |
| सहायक मेमोरी | `O(१)` | बिना किसी रिकर्शन या आवंटन के इन-प्लेस इटरेटिव ट्रैवर्सल। |

## वास्तविक दुनिया में सिस्टम इंजीनियरिंग उपयोग

### प्रोडक्शन सिस्टम आर्किटेक्चर: डेटाबेस बी-ट्री कर्सर

१. **एसक्यूएल रेंज स्कैन:** डेटाबेस स्टोरेज इंजन रेंज क्वेरी (`BETWEEN`) को प्रोसेस करने के लिए कर्सर के माध्यम से उत्तराधिकारी नोड्स पर आगे बढ़ते हैं।
२. **सी++ ऑर्डर्ड मैप इटरेटर (`std::map::iterator++`):** पैरेंट पॉइंटर्स के माध्यम से रेड-ब्लैक ट्री पर $O(१)$ अमोर्टाइज्ड समय में अगला तत्व प्राप्त करना।

## सीमा स्थितियां और प्रोडक्शन सुरक्षा

१. **बीएसटी का अधिकतम तत्व:** पूर्वज लूप रूट पार करके `null` लौटाता है।
२. **रूट नोड:** दायां बच्चा होने पर दाएं का न्यूनतम; अन्यथा `null`।
