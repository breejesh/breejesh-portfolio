> **टीएल;डीआर**
> * **किताब का सवाल:** एक $M \times N$ मैट्रिक्स दिया गया है जिसमें प्रत्येक पंक्ति और प्रत्येक स्तंभ आरोही क्रम में क्रमबद्ध है। किसी तत्व को खोजने के लिए एक विधि लिखें।
> * **मुख्य समाधान:** **ऊपरी-दाएं कोने से सैडलबैक स्टेप-वाइज प्रूनिंग**: (१) निर्देशांक `(row = 0, col = N - 1)` (ऊपरी-दाएं कोने) से शुरू करें; (२) यदि `matrix[row][col] == target`, तत्व मिल गया; (३) यदि `matrix[row][col] > target`, तो पूरे वर्तमान स्तंभ में मान लक्ष्य से बड़े हैं, इसलिए `col--` घटाएं; (४) यदि `matrix[row][col] < target`, तो पूरी वर्तमान पंक्ति में मान छोटे हैं, इसलिए `row++` बढ़ाएं; (५) यह **इष्टतम $O(M + N)$ समय** और **$O(१)$ स्पेस** में पूरा होता है।
> * **रियल-वर्ल्ड सिस्टम:** जीआईएस डेटाबेस में स्थानिक खोज (PostGIS) और वित्तीय ट्रेडिंग ऑर्डर बुक मिलान।

## १. किताब का सवाल और संदर्भ

*क्रैकिंग द कोडिंग इंटरव्यू* (समस्या १०.९) में पूछा गया है:

*"एक ऐसे M x N मैट्रिक्स में तत्व खोजें जिसकी प्रत्येक पंक्ति और प्रत्येक स्तंभ आरोही क्रम में व्यवस्थित है।"*

## २. सैडलबैक प्रूनिंग तर्क

$(0, 0)$ से शुरू करने पर कोई निर्णय सीमा नहीं बनती क्योंकि दाईं ओर या नीचे जाने पर दोनों ही मान बढ़ाते हैं।

**ऊपरी-दाएं कोने $(0, \text{cols} - 1)$** से शुरू करने पर:
* **बाईं ओर** जाने पर मान घटता है।
* **नीचे** जाने पर मान बढ़ता है।

प्रत्येक चरण में ठीक एक पंक्ति या स्तंभ स्थायी रूप से खोज स्थान से बाहर हो जाता है:
$$\text{अधिकतम चरण} = M + N$$

## प्रोडक्शन कार्यान्वयन

```java
public class SortedMatrixSearch {
    /**
     * क्रमबद्ध 2D मैट्रिक्स में elem खोजता है।
     * समय जटिलता: O(M + N)
     * स्पेस जटिलता: O(1)
     */
    public static boolean findElement(int[][] matrix, int elem) {
        if (matrix == null || matrix.length == 0 || matrix[0].length == 0) {
            return false;
        }

        int row = 0;
        int col = matrix[0].length - 1;

        while (row < matrix.length && col >= 0) {
            if (matrix[row][col] == elem) {
                return true;
            } else if (matrix[row][col] > elem) {
                col--; // पूरे स्तंभ को छोड़ें
            } else {
                row++; // पूरी पंक्ति को छोड़ें
            }
        }
        return false;
    }
}
```

## जटिलता और मेमोरी विश्लेषण

| मापदंड | जटिलता | तकनीकी विवरण |
|---|---|---|
| समय जटिलता | `O(M + N)` | प्रत्येक पुनरावृत्ति में या तो `row` बढ़ता है या `col` घटता है। |
| सहायक मेमोरी | `O(१)` | केवल दो पूर्णांक सूचकांक चर। |

## वास्तविक दुनिया में सिस्टम इंजीनियरिंग उपयोग

### प्रोडक्शन सिस्टम आर्किटेक्चर: स्थानिक अनुक्रमणिका

१. **स्थानिक R-ट्री बाउंडिंग बॉक्स (PostGIS):** 2D ग्रिड सीमाओं में अवांछित आयतों को बिना आंतरिक सेल पढ़े तुरंत हटाना।
२. **वित्तीय ऑर्डर बुक मिलान:** मूल्य-समय ग्रिड में त्वरित ट्रेड मिलान।

## सीमा स्थितियां और प्रोडक्शन सुरक्षा

१. **न्यूनतम मान से छोटा तत्व:** बाउंड्री से बाहर जाकर सुरक्षित रूप से `false` लौटाना।
२. **अधिकतम मान से बड़ा तत्व:** नीचे से बाहर जाकर तुरंत `false` लौटाना।
