> **टीएल;डीआर**
> * **किताब का सवाल:** परियोजनाओं की एक सूची और निर्भरताओं की एक सूची दी गई है। एक ऐसा निर्माण क्रम खोजें जो परियोजनाओं को क्रमिक रूप से बनाने की अनुमति दे। यदि कोई मान्य क्रम मौजूद नहीं है, तो त्रुटि लौटाएं।
> * **मुख्य समाधान:** **काह्न का इन-डिग्री एल्गोरिदम**: (१) सभी परियोजना नोड्स की इन-डिग्री (आने वाली निर्भरताएं) की गणना करें; (२) शून्य इन-डिग्री वाले नोड्स को कतार में डालें; (३) नोड्स को संसाधित करते समय पड़ोसियों की इन-डिग्री घटाएं; (४) यदि आउटपुट सूची की लंबाई कुल परियोजनाओं से कम है, तो चक्रीय निर्भरता (डेडलाक) मौजूद है ($O(P + D)$ समय)।
> * **रियल-वर्ल्ड सिस्टम:** पैकेज मैनेजर निर्भरता समाधान (npm, Cargo, Maven), डॉकर मल्टी-स्टेज बिल्ड और बाज़ल (Bazel) टास्क शेड्यूलिंग।

## १. किताब का सवाल और संदर्भ

*क्रैकिंग द कोडिंग इंटरव्यू* (समस्या ४.७) में, हमें परियोजनाओं की सूची $P$ और निर्भरताओं के जोड़े $(a, b)$ दिए गए हैं जहां परियोजना $a$ को परियोजना $b$ से पहले बनाया जाना चाहिए। हमें एक मान्य निर्माण क्रम खोजना है या चक्रीय निर्भरता चक्र का पता लगाना है।

## २. काह्न के इन-डिग्री एल्गोरिदम द्वारा टोपोलॉजिकल सॉर्टिंग

१. एक निर्देशित ग्राफ और प्रत्येक नोड के लिए इन-डिग्री मैप `inDegree[node]` बनाएं।
२. `inDegree == 0` वाले सभी नोड्स (जिनके पास कोई पूर्वापेक्षा नहीं है) को प्रोसेसिंग कतार में डालें।
३. कतार से प्रोजेक्ट निकालें, उसे बिल्ड ऑर्डर में जोड़ें और उसके प्रत्येक आउटगोइंग किनारे $(u, v)$ के लिए `inDegree[v]--` करें।
४. जब `inDegree[v] == 0` हो जाए, तो $v$ को कतार में डालें।
५. यदि अंतिम बिल्ड ऑर्डर में कुल परियोजनाओं से कम प्रोजेक्ट हैं, तो चक्र (डेडलाक) मौजूद है।

## प्रोडक्शन कार्यान्वयन

```java
import java.util.*;

public class BuildOrder {
    public static List<String> findBuildOrder(String[] projects, String[][] dependencies) {
        Map<String, List<String>> graph = new HashMap<>();
        Map<String, Integer> inDegree = new HashMap<>();

        for (String p : projects) {
            graph.put(p, new ArrayList<>());
            inDegree.put(p, 0);
        }

        for (String[] dep : dependencies) {
            String parent = dep[0];
            String child = dep[1];
            graph.get(parent).add(child);
            inDegree.put(child, inDegree.get(child) + 1);
        }

        Queue<String> queue = new LinkedList<>();
        for (String p : projects) {
            if (inDegree.get(p) == 0) queue.offer(p);
        }

        List<String> buildOrder = new ArrayList<>();
        while (!queue.isEmpty()) {
            String curr = queue.poll();
            buildOrder.add(curr);

            for (String neighbor : graph.get(curr)) {
                inDegree.put(neighbor, inDegree.get(neighbor) - 1);
                if (inDegree.get(neighbor) == 0) {
                    queue.offer(neighbor);
                }
            }
        }

        if (buildOrder.size() != projects.length) {
            return null; // चक्रीय निर्भरता चक्र का पता चला!
        }
        return buildOrder;
    }
}
```

## जटिलता और मेमोरी विश्लेषण

| मापदंड | जटिलता | तकनीकी विवरण |
|---|---|---|
| समय जटिलता | `O(P + D)` | परियोजनाओं की संख्या P और निर्भरताओं D के योग में रैखिक। |
| सहायक मेमोरी | `O(P + D)` | एडजसेंसी लिस्ट और इन-डिग्री मैप स्टोरेज। |

## सीमा स्थितियां और प्रोडक्शन सुरक्षा
