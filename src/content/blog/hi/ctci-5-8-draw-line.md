> **टीएल;डीआर**
> * **किताब का सवाल:** एक मोनोक्रोम स्क्रीन को बाइट्स के एकल एरे के रूप में संग्रहीत किया जाता है, जिससे आठ पिक्सेल एक बाइट में संग्रहीत होते हैं। स्क्रीन की चौड़ाई $w$, ८ से विभाज्य है। $(x_1, y)$ से $(x_2, y)$ तक एक क्षैतिज रेखा खींचने के लिए `drawLine` फ़ंक्शन लागू करें।
> * **मुख्य समाधान:** **बाइट-संरेखित फास्ट फिल**: (१) शुरुआती और अंतिम बाइट्स की पहचान करें; (२) बीच के सभी पूर्ण बाइट्स को थोक में `(byte) 0xFF` से भरें; (३) किनारों के आंशिक पिक्सल के लिए `start_mask` और `end_mask` लागू करें ($O((x_2 - x_1) / 8)$ समय और $O(१)$ स्पेस)।
> * **रियल-वर्ल्ड सिस्टम:** ई-इंक डिस्प्ले रेंडरिंग और फॉन्ट रेखापुंज इंजन (FreeType)।

## १. किताब का सवाल और संदर्भ

*क्रैकिंग द कोडिंग इंटरव्यू* (समस्या ५.८) में पूछा गया है:

*"एक मोनोक्रोम स्क्रीन को बाइट एरे में संग्रहीत किया जाता है जहां ८ पिक्सेल प्रति बाइट होते हैं। (x1, y) से (x2, y) तक एक क्षैतिज रेखा खींचने के लिए फ़ंक्शन लागू करें।"*

## २. मेमोरी संरचना और बिटमास्क गणना

प्रत्येक पंक्ति में `width / 8` बाइट्स होते हैं।
१. प्रारंभिक पिक्सेल: `start_offset = x1 % 8`।
२. अंतिम पिक्सेल: `end_offset = x2 % 8`।
३. यदि $x_1$ और $x_2$ एक ही बाइट में हैं: संयुक्त मास्क `start_mask & end_mask` लागू करें।
४. यदि कई बाइट्स में फैला है:
   * प्रारंभिक मास्क: `0xFF >> start_offset`।
   * बीच के पूर्ण बाइट्स: `0xFF`।
   * अंतिम मास्क: `~(0xFF >> (end_offset + 1))`।

## प्रोडक्शन कार्यान्वयन

```java
public class DrawLine {
    /**
     * मोनोक्रोम स्क्रीन पर क्षैतिज रेखा खींचता है।
     * समय जटिलता: O(लंबाई / 8)
     * स्पेस जटिलता: O(1)
     */
    public static void drawLine(byte[] screen, int width, int x1, int x2, int y) {
        int start_offset = x1 % 8;
        int first_full_byte = x1 / 8;
        if (start_offset != 0) {
            first_full_byte++;
        }

        int end_offset = x2 % 8;
        int last_full_byte = x2 / 8;
        if (end_offset != 7) {
            last_full_byte--;
        }

        // बीच के सभी पूर्ण बाइट्स को सेट करें
        for (int b = first_full_byte; b <= last_full_byte; b++) {
            screen[(width / 8) * y + b] = (byte) 0xFF;
        }

        byte start_mask = (byte) (0xFF >> start_offset);
        byte end_mask = (byte) ~(0xFF >> (end_offset + 1));

        if ((x1 / 8) == (x2 / 8)) {
            byte mask = (byte) (start_mask & end_mask);
            screen[(width / 8) * y + (x1 / 8)] |= mask;
        } else {
            if (start_offset != 0) {
                int byte_number = (width / 8) * y + first_full_byte - 1;
                screen[byte_number] |= start_mask;
            }
            if (end_offset != 7) {
                int byte_number = (width / 8) * y + last_full_byte + 1;
                screen[byte_number] |= end_mask;
            }
        }
    }
}
```

## जटिलता और मेमोरी विश्लेषण

| मापदंड | जटिलता | तकनीकी विवरण |
|---|---|---|
| समय जटिलता | `O(लंबाई / 8)` | अलग-अलग बिट्स के बजाय ८-८ पिक्सल के पूरे बाइट्स भरता है। |
| सहायक मेमोरी | `O(१)` | स्क्रीन बफर पर इन-प्लेस म्यूटेशन। |

## वास्तविक दुनिया में सिस्टम इंजीनियरिंग उपयोग

### प्रोडक्शन सिस्टम आर्किटेक्चर: लो-लेवल फ्रेमबफ़र्स

१. **ई-पेपर और ओएलईडी डिस्प्ले (SSD1306):** एसपीआई (SPI) बस के माध्यम से सीधी बाइट पंक्तियां लिखना।
२. **फॉन्ट रेखापुंज (FreeType):** १-बिट मोनोक्रोम ग्लिफ़ में क्षैतिज स्कैनलाइन भरना।

## सीमा स्थितियां और प्रोडक्शन सुरक्षा

१. **एक ही बाइट में रेखा:** संयुक्त मास्क द्वारा सुरक्षित रूप से प्रबंधित।
२. **सटीक बाइट सीमाएं:** बिना किसी अतिरिक्त मास्क के सीधे पूरे बाइट्स का भरना।
