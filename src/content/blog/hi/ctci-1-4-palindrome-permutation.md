> **टीएल;डीआर**
> * **किताब का सवाल:** एक स्ट्रिंग दिए जाने पर, यह जांचने के लिए एक फ़ंक्शन लिखें कि क्या यह किसी पैलिंड्रोम (उलटा-सीधा एक समान) का क्रमपरिवर्तन है। केस और गैर-अक्षर वर्णों को अनदेखा करें।
> * **मुख्य समाधान:** पैलिंड्रोम में अधिकतम एक ही अक्षर की विषम (Odd) आवृत्ति हो सकती है। एकल इंटीजर में बिट्स को टॉगल करके (`bitVector ^= (1 << val)`) और `(bitVector & (bitVector - 1)) == 0` द्वारा $O(N)$ समय और $O(१)$ स्पेस में जांचें।
> * **रियल-वर्ल्ड सिस्टम:** बायोइन्फॉर्मेटिक्स में डीएनए पैलिंड्रोम मोटिफ खोज और डेटाबेस क्वेरी सामान्यीकरण।

## १. किताब का सवाल और संदर्भ

*क्रैकिंग द कोडिंग इंटरव्यू* (समस्या १.४) में पूछा गया है:

*"एक स्ट्रिंग दिए जाने पर, यह जांचने के लिए एक फ़ंक्शन लिखें कि क्या यह किसी पैलिंड्रोम का क्रमपरिवर्तन है।"*

उदाहरण: `"Tact Coa"` $\to$ `true` (संभावित पैलिंड्रोम क्रमपरिवर्तन: `"taco cat"`, `"atco cta"`)।

## २. पैरिटी नियम और बिट वेक्टर समाधान

एक पैलिंड्रोम स्ट्रिंग में अधिकतम एक अक्षर विषम संख्या में हो सकता है (विषम लंबाई वाली स्ट्रिंग का केंद्रीय अक्षर)।

हैश मैप या पूर्णांक एरे आवंटित करने के बजाय, हम एकल ३२-बिट इंटीजर को बिट वेक्टर के रूप में उपयोग कर सकते हैं जहां प्रत्येक बिट ० (सम संख्या) और १ (विषम संख्या) के बीच टॉगल करता है:
* प्रत्येक अक्षर के लिए: `bitVector ^= (1 << (c - 'a'))`।
* अंत में, स्ट्रिंग तब मान्य पैलिंड्रोम क्रमपरिवर्तन होती है जब बिट वेक्टर या तो ० हो या उसमें ठीक एक ही १-बिट सेट हो: `(bitVector & (bitVector - 1)) == 0`।

## प्रोडक्शन कार्यान्वयन

```java
public class PalindromePermutation {
    public static boolean isPermutationOfPalindrome(String phrase) {
        int bitVector = 0;
        for (char c : phrase.toCharArray()) {
            int x = getCharNumber(c);
            if (x >= 0) {
                bitVector ^= (1 << x); // बिट टॉगल करें
            }
        }
        // अधिकतम एक बिट 1 होना चाहिए
        return (bitVector == 0) || ((bitVector & (bitVector - 1)) == 0);
    }

    private static int getCharNumber(char c) {
        int a = Character.getNumericValue('a');
        int z = Character.getNumericValue('z');
        int val = Character.getNumericValue(c);
        if (a <= val && val <= z) return val - a;
        return -1;
    }
}
```

## जटिलता और मेमोरी विश्लेषण

| मापदंड | जटिलता | तकनीकी विवरण |
|---|---|---|
| समय जटिलता | `O(N)` | स्ट्रिंग वर्णों का एकल पास। |
| सहायक मेमोरी | `O(१)` | एकल ३२-बिट पूर्णांक बिट वेक्टर। |

## वास्तविक दुनिया में सिस्टम इंजीनियरिंग उपयोग

### प्रोडक्शन सिस्टम आर्किटेक्चर: जीनोमिक अनुक्रम और डीएनए मोटिफ

जीनोमिक अनुक्रम संरेखण एल्गोरिदम एसआईएमडी बिट पैरिटी मास्क का उपयोग करके डीएनए पैलिंड्रोम की पहचान करते हैं।
