> **टीएल;डीआर**
> * **किताब का सवाल:** `*` या `/` ऑपरेटरों का उपयोग किए बिना दो धनात्मक पूर्णांकों को गुणा करने के लिए एक पुनरावर्ती फ़ंक्शन लिखें। आप जोड़, घटाव और बिट शिफ्टिंग का उपयोग कर सकते हैं, लेकिन संचालन को न्यूनतम रखा जाना चाहिए।
> * **मुख्य समाधान:** **विभाजन और बिट-डबलिंग (Divide-and-Conquer)**: (१) छोटी संख्या $S$ और बड़ी संख्या $B$ पहचानें; (२) $S$ को आधा करें (`S >> 1`) और आधे का उत्पाद पुनरावर्ती रूप से निकालें; (३) यदि $S$ सम है तो `half + half` लौटाएं, यदि विषम है तो `half + half + B` लौटाएं। मध्यवर्ती मान को कैश करके यह **$O(\log S)$ समय** और **$O(\log S)$ स्पेस** में निष्पादित होता है।
> * **रियल-वर्ल्ड सिस्टम:** एएलयू (ALU) हार्डवेयर मल्टीप्लायर सर्किट और बड़े पूर्णांकों की क्रिप्टोग्राफी (RSA)।

## १. किताब का सवाल और संदर्भ

*क्रैकिंग द कोडिंग इंटरव्यू* (समस्या ८.५) में पूछा गया है:

*"बिना * या / ऑपरेटर के न्यूनतम ऑपरेशनों के साथ दो धनात्मक पूर्णांकों को गुणा करने का पुनरावर्ती एल्गोरिदम लिखें।"*

## २. गणितीय आधार

मान लीजिए $S \le B$:
१. $S = 0 \implies 0$
२. $S = 1 \implies B$
३. $H = \lfloor S / 2 \rfloor \times B$ केवल एक बार निकालें।
४. यदि $S$ सम है: $S \times B = H + H$
५. यदि $S$ विषम है: $S \times B = H + H + B$

प्रत्येक चरण में $S$ आधा हो जाता है, जिससे कुल $\lfloor \log_2 S \rfloor$ पुनरावर्ती कॉल होती हैं।

## प्रोडक्शन कार्यान्वयन

```java
public class RecursiveMultiply {
    /**
     * बिना * या / ऑपरेटर के दो धनात्मक पूर्णांकों का गुणा करता है।
     * समय जटिलता: O(log(min(a, b)))
     * स्पेस जटिलता: O(log(min(a, b)))
     */
    public static int minProduct(int a, int b) {
        int bigger = a < b ? b : a;
        int smaller = a < b ? a : b;
        return minProductHelper(smaller, bigger);
    }

    private static int minProductHelper(int smaller, int bigger) {
        if (smaller == 0) return 0;
        if (smaller == 1) return bigger;

        int s = smaller >> 1;
        int halfProd = minProductHelper(s, bigger);

        if (smaller % 2 == 0) {
            return halfProd + halfProd;
        } else {
            return halfProd + halfProd + bigger;
        }
    }
}
```

## जटिलता और मेमोरी विश्लेषण

| मापदंड | जटिलता | तकनीकी विवरण |
|---|---|---|
| समय जटिलता | `O(\log S)` | जहाँ $S = \min(a, b)$। प्रत्येक स्तर पर $S$ आधा होता है। |
| सहायक मेमोरी | `O(\log S)` | $S$ के बिट्स की संख्या ($\le 31$) तक सीमित कॉल स्टैक। |

## वास्तविक दुनिया में सिस्टम इंजीनियरिंग उपयोग

### प्रोडक्शन सिस्टम आर्किटेक्चर: एएलयू मल्टीप्लायर सर्किट

१. **हार्डवेयर बूट गुणा (Booth's Algorithm):** सीपीयू चिप्स आंशिक उत्पादों को जोड़कर और शिफ्ट करके न्यूनतम क्लॉक चक्रों में गुणा करते हैं।
२. **क्रिप्टोग्राफिक बिग-इंटीजर गुणा (RSA):** बड़े पूर्णांकों का विभाजित गुणन।

## सीमा स्थितियां और प्रोडक्शन सुरक्षा

१. **० से गुणा:** तुरंत ० लौटाना।
२. **१ से गुणा:** तुरंत `bigger` लौटाना।
