> **टीएल;डीआर**
> * **किताब का सवाल:** $n$ जोड़े कोष्ठकों के सभी वैध (उचित रूप से खोले और बंद किए गए) संयोजनों को प्रिंट करने के लिए एक एल्गोरिदम लागू करें।
> * **मुख्य समाधान:** **बाउंडेड प्रीफिक्स बैकट्रैकिंग**: (१) शेष खुले कोष्ठक `leftRem` और बंद कोष्ठक `rightRem` की गिनती रखें; (२) यदि `leftRem > 0` है तो `'('` जोड़ें; (३) यदि और केवल यदि `rightRem > leftRem` है तो `')'` जोड़ें; (४) यह ठीक $n$-वां **कैटलन नंबर** $C_n = \frac{1}{n+1}\binom{2n}{n}$ वैध संयोजन उत्पन्न करता है।
> * **रियल-वर्ल्ड सिस्टम:** कंपाइलर एएसटी पार्सर (LLVM / Clang) और जेसन/एक्सएमएल नेस्टिंग सत्यापनकर्ता।

## १. किताब का सवाल और संदर्भ

*क्रैकिंग द कोडिंग इंटरव्यू* (समस्या ८.९) में पूछा गया है:

*"n जोड़े कोष्ठकों के सभी वैध और संतुलित संयोजनों को उत्पन्न करने के लिए एक विधि लिखें।"*

**उदाहरण ($n = 3$):**
`["((()))", "(()())", "(())()", "()(())", "()()()"]`

## २. बाउंडेड प्रीफिक्स बैकट्रैकिंग तर्क

एक कोष्ठक स्ट्रिंग केवल तभी वैध होती है जब:
१. `'('` लगाने के लिए शेष खुले कोष्ठक उपलब्ध हों (`leftRem > 0`)।
२. `')'` लगाने के लिए उपलब्ध बंद कोष्ठक खुले कोष्ठकों से अधिक हों (`rightRem > leftRem`)।

## प्रोडक्शन कार्यान्वयन

```java
import java.util.ArrayList;
import java.util.List;

public class ValidParens {
    /**
     * n जोड़े कोष्ठकों के सभी वैध संयोजनों की गणना करता है।
     * समय जटिलता: O(4^N / sqrt(N))
     * स्पेस जटिलता: O(N)
     */
    public static List<String> generateParens(int count) {
        char[] str = new char[count * 2];
        List<String> list = new ArrayList<>();
        addParen(list, count, count, str, 0);
        return list;
    }

    private static void addParen(List<String> list, int leftRem, int rightRem,
                                 char[] str, int index) {
        if (leftRem < 0 || rightRem < leftRem) return;

        if (leftRem == 0 && rightRem == 0) {
            list.add(String.copyValueOf(str));
        } else {
            if (leftRem > 0) {
                str[index] = '(';
                addParen(list, leftRem - 1, rightRem, str, index + 1);
            }
            if (rightRem > leftRem) {
                str[index] = ')';
                addParen(list, leftRem, rightRem - 1, str, index + 1);
            }
        }
    }
}
```

## जटिलता और मेमोरी विश्लेषण

| मापदंड | जटिलता | तकनीकी विवरण |
|---|---|---|
| समय जटिलता | $O\left(\frac{4^N}{\sqrt{N}}\right)$ | ठीक कैटलन संख्या $C_N = \frac{1}{N+1}\binom{2N}{N}$ स्ट्रिंग्स का निर्माण। |
| सहायक मेमोरी | `O(N)` | $2N$ गहराई तक सीमित कॉल स्टैक और एकल कैरेक्टर बफर। |

## वास्तविक दुनिया में सिस्टम इंजीनियरिंग उपयोग

### प्रोडक्शन सिस्टम आर्किटेक्चर: एएसटी पार्सर

१. **कंपाइलर पार्सर (ANTLR / LLVM Clang):** पुशडाउन ऑटोमेटा द्वारा नेस्टेड स्कोप और कोष्ठकों का सत्यापन।
२. **जेसन / एक्सएमएल डिकोडर:** स्टैक ओवरफ्लो हमलों से बचने के लिए नेस्टिंग सीमा नियंत्रण।

## सीमा स्थितियां और प्रोडक्शन सुरक्षा

१. **$n = 0$:** `[""]` लौटाता है।
२. **$n = 1$:** `["()"]` लौटाता है।
