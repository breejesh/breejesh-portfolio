> **टीएल;डीआर**
> * **किताब का सवाल:** १०० मंजिला इमारत है। यदि कोई अंडा $N$वीं मंजिल या उससे ऊपर से गिरता है, तो वह टूट जाएगा। यदि नीचे से गिरता है, तो नहीं टूटेगा। २ अंडे दिए जाने पर, सबसे खराब स्थिति में न्यूनतम ड्रॉप्स के साथ $N$ खोजें।
> * **मुख्य समाधान:** **घटते अंतराल का संतुलन**: यदि अंडा १ मंजिल $x$ से गिरता है, तो अगला परीक्षण $x + (x - 1)$ पर होगा ताकि सबसे खराब स्थिति स्थिर रहे। $\frac{x(x + 1)}{2} \ge 100 \implies x = 14$ ड्रॉप्स।
> * **रियल-वर्ल्ड सिस्टम:** अडेप्टिव नेटवर्क प्रोबिंग (TCP कंजेशन विंडो थ्रेशोल्ड) और हार्डवेयर स्ट्रेस टेस्टिंग।

## १. किताब का सवाल और संदर्भ

*क्रैकिंग द कोडिंग इंटरव्यू* (समस्या ६.८) में पूछा गया है:

*"१०० मंजिला इमारत में २ अंडों के साथ वह मंजिल खोजें जहां से अंडा टूटता है, जबकि सबसे खराब स्थिति में ड्रॉप्स की संख्या न्यूनतम हो।"*

## २. घटते अंतराल का संतुलन सिद्धांत

यदि अंडा १ समान अंतराल (उदा. हर १०वीं मंजिल) पर गिराया जाए, तो मंजिल ९९ पर टूटने पर अंडा २ को ९१ से ९८ तक ८ बार गिराना पड़ेगा (कुल १९ ड्रॉप्स)।

सबसे खराब स्थिति को संतुलित करने के लिए, अंडा १ के प्रत्येक सफल ड्रॉप के बाद अंतराल को १ कम किया जाता है:
$$x + (x - 1) + (x - 2) + \dots + 1 \ge 100 \implies \frac{x(x + 1)}{2} \ge 100 \implies x = 14$$

अंडा १ गिराने के क्रम: १४, २८, ४१, ५५, ६८, ८०, ९१, १००।

## प्रोडक्शन कार्यान्वयन

```java
public class EggDrop {
    /**
     * N मंजिलों के लिए सबसे खराब स्थिति में न्यूनतम ड्रॉप्स की गणना करता है।
     * समय जटिलता: O(1)
     * स्पेस जटिलता: O(1)
     */
    public static int findOptimalDrops(int totalFloors) {
        // द्विघात समीकरण हल: x^2 + x - 2 * totalFloors = 0
        return (int) Math.ceil((-1.0 + Math.sqrt(1.0 + 8.0 * (double) totalFloors)) / 2.0);
    }
}
```

## जटिलता और मेमोरी विश्लेषण

| मापदंड | जटिलता | तकनीकी विवरण |
|---|---|---|
| अधिकतम ड्रॉप्स | `१४` | १०० मंजिलों के लिए सबसे खराब स्थिति में। |
| समय जटिलता | `O(१)` | बंद-रूप द्विघात समीकरण समाधान। |
| सहायक मेमोरी | `O(१)` | स्थानीय रजिस्टर गणना। |

## वास्तविक दुनिया में सिस्टम इंजीनियरिंग उपयोग

### प्रोडक्शन सिस्टम आर्किटेक्चर: अडेप्टिव नेटवर्क प्रोबिंग

टीसीपी कंजेशन कंट्रोल एल्गोरिदम (TCP BBR / CUBIC) नेटवर्क संतृप्ति बिंदु का पता लगाने के लिए इसी तरह घटते अंतराल प्रोबिंग का उपयोग करते हैं।

## सीमा स्थितियां और प्रोडक्शन सुरक्षा

१. **१ मंजिल की इमारत:** ठीक १ ड्रॉप।
२. **अंडा कभी नहीं टूटता:** मंजिल १०० पर अंतिम ड्रॉप के बाद प्रमाणित।
