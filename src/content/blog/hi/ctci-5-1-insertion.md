> **टीएल;डीआर**
> * **किताब का सवाल:** आपको दो ३२-बिट संख्याएं, $N$ और $M$, और दो बिट स्थितियां, $i$ और $j$ दी गई हैं। $N$ में $M$ को इस प्रकार सम्मिलित करने के लिए एक मेथड लिखें कि $M$, बिट $j$ से शुरू हो और बिट $i$ पर समाप्त हो।
> * **मुख्य समाधान:** **बिटमास्क क्लियरिंग**: (१) $i$ और $j$ के बीच ० वाला मास्क बनाने के लिए `~0 << (j + 1)` और `(1 << i) - 1` का बिटवाइज़ OR करें; (२) `n & mask` द्वारा $N$ में बिट्स $i..j$ को साफ़ करें; (३) $M$ को `m << i` से शिफ्ट करें; (४) `(n & mask) | (m << i)` द्वारा $O(१)$ समय में मर्ज करें।
> * **रियल-वर्ल्ड सिस्टम:** नेटवर्क पैकेट हेडर एनकैप्सुलेशन, हार्डवेयर कंट्रोल रजिस्टर अपडेट और जीपीयू पिक्सेल बिट पैकिंग।

## १. किताब का सवाल और संदर्भ

*क्रैकिंग द कोडिंग इंटरव्यू* (समस्या ५.१) में, दिया गया है:
$N = 10000000000_2$, $M = 10011_2$, $i = 2, j = 6$
अपेक्षित आउटपुट: $N = 10001001100_2$

## २. बिटमास्क क्लियरिंग और मर्जिंग रणनीति

१. **$N$ में $i$ से $j$ तक के बिट्स को साफ़ करना:** $i$ और $j$ के बीच ० और अन्यत्र १ वाला मास्क बनाएं:
   * बायां भाग: `left = (~0) << (j + 1)`
   * दायां भाग: `right = (1 << i) - 1`
   * संयुक्त मास्क: `mask = left | right`
२. **$N$ में बिट्स साफ़ करें:** `n_cleared = N & mask`
३. **$M$ को शिफ्ट और मर्ज करें:** `(m << i) | n_cleared`

## प्रोडक्शन कार्यान्वयन

```java
public class BitInsertion {
    public static int updateBits(int n, int m, int i, int j) {
        // n में i से j तक के बिट्स साफ़ करने के लिए मास्क बनाएं
        int allOnes = ~0; // 11111111...

        // स्थिति j से पहले 1s, फिर 0s
        int left = (j >= 31) ? 0 : (allOnes << (j + 1));

        // स्थिति i के बाद 1s
        int right = ((1 << i) - 1);

        // संयुक्त मास्क
        int mask = left | right;

        // बिट्स साफ़ करें और m को डालें
        int n_cleared = n & mask;
        int m_shifted = m << i;

        return n_cleared | m_shifted;
    }
}
```

## जटिलता और मेमोरी विश्लेषण

| मापदंड | जटिलता | तकनीकी विवरण |
|---|---|---|
| समय जटिलता | `O(१)` | बिटवाइज़ शिफ्ट और मास्किंग निर्देश एकल सीपीयू चक्र में निष्पादित होते हैं। |
| सहायक मेमोरी | `O(१)` | एकल रजिस्टर गणना। |

## वास्तविक दुनिया में सिस्टम इंजीनियरिंग उपयोग

### प्रोडक्शन सिस्टम आर्किटेक्चर: हार्डवेयर रजिस्टर नियंत्रण

ऑपरेटिंग सिस्टम डिवाइस ड्राइवर अन्य फ्लैग्स को अधिलेखित किए बिना लक्षित बिटफील्ड्स को अपडेट करने के लिए हार्डवेयर कंट्रोल रजिस्टरों पर बिटमास्किंग का उपयोग करते हैं।

## सीमा स्थितियां और प्रोडक्शन सुरक्षा

१. $j = 31$ (MSB सीमा): ३२-बिट शिफ्ट ओवरफ्लो से बचने के लिए `j >= 31 ? 0 : ...` द्वारा प्रबंधित।
२. $i = 0$ (LSB सीमा): दायां मास्क ० के बराबर होता है।
