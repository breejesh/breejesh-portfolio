> **टीएल;डीआर**
> * **किताब का सवाल:** एक त्रिभुज के विभिन्न शीर्षों पर तीन चींटियां हैं। यदि वे त्रिभुज की भुजाओं पर यादृच्छिक रूप से किसी भी दिशा में चलना शुरू करती हैं, तो उनके बीच टकराव की क्या संभावना है? इसी तरह, $n$-शीर्ष वाले बहुभुज पर $n$ चींटियों के लिए संभावना ज्ञात करें।
> * **मुख्य समाधान:** **पूरक प्रायिकता (Complementary Probability)**: चींटियां केवल तभी नहीं टकराएंगी जब सभी एक ही दिशा में चलें (सभी दक्षिणावर्त या सभी वामावर्त)। कुल दिशा संयोजन $= 2^n$। बिना टकराव वाले संयोजन $= 2$। बिना टकराव की संभावना $= 2 / 2^n = (1/2)^{n-1}$। अतः, **टकराव की प्रायिकता $P(\text{टकराव}) = 1 - (1/2)^{n-1}$**। त्रिभुज ($n=3$) के लिए, $1 - 1/4 = 3/4 = \mathbf{75\%}$।
> * **रियल-वर्ल्ड सिस्टम:** ईथरनेट साझा माध्यम में CSMA/CD टकराव मॉडल और टोकन रिंग नेटवर्क।

## १. किताब का सवाल और संदर्भ

*क्रैकिंग द कोडिंग इंटरव्यू* (समस्या ६.४) में पूछा गया है:

*"त्रिभुज के कोनों पर ३ चींटियां हैं। यदि वे यादृच्छिक दिशा में चलती हैं तो टकराव की क्या संभावना है? n चींटियों के लिए सामान्यीकृत करें।"*

## २. गणितीय व्युत्पत्ति

१. **कुल संभावित दिशाएं:** प्रत्येक चींटी के पास २ विकल्प होते हैं $\implies 2^n$ संयोजन।
२. **बिना टकराव वाली स्थितियां:**
   * सभी घड़ी की दिशा (दक्षिणावर्त) में: $(1/2)^n$
   * सभी घड़ी की विपरीत दिशा (वामावर्त) में: $(1/2)^n$
   * बिना टकराव की संभावना: $2 \times (1/2)^n = (1/2)^{n-1}$
३. **टकराव की संभावना:**
   $$P(\text{टकराव}) = 1 - \left(\frac{1}{2}\right)^{n-1}$$
४. त्रिभुज ($n=3$) के लिए: $1 - (1/2)^2 = 1 - 0.25 = \mathbf{75\%}$।

## प्रोडक्शन कार्यान्वयन

```java
public class AntsOnPolygon {
    /**
     * बहुभुज पर n चींटियों के टकराव की संभावना की गणना करता है।
     * समय जटिलता: O(1)
     * स्पेस जटिलता: O(1)
     */
    public static double collisionProbability(int n) {
        if (n < 3) {
            throw new IllegalArgumentException("बहुभुज में कम से कम 3 कोने होने चाहिए।");
        }
        return 1.0 - Math.pow(0.5, n - 1);
    }
}
```
