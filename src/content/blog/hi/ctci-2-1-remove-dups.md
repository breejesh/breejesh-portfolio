> **टीएल;डीआर**
> * **किताब का सवाल:** एक अनसॉर्टेड लिंक्ड लिस्ट से डुप्लिकेट तत्वों को हटाने के लिए कोड लिखें। यदि कोई अस्थायी बफर अनुमत नहीं है तो आप इसे कैसे हल करेंगे?
> * **मुख्य समाधान:** (१) बफर के साथ: `HashSet<Integer>` का उपयोग करके $O(N)$ समय और $O(N)$ स्पेस में; (२) बिना बफर के: आगे स्कैन करने वाले रनर पॉइंटर (`runner`) द्वारा $O(N^२)$ समय और $O(१)$ स्पेस में।
> * **रियल-वर्ल्ड सिस्टम:** मेमोरी एलोकेटर फ्री-लिस्ट और डेटाबेस ट्रांजेक्शन जर्नल डी-डुप्लीकेशन।

## १. किताब का सवाल और संदर्भ

*क्रैकिंग द कोडिंग इंटरव्यू* (समस्या २.१) में पूछा गया है:

*"एक अनसॉर्टेड लिंक्ड लिस्ट से डुप्लिकेट हटाने के लिए कोड लिखें। यदि किसी अस्थायी बफर की अनुमति नहीं है तो आप इसे कैसे हल करेंगे?"*

## २. बफर बनाम रनर पॉइंटर तकनीक

१. **हैशसेट समाधान ($O(N)$ समय, $O(N)$ स्पेस):** लिस्ट को एक पॉइंटर से स्कैन करें और देखे गए मानों को `HashSet` में रखें। यदि कोई मान पहले से मौजूद है, तो उसे हटाएं: `prev.next = current.next`।
२. **बिना बफर समाधान ($O(N^२)$ समय, $O(१)$ स्पेस):** प्रत्येक `current` नोड के लिए, एक `runner` पॉइंटर आगे के सभी शेष नोड्स को स्कैन करता है और समान मान वाले नोड को हटा देता है।

## प्रोडक्शन कार्यान्वयन

```java
import java.util.HashSet;

public class RemoveDups {
    public static class LinkedListNode {
        public int data;
        public LinkedListNode next;
        public LinkedListNode(int d) { this.data = d; }
    }

    // समाधान 1: बफर के साथ - O(N) समय, O(N) स्पेस
    public static void deleteDups(LinkedListNode n) {
        HashSet<Integer> set = new HashSet<>();
        LinkedListNode prev = null;
        while (n != null) {
            if (set.contains(n.data)) {
                prev.next = n.next;
            } else {
                set.add(n.data);
                prev = n;
            }
            n = n.next;
        }
    }

    // समाधान 2: बिना बफर के - O(N^2) समय, O(1) स्पेस
    public static void deleteDupsNoBuffer(LinkedListNode head) {
        LinkedListNode current = head;
        while (current != null) {
            LinkedListNode runner = current;
            while (runner.next != null) {
                if (runner.next.data == current.data) {
                    runner.next = runner.next.next; // डुप्लिकेट नोड हटाएं
                } else {
                    runner = runner.next;
                }
            }
            current = current.next;
        }
    }
}
```

## जटिलता और मेमोरी विश्लेषण

| मापदंड | जटिलता | तकनीकी विवरण |
|---|---|---|
| समय जटिलता (बफर के साथ) | `O(N)` | $O(१)$ हैशसेट लुकअप के साथ एकल पास। |
| समय जटिलता (बिना बफर) | `O(N^२)` | नेस्टेड रनर पॉइंटर लूप। |
| स्पेस जटिलता | `O(N) बनाम O(१)` | हैशसेट मेमोरी बनाम इन-प्लेस पॉइंटर्स। |

## वास्तविक दुनिया में सिस्टम इंजीनियरिंग उपयोग

### प्रोडक्शन सिस्टम आर्किटेक्चर: कर्नेल मेमोरी प्रबंधन

कर्नेल स्लैब एलोकेटर मेमोरी कंपैक्शन के दौरान डी-डुप्लिकेशन लागू करते हैं ताकि सर्कुलर रेफरेंसिंग से बचा जा सके।

## सीमा स्थितियां और प्रोडक्शन सुरक्षा

१. सभी समान मानों वाली लिस्ट (`१->१->१`): एकल नोड बचता है।
२. खाली लिस्ट या १ नोड: $O(१)$ में बिना बदलाव के समाप्त।
