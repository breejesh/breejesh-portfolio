> **टीएल;डीआर**
> * **किताब का सवाल:** ० और १ के बीच एक वास्तविक संख्या (उदा. ०.७२) दिए जाने पर, इसका बाइनरी प्रतिनिधित्व प्रिंट करें। यदि संख्या को अधिकतम ३२ वर्णों में सटीक रूप से प्रदर्शित नहीं किया जा सकता है, तो "ERROR" प्रिंट करें।
> * **मुख्य समाधान:** **२ से बार-बार गुणा**: बाइनरी में किसी भिन्न को २ से गुणा करने पर भिन्नात्मक बाइनरी अंक एक स्थान बाईं ओर खिसक जाते हैं। यदि गुणनफल $r = num \times 2 \ge 1$ है, तो अगला बिट `1` है (और $r$ से १ घटाएं); अन्यथा अगला बिट `0` है। यदि स्ट्रिंग ३२ वर्णों से अधिक हो जाती है, तो "ERROR" लौटाएं ($O(१)$ समय और $O(१)$ स्पेस)।
> * **रियल-वर्ल्ड सिस्टम:** आईईईई ७५४ (IEEE 754) फ्लोटिंग पॉइंट एनकोडिंग और वित्तीय गणनाओं में फिक्स्ड-पॉइंट नंबर।

## १. किताब का सवाल और संदर्भ

*क्रैकिंग द कोडिंग इंटरव्यू* (समस्या ५.२) में पूछा गया है:

*"० और १ के बीच एक वास्तविक संख्या को बाइनरी में बदलें। यदि इसे ३२ वर्णों के भीतर सटीक रूप से नहीं दर्शाया जा सकता, तो 'ERROR' प्रिंट करें।"*

**गणितीय आधार:**
किसी भी संख्या $x \in (0, 1)$ को बाइनरी में इस प्रकार लिखा जाता है:
$$x = \sum_{i=1}^{\infty} b_i \cdot 2^{-i} = b_1 \cdot 2^{-1} + b_2 \cdot 2^{-2} + b_3 \cdot 2^{-3} + \dots$$
२ से गुणा करने पर $2x = b_1 + b_2 \cdot 2^{-1} + \dots$ मिलता है, जहाँ पूर्णांक भाग ही पहला बाइनरी बिट $b_1$ होता है।

## २. एल्गोरिदम कार्यप्रणाली

१. सत्यापित करें कि $0 < num < 1$।
२. `StringBuilder binary = new StringBuilder(".")` शुरू करें।
३. जब तक `num > 0`:
   * यदि `binary.length() >= 32`, तो `"ERROR"` लौटाएं।
   * `r = num * 2` की गणना करें।
   * यदि $r \ge 1$: `'1'` जोड़ें और `num = r - 1` सेट करें।
   * अन्यथा: `'0'` जोड़ें और `num = r` सेट करें।
४. `binary.toString()` लौटाएं।

## प्रोडक्शन कार्यान्वयन

```java
public class BinaryToString {
    /**
     * (0, 1) में वास्तविक संख्या को बाइनरी स्ट्रिंग में बदलता है।
     * समय जटिलता: O(1) [अधिकतम 32 पुनरावृत्तियां]
     * स्पेस जटिलता: O(1)
     */
    public static String printBinary(double num) {
        if (num >= 1 || num <= 0) {
            return "ERROR";
        }

        StringBuilder binary = new StringBuilder();
        binary.append(".");

        while (num > 0) {
            // अधिकतम 32 वर्णों की सीमा
            if (binary.length() >= 32) {
                return "ERROR";
            }

            double r = num * 2;
            if (r >= 1) {
                binary.append(1);
                num = r - 1;
            } else {
                binary.append(0);
                num = r;
            }
        }

        return binary.toString();
    }
}
```

## जटिलता और मेमोरी विश्लेषण

| मापदंड | जटिलता | तकनीकी विवरण |
|---|---|---|
| समय जटिलता | `O(१)` | लूप अधिकतम ३२ बार चलता है। |
| सहायक मेमोरी | `O(१)` | अधिकतम ३२ वर्णों का स्ट्रिंग बफर। |

## वास्तविक दुनिया में सिस्टम इंजीनियरिंग उपयोग

### प्रोडक्शन सिस्टम आर्किटेक्चर: फ्लोटिंग पॉइंट परिशुद्धता

१. **बाइनरी में आवर्ती दशमलव:** $0.1_{10}$ जैसी सामान्य दशमलव संख्याएं बाइनरी में अनंत आवर्ती होती हैं ($0.000110011..._2$)। वित्तीय प्रणालियां राउंडिंग त्रुटियों से बचने के लिए फिक्स्ड-पॉइंट या `BigDecimal` का उपयोग करती हैं।
२. **जीपीयू शेडर्स:** रंगों को $[0, 255]$ से $[0.0, 1.0]$ फ्लोट में सामान्यीकृत करना।

## सीमा स्थितियां और प्रोडक्शन सुरक्षा

१. **२ की सटीक घातें ($0.5 \to .1$, $0.75 \to .11$):** तुरंत समाप्त होती हैं।
२. **अपरिमित संख्याएं ($0.1, 0.72$):** ३२ वर्णों की सीमा पार होते ही `"ERROR"` लौटाती हैं।
