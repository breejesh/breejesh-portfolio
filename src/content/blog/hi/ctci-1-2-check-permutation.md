> **टीएल;डीआर**
> * **किताब की समस्या:** दो स्ट्रिंग्स दिए जाने पर जांचें कि क्या एक दूसरी का क्रमपरिवर्तन (Anagram/Permutation) है।
> * **समाधान:** कैरेक्टर फ्रीक्वेंसी एरे: पहली स्ट्रिंग के अक्षरों की गिनती बढ़ाना और दूसरी के अक्षरों की गिनती घटाना। यदि कोई गिनती शून्य से नीचे जाए तो `false`।
> * **रियल-वर्ल्ड सिस्टम:** सर्च इंजन में एनाग्राम सर्च और क्रिप्टोग्राफी में फ्रीक्वेंसी एनालिसिस।

## १. किताब का सवाल और संदर्भ

सीटीसीआई १.२ में दो स्ट्रिंग्स के समान अक्षरों और समान बारंबारता की जांच की जाती है।

## २. फ्रीक्वेंसी काउंटिंग विधि

सॉर्टिंग के $O(N \log N)$ समय के बजाय $O(N)$ समय में १२८ साइज के एरे से अक्षरों का मिलान करना।

## प्रोडक्शन कार्यान्वयन

```java
// फ्रीक्वेंसी एरे समाधान
public static boolean permutation(String s, String t) {
    if (s.length() != t.length()) return false;
    int[] letters = new int[128];
    for (int i = 0; i < s.length(); i++) letters[s.charAt(i)]++;
    for (int i = 0; i < t.length(); i++) {
        if (--letters[t.charAt(i)] < 0) return false;
    }
    return true;
}
```

## जटिलता और मेमोरी विश्लेषण

| मापदंड | जटिलता | तकनीकी विवरण |
|---|---|---|
| समय | `O(N)` | एकल लीनियर पास। |
| मेमोरी | `O(१)` | १२८ साइज का एरे। |

## वास्तविक दुनिया में सिस्टम इंजीनियरिंग उपयोग

### वास्तविक दुनिया में उपयोग: सर्च इंजन क्वेरी सामान्यीकरण

सर्च इंजन शब्दों के क्रम बदलने पर भी सही परिणाम देने के लिए इसी बैग-ऑफ-वर्ड्स फ्रीक्वेंसी का उपयोग करते हैं।

## सीमा स्थितियां और प्रोडक्शन सुरक्षा

१. अलग-अलग लंबाई वाली स्ट्रिंग्स में तुरंत `false`।
