> **टीएल;डीआर**
> * **किताब का सवाल:** अद्वितीय वर्णों की स्ट्रिंग के सभी क्रमपरिवर्तनों (Permutations) की गणना करने के लिए एक विधि लिखें।
> * **मुख्य समाधान:** **उपस्ट्रिंग सम्मिलन पुनरावृत्ति**: (१) आधार स्थिति: `""` के लिए `[""]`; (२) पहला वर्ण $c = S[0]$ अलग करें और शेष उपस्ट्रिंग के सभी $(N - 1)!$ क्रमपरिवर्तनों की पुनरावर्ती गणना करें; (३) प्रत्येक उप-क्रमपरिवर्तन में $c$ को सभी स्लॉट इंडेक्स $0 \dots |word|$ पर डालें; (४) कुल $N!$ परिणाम इष्टतम **$O(N! \cdot N)$ समय** और **$O(N! \cdot N)$ मेमोरी** में उत्पन्न होते हैं।
> * **रियल-वर्ल्ड सिस्टम:** क्रिप्टोग्राफ़िक पासवर्ड वर्डलिस्ट जनरेटर और संयोजन परीक्षण सूट।

## १. किताब का सवाल और संदर्भ

*क्रैकिंग द कोडिंग इंटरव्यू* (समस्या ८.७) में पूछा गया है:

*"अद्वितीय वर्णों वाली स्ट्रिंग के सभी संभावित क्रमपरिवर्तनों की गणना करने के लिए एक एल्गोरिदम लिखें।"*

## २. पुनरावर्ती सम्मिलन एल्गोरिदम

स्ट्रिंग $S = \text{"abc"}$ के लिए:
१. `"c"` का क्रमपरिवर्तन: `["c"]`।
२. `"c"` में `'b'` सम्मिलित करें: `["bc", "cb"]`।
३. `'a'` को `"bc"` और `"cb"` के प्रत्येक स्लॉट में डालें:
   * `"bc"` से $\to$ `"abc"`, `"bac"`, `"bca"`।
   * `"cb"` से $\to$ `"acb"`, `"cab"`, `"cba"`।
   * कुल $= 3! = 6$ क्रमपरिवर्तन।

## प्रोडक्शन कार्यान्वयन

```java
import java.util.ArrayList;
import java.util.List;

public class PermutationsWithoutDups {
    /**
     * अद्वितीय वर्णों के सभी क्रमपरिवर्तनों की गणना करता है।
     * समय जटिलता: O(N! * N)
     * स्पेस जटिलता: O(N! * N)
     */
    public static List<String> getPerms(String str) {
        if (str == null) return null;
        List<String> permutations = new ArrayList<>();

        if (str.length() == 0) {
            permutations.add("");
            return permutations;
        }

        char first = str.charAt(0);
        String remainder = str.substring(1);
        List<String> words = getPerms(remainder);

        for (String word : words) {
            for (int j = 0; j <= word.length(); j++) {
                String s = insertCharAt(word, first, j);
                permutations.add(s);
            }
        }

        return permutations;
    }

    private static String insertCharAt(String word, char c, int i) {
        String start = word.substring(0, i);
        String end = word.substring(i);
        return start + c + end;
    }
}
```

## जटिलता और मेमोरी विश्लेषण

| मापदंड | जटिलता | तकनीकी विवरण |
|---|---|---|
| समय जटिलता | `O(N! * N)` | $N!$ स्ट्रिंग्स उत्पन्न करता है, प्रत्येक में $O(N)$ कॉपी समय। |
| सहायक मेमोरी | `O(N! * N)` | हीप में सभी क्रमपरिवर्तनों का संग्रहण। |

## वास्तविक दुनिया में सिस्टम इंजीनियरिंग उपयोग

### प्रोडक्शन सिस्टम आर्किटेक्चर: संयोजन परीक्षण

१. **ऑर्थोगोनल ऐरे टेस्टिंग:** सभी संभावित कॉन्फ़िगरेशन संयोजनों को सत्यापित करने के लिए क्रमपरिवर्तन निर्माण।
२. **क्रिप्टोग्राफिक डिक्शनरी जनरेशन:** पासवर्ड क्रैकिंग टूल्स में जीपीयू-त्वरित क्रमपरिवर्तन।

## सीमा स्थितियां और प्रोडक्शन सुरक्षा

१. **रिक्त स्ट्रिंग:** `[""]` लौटाना।
२. **१ वर्ण वाली स्ट्रिंग:** `["a"]` लौटाना।
