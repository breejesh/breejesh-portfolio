> **टीएल;डीआर**
> * **किताब का सवाल:** आप एक पेन का परीक्षण कैसे करेंगे?
> * **मुख्य समाधान:** **५-चरणीय उत्पाद QA मैट्रिक्स**: (१) **उपयोगकर्ता और आवश्यकताएं**: लक्षित उपयोगकर्ता (छात्र, कलाकार, अंतरिक्ष यात्री, डॉक्टर) और स्याही प्रकार (जेल, बॉलपॉइंट, फाउंटेन, स्पेस पेन); (२) **कार्यात्मक सत्यापन**: स्याही का निरंतर प्रवाह, विभिन्न सतहों पर लिखना (कागज, कार्डबोर्ड, कपड़ा), कोई रुकावट न होना और तुरंत सूखना; (३) **पर्यावरणीय तनाव परीक्षण**: अत्यधिक तापमान ($-20^\circ\text{C}$ से $+60^\circ\text{C}$), ऊंचाई/विमान दबाव परिवर्तन (स्याही रिसाव से बचाव) और आर्द्रता; (४) **स्थायित्व और ड्रॉप टेस्ट**: कंक्रीट पर २ मीटर से गिरना, क्लिप का लचीलापन और क्लिक तंत्र का जीवनकाल (५०,००० क्लिक); (५) **सुरक्षा और मानक**: गैर-विषाक्त स्याही (ASTM D-4236) और बच्चों की सुरक्षा के लिए हवादार ढक्कन (ISO 11540)।
> * **रियल-वर्ल्ड सिस्टम:** विनिर्माण उद्योग में हार्डवेयर QA परीक्षण (Bic, Apple Pencil)।

## १. किताब का सवाल और संदर्भ

*क्रैकिंग द कोडिंग इंटरव्यू* (समस्या ११.५) में पूछा गया है:

*"एक पेन के कार्यात्मक, शारीरिक, पर्यावरणीय और सुरक्षा पहलुओं का मूल्यांकन करने के लिए संपूर्ण परीक्षण रणनीति तैयार करें।"*

## २. परीक्षण मैट्रिक्स

| श्रेणी | परीक्षण मामला | उत्तीर्ण मानदंड |
|---|---|---|
| **मुख्य कार्यक्षमता** | स्वचालित पहिये पर निरंतर लिखना | बिना रुके न्यूनतम २,००० मीटर निरंतर रेखा। |
| **सतह अनुकूलन** | विभिन्न प्रकार के कागज, कार्डबोर्ड, रसीदें | स्याही का समान रूप से चिपकना। |
| **ऊंचाई / दबाव** | वैक्यूम चैंबर में दबाव कम करना ($0.5\text{ atm}$) | निब के आसपास शून्य स्याही रिसाव। |
| **ड्रॉप प्रतिरोध** | कंक्रीट पर २ मीटर ऊंचाई से गिरना | निब का जाम न होना; आवरण का अक्षुण्ण रहना। |
| **बाल सुरक्षा** | पेन कैप से वायु प्रवाह (ISO 11540) | $१.३३\text{ kPa}$ पर $८\text{ लीटर/मिनट}$ से अधिक वायु प्रवाह। |

## प्रोडक्शन ऑटोमेटेड टेस्ट हार्नेस

```java
public class ProductTestingFramework {
    public interface SensorTelemetry {
        double readInkFlowRate();
        double readTipPressureGrams();
        boolean hasSkippingDetected();
    }

    public static class AutomatedWritingTest {
        private static final double MIN_WRITING_DISTANCE_METERS = 2000.0;

        public static boolean evaluatePenQuality(SensorTelemetry robot, double currentMetersDrawn) {
            if (currentMetersDrawn < MIN_WRITING_DISTANCE_METERS) {
                return false;
            }

            double inkRate = robot.readInkFlowRate();
            if (inkRate <= 0.0 || robot.hasSkippingDetected()) {
                return false;
            }

            return true;
        }
    }
}
```

## वास्तविक दुनिया में सिस्टम इंजीनियरिंग उपयोग

### प्रोडक्शन सिस्टम आर्किटेक्चर: त्वरित जीवन परीक्षण (ALT)

१. **FMEA विफलता विश्लेषण:** संभावित यांत्रिक विफलताओं (स्याही सूखना, स्प्रिंग टूटना) का व्यवस्थित मूल्यांकन।
२. **थर्मल शॉक चैंबर:** तापमान चक्रों द्वारा ३ साल के जीवनकाल का १४ दिनों में अनुकरण।

## सीमा स्थितियां और प्रोडक्शन सुरक्षा

१. **बिना ढक्कन के खुला रहना:** ७२ घंटे खुला रहने के बाद ३ स्ट्रोक में लिखना शुरू करना।
२. **रासायनिक सुरक्षा:** गैर-विषैले मानकों (EN 71-3) का पूर्ण अनुपालन।
