> **टीएल;डीआर**
> * **किताब का सवाल:** आपके पास एक पूर्णांक है और आप ठीक एक बिट को ० से १ में बदल सकते हैं। १ की सबसे लंबी निरंतर श्रृंखला की लंबाई खोजने के लिए कोड लिखें।
> * **मुख्य समाधान:** **एकल पास रन-लेंथ ट्रैकिंग**: दो काउंटर रखें, `currentLength` और `previousLength`। जब ० मिले, यदि अगला बिट १ है, तो `previousLength = currentLength`; यदि अगला बिट ० है, तो `previousLength = 0`। प्रत्येक चरण पर $\text{maxLength} = \max(\text{maxLength}, \text{previousLength} + \text{currentLength} + 1)$ अपडेट करें ($O(b)$ समय और $O(१)$ स्पेस)।
> * **रियल-वर्ल्ड सिस्टम:** ऑपरेटिंग सिस्टम मेमोरी पेज एलोकेशन बिटमैप्स और डेटा कम्प्रेशन (RLE)।

## १. किताब का सवाल और संदर्भ

*क्रैकिंग द कोडिंग इंटरव्यू* (समस्या ५.३) में पूछा गया है:

*"आपके पास एक पूर्णांक है और आप ठीक एक बिट को ० से १ में बदल सकते हैं। १ की सबसे लंबी श्रृंखला की लंबाई ज्ञात करें।"*

**उदाहरण:**
* इनपुट: `1775` (बाइनरी `11011101111_2`)
* आउटपुट: `8` (इंडेक्स ४ पर ० को १ में बदलने पर)।

## २. एल्गोरिदम कार्यप्रणाली

१. `currentLength = 0`, `previousLength = 0`, `maxLength = 1` शुरू करें।
२. सबसे दाहिने बिट (`a & 1`) की जांच करें:
   * यदि `1` है: `currentLength++`।
   * यदि `0` है:
     * यदि अगला बिट (`a & 2`) भी ० है, तो `previousLength = 0`।
     * अन्यथा, `previousLength = currentLength`।
     * `currentLength = 0`।
३. `maxLength = Math.max(previousLength + currentLength + 1, maxLength)` को अपडेट करें।
४. `a >>>= 1` से दाईं ओर शिफ्ट करें।

## प्रोडक्शन कार्यान्वयन

```java
public class FlipBitToWin {
    /**
     * एक बिट फ्लिप के साथ 1s की अधिकतम श्रृंखला खोजता है।
     * समय जटिलता: O(b) जहां b बिट्स की संख्या है (int के लिए <= 32)।
     * स्पेस जटिलता: O(1)
     */
    public static int flipBit(int a) {
        if (~a == 0) return Integer.BYTES * 8;

        int currentLength = 0;
        int previousLength = 0;
        int maxLength = 1;

        while (a != 0) {
            if ((a & 1) == 1) {
                currentLength++;
            } else if ((a & 1) == 0) {
                previousLength = ((a & 2) == 0) ? 0 : currentLength;
                currentLength = 0;
            }
            maxLength = Math.max(previousLength + currentLength + 1, maxLength);
            a >>>= 1;
        }

        return maxLength;
    }
}
```

## जटिलता और मेमोरी विश्लेषण

| मापदंड | जटिलता | तकनीकी विवरण |
|---|---|---|
| समय जटिलता | `O(b)` | बिटवाइज़ ऑपरेशनों द्वारा अधिकतम ३२ बिट्स की जांच। |
| सहायक मेमोरी | `O(१)` | केवल तीन पूर्णांक चरों का उपयोग। |

## वास्तविक दुनिया में सिस्टम इंजीनियरिंग उपयोग

### प्रोडक्शन सिस्टम आर्किटेक्चर: ओएस पेज एलोकेशन

१. **मेमोरी पेज फ्रेम एलोकेटर:** कर्नेल उपलब्ध मेमोरी पृष्ठों के सबसे लंबे निरंतर ब्लॉक को खोजने के लिए बिटमैप स्कैन करता है।
२. **डेटा कम्प्रेशन (Snappy / LZ4):** दोहराए जाने वाले बिट पैटर्न की कुशल पहचान।

## सीमा स्थितियां और प्रोडक्शन सुरक्षा

१. **सभी १s (`-1` / `0xFFFFFFFF`):** ३२ लौटाता है।
२. **सभी ०s (`0`):** १ लौटाता है।
