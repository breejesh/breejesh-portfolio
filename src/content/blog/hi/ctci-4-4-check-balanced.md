> **टीएल;डीआर**
> * **किताब का सवाल:** एक बाइनरी ट्री संतुलित है या नहीं, यह जांचने के लिए एक फ़ंक्शन लागू करें। एक संतुलित पेड़ वह होता है जिसमें किसी भी नोड के दो सबट्री की ऊंचाई कभी भी १ से अधिक भिन्न नहीं होती।
> * **मुख्य समाधान:** **बॉटम-अप पोस्ट-ऑर्डर शॉर्ट-सर्किटिंग**: पत्तियों से ऊपर की ओर ऊंचाई की गणना करें। यदि कोई सबट्री असंतुलित है ($|h_{बायां} - h_{दायां}| > 1$), तो तुरंत एक त्रुटि कोड (`Integer.MIN_VALUE`) लौटाकर निष्पादन रोकें ($O(N)$ समय और $O(H)$ स्टैक स्पेस)।
> * **रियल-वर्ल्ड सिस्टम:** एवीएल (AVL) और रेड-ब्लैक ट्री संरचनाओं का स्वास्थ्य परीक्षण।

## १. किताब का सवाल और संदर्भ

*क्रैकिंग द कोडिंग इंटरव्यू* (समस्या ४.४) में पूछा गया है:

*"यह जांचने के लिए एक फ़ंक्शन लागू करें कि क्या कोई बाइनरी ट्री संतुलित है।"*

## २. ऊपर-से-नीचे जांच की विफलता

रूट से प्रत्येक नोड पर बार-बार `getHeight` कॉल करने से नीचे के नोड्स बार-बार गिने जाते हैं:
* संतुलित पेड़ के लिए इसमें $O(N \log N)$ और रैखिक पेड़ के लिए $O(N^2)$ समय लगता है।

## ३. इष्टतम बॉटम-अप पोस्ट-ऑर्डर विधि

हम ऊंचाई और संतुलन दोनों की जांच एक ही पास में करते हैं:
१. `checkHeight(node)` संतुलित होने पर वास्तविक ऊंचाई लौटाता है।
२. यदि $|h_{बायां} - h_{दायां}| > 1$, या किसी बच्चे ने पहले ही त्रुटि लौटाई है, तो तुरंत `Integer.MIN_VALUE` लौटाएं।
३. यदि संतुलित है, तो $\max(h_{बायां}, h_{दायां}) + 1$ लौटाएं।

## प्रोडक्शन कार्यान्वयन

```java
public class CheckBalanced {
    public static class TreeNode {
        public int val;
        public TreeNode left;
        public TreeNode right;
        public TreeNode(int x) { this.val = x; }
    }

    /**
     * जांचता है कि क्या बाइनरी ट्री ऊंचाई-संतुलित है।
     * समय जटिलता: O(N)
     * स्पेस जटिलता: O(H) जहां H पेड़ की ऊंचाई है।
     */
    public static boolean isBalanced(TreeNode root) {
        return checkHeight(root) != Integer.MIN_VALUE;
    }

    private static int checkHeight(TreeNode root) {
        if (root == null) return -1; // null की ऊंचाई -1

        int leftHeight = checkHeight(root.left);
        if (leftHeight == Integer.MIN_VALUE) return Integer.MIN_VALUE;

        int rightHeight = checkHeight(root.right);
        if (rightHeight == Integer.MIN_VALUE) return Integer.MIN_VALUE;

        int heightDiff = Math.abs(leftHeight - rightHeight);
        if (heightDiff > 1) {
            return Integer.MIN_VALUE; // त्रुटि मिली -> ऊपर भेजें
        } else {
            return Math.max(leftHeight, rightHeight) + 1;
        }
    }
}
```

## जटिलता और मेमोरी विश्लेषण

| मापदंड | जटिलता | तकनीकी विवरण |
|---|---|---|
| समय जटिलता | `O(N)` | प्रत्येक नोड अधिकतम एक बार देखा जाता है; असंतुलन पर तुरंत रुकता है। |
| सहायक मेमोरी | `O(H)` | पेड़ की ऊंचाई $H$ के बराबर स्टैक मेमोरी ($O(\log N)$ औसत)। |

## वास्तविक दुनिया में सिस्टम इंजीनियरिंग उपयोग

### प्रोडक्शन सिस्टम आर्किटेक्चर: संतुलन इनवेरिएंट ऑडिट

१. **मेमोरी डेटाबेस और एलएसएम ट्री (RocksDB):** संतुलित पेड़ बनाए रखने के लिए समय-समय पर नोड ऊंचाइयों का ऑडिट।
२. **गेम इंजन में कोलिजन ट्री:** बाउंडिंग वॉल्यूम पदानुक्रम को संतुलित रखना।

## सीमा स्थितियां और प्रोडक्शन सुरक्षा

१. **खाली पेड़:** `true` लौटाता है (ऊंचाई $-1$)।
२. **गहराई में असंतुलन:** त्रुटि कोड तुरंत शेष सबट्री के निष्पादन को रोक देता है।
