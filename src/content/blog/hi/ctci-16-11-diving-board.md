> **टीएल;डीआर**
> * **किताब का सवाल:** आप लकड़ी के तख्तों को जोड़कर एक डाइविंग बोर्ड बना रहे हैं। दो प्रकार के तख्ते हैं: छोटे ($s$) और लंबे ($l$)। आपको ठीक $K$ तख्तों का उपयोग करना होगा। डाइविंग बोर्ड के लिए सभी संभावित लंबाइयों को उत्पन्न करने के लिए एक विधि लिखें।
> * **गणितीय सफलता:** **क्लोज्ड-फॉर्म लीनियर इटरेशन**:
>   1. कोई भी मान्य संयोजन $i$ छोटे तख्तों और $(K - i)$ लंबे तख्तों से बना होता है ($0 \le i \le K$)।
>   2. कुल लंबाई का सूत्र है:
>      $$\text{लंबाई}(i) = i \times s + (K - i) \times l$$
>   3. यदि $s == l$, तो केवल $१$ अद्वितीय लंबाई होती है ($K \times s$)।
>   4. यदि $s \ne l$, तो $i$ को $०$ से $K$ तक चलाने पर ठीक **$K + 1$ अद्वितीय लंबाइयाँ** प्राप्त होती हैं।
>   5. यह **$O(K)$ समय** और **$O(K)$ स्पेस** में चलता है।
> * **रियल-वर्ल्ड सिस्टम:** मेमोरी एलोकेटर (jemalloc) में ब्लॉक साइजिंग।

## १. किताब का सवाल और संदर्भ

*क्रैकिंग द कोडिंग इंटरव्यू* (समस्या १६.११) में पूछा गया है:

*"K छोटे और लंबे तख्तों से बनने वाले डाइविंग बोर्ड की सभी संभावित अनूठी लंबाइयों की सूची बनाएं।"*

## २. ठीक $K + 1$ मान क्यों होते हैं?

चूँकि जोड़ क्रमविनिमेय (Commutative) है, तख्तों का क्रम कुल लंबाई को प्रभावित नहीं करता; केवल छोटे तख्तों की संख्या $i \in [०, K]$ लंबाई निर्धारित करती है।

## प्रोडक्शन कार्यान्वयन

```java
public class DivingBoard {

    public static int[] allLengths(int k, int shorter, int longer) {
        if (k <= 0) return new int[0];
        if (shorter == longer) return new int[] { k * shorter };

        int[] lengths = new int[k + 1];

        for (int i = 0; i <= k; i++) {
            int nShorter = i;
            int nLonger = k - i;
            lengths[i] = nShorter * shorter + nLonger * longer;
        }

        return lengths;
    }
}
```

## जटिलता विश्लेषण

| दृष्टिकोण | समय जटिलता | सहायक स्पेस | ओवरहेड |
|---|---|---|---|
| **क्लोज्ड-फॉर्म सूत्र** | **$O(K)$** | **$O(K)$** | **कोई नहीं (शुद्ध गणित)** |
| **मेमोइज़्ड रिकर्शन** | $O(K^2)$ | $O(K^2)$ | HashSet + रिकर्शन स्टैक |

## वास्तविक दुनिया में सिस्टम इंजीनियरिंग उपयोग

### प्रोडक्शन सिस्टम आर्किटेक्चर: मेमोरी ब्लॉक साइजिंग

१. **मेमोरी क्लास साइजिंग:** jemalloc और TCMalloc जैसे मेमोरी एलोकेटर त्वरित आवंटन के लिए गणितीय सूत्रों द्वारा मेमोरी बकेट का आकार निर्धारित करते हैं।

## सीमा स्थितियां और प्रोडक्शन सुरक्षा

१. **$K \le 0$:** खाली सरणी लौटाना।
२. **समान आकार के तख्ते ($s = l$):** १ तत्व वाली सरणी ($K \times s$) लौटाना।
