> **टीएल;डीआर**
> * **किताब का सवाल:** आपके पास ५-क्वार्ट का जग, ३-क्वार्ट का जग और असीमित पानी की आपूर्ति है (कोई माप चिह्न नहीं)। आप ठीक ४ क्वार्ट पानी कैसे प्राप्त करेंगे?
> * **मुख्य समाधान:** **यूक्लिडियन जल-स्थानांतरण अनुक्रम**: (१) ५-क्वार्ट का जग पूरा भरें; (२) ५-क्वार्ट से ३-क्वार्ट वाले जग में भरें (५-क्वार्ट में २ क्वार्ट बचेगा); (३) ३-क्वार्ट जग खाली करें; (४) २ क्वार्ट को ३-क्वार्ट वाले जग में डालें; (५) ५-क्वार्ट जग फिर से भरें; (६) ५-क्वार्ट से ३-क्वार्ट जग में तब तक डालें जब तक वह भर न जाए (ठीक १ क्वार्ट जाएगा), जिससे ५-क्वार्ट जग में ठीक **४ क्वार्ट** पानी बच जाएगा।
> * **रियल-वर्ल्ड सिस्टम:** टोकन बकेट एल्गोरिदम और बेज़ाउट पहचान (Bézout's Identity)।

## १. किताब का सवाल और संदर्भ

*क्रैकिंग द कोडिंग इंटरव्यू* (समस्या ६.५) में पूछा गया है:

*"५-क्वार्ट और ३-क्वार्ट के दो बिना माप वाले जगों से ठीक ४ क्वार्ट पानी कैसे मापेंगे?"*

## २. गणितीय आधार: बेज़ाउट की पहचान (Bézout's Identity)

रैखिक डायोफैंटाइन समीकरणों के अनुसार:
$$a \cdot x + b \cdot y = d$$
लक्ष्य $d$ को $a$ और $b$ जगों से केवल तभी मापा जा सकता है जब $d$, $\gcd(a, b)$ का गुणज हो और $d \le \max(a, b)$ हो।
* $\gcd(5, 3) = 1$ होने के कारण ४ मापना निश्चित रूप से संभव है:
$$5(2) + 3(-2) = 10 - 6 = 4$$

## ३. चरण-दर-चरण स्थिति तालिका

| चरण | क्रिया | ५-क्वार्ट जग | ३-क्वार्ट जग | विवरण |
|---|---|---|---|---|
| ० | प्रारंभिक स्थिति | ० qt | ० qt | दोनों खाली |
| १ | ५-क्वार्ट भरें | ५ qt | ० qt | पूरा भरा |
| २ | ५ $\to$ ३ में डालें | २ qt | ३ qt | ३ qt गया, २ qt बचा |
| ३ | ३-क्वार्ट खाली करें | २ qt | ० qt | खाली किया |
| ४ | २ qt को ३ में डालें | ० qt | २ qt | २ qt स्थानांतरित |
| ५ | ५-क्वार्ट भरें | ५ qt | २ qt | पूरा भरा |
| ६ | ५ $\to$ ३ में डालें | **४ qt** | ३ qt | १ qt गया, **४ qt** बचा |

## प्रोडक्शन कार्यान्वयन

```java
import java.util.ArrayList;
import java.util.List;

public class JugsOfWater {
    public static class State {
        public final int jug5;
        public final int jug3;
        public final String action;

        public State(int j5, int j3, String action) {
            this.jug5 = j5;
            this.jug3 = j3;
            this.action = action;
        }
    }

    public static List<State> measureFourQuarts() {
        List<State> steps = new ArrayList<>();
        steps.add(new State(0, 0, "प्रारंभिक खाली स्थिति"));
        steps.add(new State(5, 0, "5-क्वार्ट जग भरें"));
        steps.add(new State(2, 3, "5 से 3 में डालें"));
        steps.add(new State(2, 0, "3-क्वार्ट जग खाली करें"));
        steps.add(new State(0, 2, "2 क्वार्ट को 3-क्वार्ट जग में डालें"));
        steps.add(new State(5, 2, "5-क्वार्ट जग पूरा भरें"));
        steps.add(new State(4, 3, "3 को भरने तक डालें (4 क्वार्ट बचता है)"));
        return steps;
    }
}
```
