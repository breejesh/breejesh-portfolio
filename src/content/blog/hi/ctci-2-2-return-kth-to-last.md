> **टीएल;डीआर**
> * **किताब का सवाल:** सिंगली लिंक्ड लिस्ट का अंत से $k$-वां नोड खोजने के लिए एक एल्गोरिदम लागू करें।
> * **मुख्य समाधान:** $k$ नोड्स की दूरी पर दो पॉइंटर्स: पहले पॉइंटर को $k$ कदम आगे बढ़ाएं। फिर दोनों पॉइंटर्स को एक साथ आगे बढ़ाएं जब तक कि पहला पॉइंटर `null` पर न पहुंचे। दूसरा पॉइंटर अंत से ठीक $k$-वें नोड पर होगा ($O(N)$ समय और $O(१)$ स्पेस)।
> * **रियल-वर्ल्ड सिस्टम:** स्ट्रीमिंग टेलीमेट्री में स्लाइडिंग विंडो ऑफसेट और नेटवर्क बफर प्लेबैक।

## १. किताब का सवाल और संदर्भ

*क्रैकिंग द कोडिंग इंटरव्यू* (समस्या २.२) में पूछा गया है:

*"सिंगली लिंक्ड लिस्ट का अंत से k-वां तत्व खोजने के लिए एक एल्गोरिदम लागू करें।"*

नोट: $k=१$ अंतिम नोड (टेल) को दर्शाता है, $k=२$ अंत से दूसरे नोड को, इत्यादि।

## २. दो-पॉइंटर स्लाइडिंग विंडो कार्यप्रणाली

पूरी लिस्ट को दो बार स्कैन करने ($N$ गिनने और फिर $N - k$ तक पहुंचने) के बजाय हम दो पॉइंटर्स $p_१$ और $p_२$ रखते हैं:
१. $p_१$ को $k$ नोड्स आगे बढ़ाएं।
२. यदि $k$ कदम पूरे होने से पहले $p_१$, `null` बन जाता है, तो लिस्ट में $k$ से कम नोड्स हैं (`null` लौटाएं)।
३. अब दोनों पॉइंटर्स $p_१$ और $p_२$ को समान गति (१ नोड प्रति चरण) से आगे बढ़ाएं।
४. जब $p_१$ लिस्ट के अंत (`null`) पर पहुंचेगा, तो $p_२$ ठीक अंत से $k$-वें नोड पर होगा।

## प्रोडक्शन कार्यान्वयन

```java
public class KthToLast {
    public static class LinkedListNode {
        public int data;
        public LinkedListNode next;
        public LinkedListNode(int d) { this.data = d; }
    }

    public static LinkedListNode nthToLast(LinkedListNode head, int k) {
        if (head == null || k <= 0) return null;

        LinkedListNode p1 = head;
        LinkedListNode p2 = head;

        // p1 को k नोड्स आगे ले जाएं
        for (int i = 0; i < k; i++) {
            if (p1 == null) return null; // लिस्ट की लंबाई k से कम है
            p1 = p1.next;
        }

        // दोनों पॉइंटर्स को एक साथ तब तक आगे बढ़ाएं जब तक p1 अंत पर न पहुंचे
        while (p1 != null) {
            p1 = p1.next;
            p2 = p2.next;
        }
        return p2;
    }
}
```

## जटिलता और मेमोरी विश्लेषण

| मापदंड | जटिलता | तकनीकी विवरण |
|---|---|---|
| समय जटिलता | `O(N)` | $N$ नोड्स की लिंक्ड लिस्ट का एकल पास। |
| सहायक मेमोरी | `O(१)` | केवल दो पॉइंटर संदर्भ। |

## वास्तविक दुनिया में सिस्टम इंजीनियरिंग उपयोग

### प्रोडक्शन सिस्टम आर्किटेक्चर: लॉग स्ट्रीमिंग और मेट्रिक्स बफर

लॉग स्ट्रीमिंग और टेलीमेट्री रिंग बफर सक्रिय हेड से $K$ इवेंट्स पीछे ट्रेलिंग पॉइंटर्स रखते हैं ताकि पूरे ऐतिहासिक एरे को सहेजे बिना विंडो मेट्रिक्स की गणना की जा सके।

## सीमा स्थितियां और प्रोडक्शन सुरक्षा

१. **$k > \text{लिस्ट का आकार}$:** $O(k)$ में `null` लौटाता है।
२. **$k = १$:** अंतिम नोड (टेल) लौटाता है।
