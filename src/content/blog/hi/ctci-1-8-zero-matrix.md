> **टीएल;डीआर**
> * **किताब का सवाल:** एक ऐसा एल्गोरिदम लिखें कि यदि M x N मैट्रिक्स में कोई तत्व ० है, तो उसकी पूरी पंक्ति और स्तंभ को ० पर सेट किया जाए।
> * **मुख्य समाधान:** पहली पंक्ति और स्तंभ को फ्लैग एरे (`matrix[0][j] = 0` और `matrix[i][0] = 0`) के रूप में उपयोग करें, जिससे बिना किसी अतिरिक्त मेमोरी आवंटन के $O(१)$ स्पेस और $O(M \times N)$ समय प्राप्त होता है।
> * **रियल-वर्ल्ड सिस्टम:** स्पार्स मैट्रिक्स कम्प्रेशन, स्प्रेडशीट इंजन और रिलेशनल डेटाबेस मास्किंग।

## १. किताब का सवाल और संदर्भ

*क्रैकिंग द कोडिंग इंटरव्यू* (समस्या १.८) में पूछा गया है:

*"एक ऐसा एल्गोरिदम लिखें कि यदि M x N मैट्रिक्स में कोई तत्व ० है, तो उसकी पूरी पंक्ति और स्तंभ को ० पर सेट किया जाए।"*

## २. इन-प्लेस स्टोरेज फ्लैग एल्गोरिदम

यदि हम ० मिलते ही तुरंत पूरी पंक्ति या स्तंभ को शून्य कर देंगे, तो आगे आने वाली खोजें नए बने शून्यों को भी मूल शून्य समझ लेंगी और पूरी मैट्रिक्स शून्य हो जाएगी।

*इष्टतम O(१) स्पेस रणनीति:*
१. पहले जांचें कि क्या पहली पंक्ति और पहले स्तंभ में मूल रूप से कोई ० है (दो बूलियन चरों में सहेजें: `rowHasZero`, `colHasZero`)।
२. शेष मैट्रिक्स ($i=1..M-1, j=1..N-1$) को स्कैन करें। यदि `matrix[i][j] == 0`, तो `matrix[i][0] = 0` और `matrix[0][j] = 0` सेट करें।
३. पहली पंक्ति और स्तंभ के निशानों के आधार पर आंतरिक सेलों को शून्य करें।
४. यदि `rowHasZero` या `colHasZero` सत्य थे, तो पहली पंक्ति और पहले स्तंभ को भी शून्य करें।

## प्रोडक्शन कार्यान्वयन

```java
public class ZeroMatrix {
    public static void setZeros(int[][] matrix) {
        boolean rowHasZero = false;
        boolean colHasZero = false;

        // जांचें कि क्या पहले कॉलम में 0 है
        for (int i = 0; i < matrix.length; i++) {
            if (matrix[i][0] == 0) { colHasZero = true; break; }
        }

        // जांचें कि क्या पहली पंक्ति में 0 है
        for (int j = 0; j < matrix[0].length; j++) {
            if (matrix[0][j] == 0) { rowHasZero = true; break; }
        }

        // पहली पंक्ति और कॉलम को स्टोरेज फ्लैग के रूप में उपयोग करें
        for (int i = 1; i < matrix.length; i++) {
            for (int j = 1; j < matrix[0].length; j++) {
                if (matrix[i][j] == 0) {
                    matrix[i][0] = 0;
                    matrix[0][j] = 0;
                }
            }
        }

        // पहले कॉलम के आधार पर पंक्तियों को शून्य करें
        for (int i = 1; i < matrix.length; i++) {
            if (matrix[i][0] == 0) nullifyRow(matrix, i);
        }

        // पहली पंक्ति के आधार पर कॉलमों को शून्य करें
        for (int j = 1; j < matrix[0].length; j++) {
            if (matrix[0][j] == 0) nullifyColumn(matrix, j);
        }

        // आवश्यकता पड़ने पर पहली पंक्ति और कॉलम को शून्य करें
        if (rowHasZero) nullifyRow(matrix, 0);
        if (colHasZero) nullifyColumn(matrix, 0);
    }

    private static void nullifyRow(int[][] matrix, int row) {
        for (int j = 0; j < matrix[0].length; j++) matrix[row][j] = 0;
    }

    private static void nullifyColumn(int[][] matrix, int col) {
        for (int i = 0; i < matrix.length; i++) matrix[i][col] = 0;
    }
}
```

## जटिलता और मेमोरी विश्लेषण

| मापदंड | जटिलता | तकनीकी विवरण |
|---|---|---|
| समय जटिलता | `O(M * N)` | M x N मैट्रिक्स के दो पूर्ण पास। |
| सहायक मेमोरी | `O(१)` | पहली पंक्ति और स्तंभ के सेलों का इन-प्लेस स्टोरेज फ्लैग के रूप में पुन: उपयोग। |

## वास्तविक दुनिया में सिस्टम इंजीनियरिंग उपयोग

### प्रोडक्शन सिस्टम आर्किटेक्चर: स्पार्स मैट्रिक्स कम्प्रेशन और लीनियर बीजगणित

कंप्रेस्ड स्पार्स रो (CSR) लीनियर अल्जebra लाइब्रेरी और स्प्रेडशीट रिकैलकुलेशन इंजन इन-प्लेस मार्कर स्कैनिंग का उपयोग करके शून्य आयामों को कुशलतापूर्वक संसाधित करते हैं।

## सीमा स्थितियां और प्रोडक्शन सुरक्षा

१. सभी तत्वों का शून्य होना: सुरक्षित रूप से संभाला जाता है।
२. बिंदु (०,०) पर शून्य होना: पहले पंक्ति व कॉलम के स्वतंत्र फ्लैग द्वारा संभाला जाता है।
