> **टीएल;डीआर**
> * **किताब का सवाल:** पुराने सेल फोन पर, उपयोगकर्ता संख्यात्मक कीपैड पर टाइप करते थे और फोन उन शब्दों की एक सूची प्रदान करता था जो उपयोगकर्ता द्वारा दर्ज किए गए कुंजी अनुक्रम से मेल खाते थे ($२ \to \text{abc}, ३ \to \text{def}, \dots$)। अंकों के एक अनुक्रम (उदा. `"8733"`) और एक डिक्शनरी के लिए सभी वैध शब्द लौटाएं (उदा. `["tree", "used"]`)।
> * **मुख्य समाधान:**
>   1. **प्रीकंप्यूटेड हैश मैप (प्रोडक्शन के लिए सर्वोत्तम)**:
>      * डिक्शनरी के प्रत्येक शब्द को उसके T9 संख्यात्मक रूप में बदलें (उदा. `"tree"` $\to$ `"8733"`)।
>      * `Map<String, List<String>>` में स्टोर करें।
>      * खोज **$O(L)$ समय** में पूरी होती है ($L = \text{अंकों की लंबाई}$)।
>   2. **ट्राई (Trie) खोज**:
>      * शब्दों को ट्राई में रखें और प्रत्येक अंक से संबंधित शाखाओं का ही अन्वेषण करें।
> * **रियल-वर्ल्ड सिस्टम:** एंड्रॉइड डायलर (AOSP) और इंटरेक्टिव वॉयस रिस्पांस (IVR)।

## १. किताब का सवाल और संदर्भ

*क्रैकिंग द कोडिंग इंटरव्यू* (समस्या १६.२०) में पूछा गया है:

*"टी९ कीपैड अंकों के अनुक्रम से मेल खाने वाले सभी मान्य डिक्शनरी शब्दों को खोजने के लिए एल्गोरिदम लिखें।"*

## २. प्रीकंप्यूटेड हैश संरचना

डिक्शनरी के शब्दों को पहले से ही अंकों के साथ मैप करने से रनटाइम पर कोई भी खोज केवल $O(L)$ समय में पूरी हो जाती है।

## प्रोडक्शन कार्यान्वयन

```java
import java.util.*;

public class T9Lookup {

    private static final int[] CHAR_TO_DIGIT = {
        2, 2, 2,  // a, b, c
        3, 3, 3,  // d, e, f
        4, 4, 4,  // g, h, i
        5, 5, 5,  // j, k, l
        6, 6, 6,  // m, n, o
        7, 7, 7, 7, // p, q, r, s
        8, 8, 8,  // t, u, v
        9, 9, 9, 9  // w, x, y, z
    };

    public static String wordToDigits(String word) {
        StringBuilder sb = new StringBuilder();
        for (char c : word.toLowerCase().toCharArray()) {
            if (c >= 'a' && c <= 'z') {
                sb.append(CHAR_TO_DIGIT[c - 'a']);
            }
        }
        return sb.toString();
    }

    public static Map<String, List<String>> initializeT9Map(String[] dictionary) {
        Map<String, List<String>> map = new HashMap<>();
        for (String word : dictionary) {
            String digits = wordToDigits(word);
            map.computeIfAbsent(digits, k -> new ArrayList<>()).add(word);
        }
        return map;
    }

    public static List<String> getValidWords(String digits, Map<String, List<String>> t9Map) {
        return t9Map.getOrDefault(digits, Collections.emptyList());
    }
}
```

## जटिलता विश्लेषण

| चरण | एल्गोरिदम | समय जटिलता | सहायक स्पेस |
|---|---|---|---|
| **प्रीप्रोसेसिंग** | डिक्शनरी इंडेक्सिंग | $O(W \cdot K)$ | $O(W \cdot K)$ हैश तालिका |
| **रनटाइम क्वेरी** | हैश मैप लुकअप | **$O(L)$** | **$O(1)$** |

## वास्तविक दुनिया में सिस्टम इंजीनियरिंग उपयोग

### प्रोडक्शन सिस्टम आर्किटेक्चर: एंड्रॉइड डायलर (AOSP)

१. **स्मार्ट टी९ सर्च:** एंड्रॉइड डायलर संपर्क सूची को SQLite FTS तालिकाओं में T9 अंकों के रूप में प्री-इंडेक्स करता है ताकि टाइप करते ही तुरंत संपर्क मिल जाएं।
२. **आईवीआर सिस्टम (IVR):** फोन मेनू में कीपैड प्रविष्टियों का मिलान।

## सीमा स्थितियां और प्रोडक्शन सुरक्षा

१. **बेमेल अंक अनुक्रम:** बिना किसी नल-पॉइंटर अपवाद के `Collections.emptyList()` लौटाना।
