> **टीएल;डीआर**
> * **किताब का सवाल:** एक यादृच्छिक जनरेटर `rand5()` दिया गया है जो समान संभावना के साथ $०$ से $४$ तक एक पूर्णांक उत्पन्न करता है, `rand7()` को लागू करें जो $०$ से $६$ तक एक पूर्णांक समान संभावना के साथ उत्पन्न करता है।
> * **मुख्य समाधान:** **२डी बेस-५ ग्रिड और रिजेक्शन सैंपलिंग (Rejection Sampling)**:
>   1. **परिणाम स्पेस विस्तार**: `rand5()` को दो बार कॉल करने पर $५ \times ५ = २५$ समान संभावित परिणाम उत्पन्न होते हैं:
>      $$\text{num} = 5 \times \text{rand5}() + \text{rand5}() \in [०, २४]$$
>   2. **सममित कटऑफ**: २५ से छोटा ७ का सबसे बड़ा गुणज $२१ = ३ \times ७$ है।
>   3. **स्वीकृति**: यदि $\text{num} < २१$, तो $\text{num} \pmod ७$ लौटाएं ($\Pr = ३/२१ = १/७$)।
>   4. यदि $\text{num} \ge २१$, तो खारिज करें और पुनः प्रयास करें।
>   5. यह **$O(1)$ अपेक्षित समय** ($\approx १.१९$ अपेक्षित चक्र) और **$O(1)$ सहायक स्पेस** में चलता है।
> * **रियल-वर्ल्ड सिस्टम:** टीएलएस हैंडशेक में क्रिप्टोग्राफिक नॉनसेस (Nonces) और मोंटे कार्लो सिमुलेशन।

## १. किताब का सवाल और संदर्भ

*क्रैकिंग द कोडिंग इंटरव्यू* (समस्या १६.२३) में पूछा गया है:

*"केवल rand5() के माध्यम से ० से ६ तक पूर्णतः निष्पक्ष (Unbiased) यादृच्छिक संख्या उत्पन्न करने के लिए विधि लिखें।"*

## २. २डी बेस-५ परिणाम मैट्रिक्स

प्रत्येक सेल की संभावना ठीक $१/२५$ होती है, जिससे २१ तत्वों का चयन समान वितरण सुनिश्चित करता है।

## प्रोडक्शन कार्यान्वयन

```java
import java.util.Random;

public class Rand7FromRand5 {

    private static final Random RNG = new Random();

    public static int rand5() {
        return RNG.nextInt(5);
    }

    public static int rand7() {
        while (true) {
            int num = 5 * rand5() + rand5();
            if (num < 21) {
                return num % 7;
            }
        }
    }
}
```

## जटिलता और सांख्यिकीय विश्लेषण

| मापदंड | मान | तकनीकी विवरण |
|---|---|---|
| स्वीकृति प्रायिकता | $p = २१ / २५ = ८४.०\%$ | प्रथम प्रयास में उच्च सफलता दर। |
| अपेक्षित चक्र | $E = २५ / २१ \approx १.१९$ | त्वरित समापन। |
| समय जटिलता | `O(1) अपेक्षित` | ज्यामितीय वितरण। |
| सांख्यिकीय पूर्वाग्रह | `०.००%` | प्रत्येक आउटपुट के लिए सटीक $१/७$ संभावना। |

## वास्तविक दुनिया में सिस्टम इंजीनियरिंग उपयोग

### प्रोडक्शन सिस्टम आर्किटेक्चर: क्रिप्टोग्राफिक एंट्रॉपी कंडीशनिंग

१. **वॉन न्यूमैन एल्गोरिदम:** हार्डवेयर सुरक्षा चिप्स में भौतिक शोर से आने वाले असंतुलित बिट्स को रिजेक्शन सैंपलिंग द्वारा शुद्ध क्रिप्टोग्राफिक यादृच्छिक संख्याओं में बदलना।
२. **मोंटे कार्लो सैंपलिंग:** जटिल संभावना वितरणों का मॉडलिंग।

## सीमा स्थितियां और प्रोडक्शन सुरक्षा

१. **`(rand5() + rand5()) % 7` का भ्रम:** सीधे जोड़ने से त्रिकोणीय गैर-समान वितरण ($P(4) > P(0)$) बनता है, जबकि $5 \times \text{rand5}()$ कार्तीय ग्रिड में पूर्ण एकरूपता बनाए रखता है।
