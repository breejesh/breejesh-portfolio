> **टीएल;डीआर**
> * **किताब का सवाल:** बिना किसी अस्थायी चर (Temporary Variable) का उपयोग किए दो संख्याओं को इन-प्लेस स्वैप करने के लिए फ़ंक्शन लिखें।
> * **मुख्य समाधान:**
>   1. **बिटवाइज़ XOR (ओवरफ्लो से सुरक्षित)**:
>      * `a = a ^ b;`
>      * `b = a ^ b;` (`(a ^ b) ^ b = a` बनता है)
>      * `a = a ^ b;` (`(a ^ b) ^ a = b` बनता है)
>   2. **अंकगणितीय अंतर**:
>      * `a = a - b;`
>      * `b = a + b;` (`a` बनता है)
>      * `a = b - a;` (`b` बनता है)
>   3. यह **$O(1)$ समय** और **$O(1)$ सहायक मेमोरी** में चलता है।
> * **रियल-वर्ल्ड सिस्टम:** x86 असेंबली में हार्डवेयर `XCHG` निर्देश।

## १. किताब का सवाल और संदर्भ

*क्रैकिंग द कोडिंग इंटरव्यू* (समस्या १६.१) में पूछा गया है:

*"अस्थायी मेमोरी आवंटित किए बिना दो चरों के मानों को परस्पर बदलने के लिए इन-प्लेस फ़ंक्शन लिखें।"*

## २. बिटवाइज़ XOR का गणितीय प्रमाण

XOR ऑपरेशन स्व-उलटा ($x \oplus x = 0$) होता है:
१. $a_1 = a \oplus b$
२. $b_1 = a_1 \oplus b = (a \oplus b) \oplus b = a$
३. $a_2 = a_1 \oplus b_1 = (a \oplus b) \oplus a = b$

## प्रोडक्शन कार्यान्वयन

```java
public class NumberSwapper {

    public static void swapXor(int[] pair) {
        if (pair == null || pair.length < 2) return;
        pair[0] = pair[0] ^ pair[1];
        pair[1] = pair[0] ^ pair[1];
        pair[0] = pair[0] ^ pair[1];
    }
}
```

```c
void swap_xor(int *a, int *b) {
    if (a != b) { // पॉइंटर अलियासिंग से बचाव: समान पते पर शून्य होने से रोकता है
        *a ^= *b;
        *b ^= *a;
        *a ^= *b;
    }
}
```

## जटिलता और सुरक्षा विश्लेषण

| विधि | समय जटिलता | स्पेस जटिलता | ओवरफ्लो जोखिम |
|---|---|---|---|
| **बिटवाइज़ XOR** | `O(1)` | `O(1)` | **शून्य** (तार्किक बिट ऑपरेशन) |
| **अंकगणितीय अंतर** | `O(1)` | `O(1)` | **उच्च** (साइन किए गए पूर्णांकों में ओवरफ्लो) |

## वास्तविक दुनिया में सिस्टम इंजीनियरिंग उपयोग

### प्रोडक्शन सिस्टम आर्किटेक्चर: पॉइंटर अलियासिंग का खतरा

१. **समान मेमोरी पता:** यदि `swap_xor(&x, &x)` को एक ही पते पर बुलाया जाता है, तो `*x ^= *x` शून्य बन जाता है, जिससे मूल मान नष्ट हो जाता है।
२. **कंपाइलर अनुकूलन:** आधुनिक कंपाइलर अस्थायी चर वाले कोड को सीधे हार्डवेयर `XCHG` निर्देश में बदल देते हैं।

## सीमा स्थितियां और प्रोडक्शन सुरक्षा

१. **समान पते की जांच:** इन-प्लेस XOR निष्पादित करने से पहले `if (a != b)` की जांच आवश्यक है।
