> **टीएल;डीआर**
> * **किताब का सवाल:** आपके पास १ से $N$ तक की सभी संख्याओं वाला एक ऐरे है, जहाँ $N \le 32,000$ है। ऐरे में डुप्लिकेट प्रविष्टियां हो सकती हैं और आपको $N$ का मान नहीं पता है। केवल ४ किलोबाइट मेमोरी उपलब्ध होने पर, आप ऐरे में सभी डुप्लिकेट तत्वों को कैसे प्रिंट करेंगे?
> * **मुख्य समाधान:** **४ KB कॉम्पैक्ट बिटसेट**: (१) $4\text{ KB} = 4,096\text{ bytes} = 32,768\text{ bits}$; (२) ३२,००० संख्याओं के लिए, एक बिट वेक्टर को ठीक $32,000 / 8 = 4,000\text{ bytes} \approx 3.91\text{ KB}$ की आवश्यकता होती है; (३) ऐरे में लूप चलाएं और प्रत्येक संख्या $v$ के लिए `bitSet.get(v - 1)` जांचें: यदि सत्य है, तो डुप्लिकेट प्रिंट करें, अन्यथा `bitSet.set(v - 1)` करें; (४) यह **$O(N)$ समय** और **सख्ती से $< 4\text{ KB}$ स्पेस** में पूरा होता है।
> * **रियल-वर्ल्ड सिस्टम:** एम्बेडेड माइक्रोकंट्रोलर सेंसर डेटा प्रोसेसिंग और टीसीपी (TCP) पैकेट विंडो ट्रैकिंग।

## १. किताब का सवाल और संदर्भ

*क्रैकिंग द कोडिंग इंटरव्यू* (समस्या १०.८) में पूछा गया है:

*"१ से ३२,००० तक की संख्याओं वाले ऐरे में से केवल ४ किलोबाइट मेमोरी के तहत सभी डुप्लिकेट संख्याओं को प्रिंट करें।"*

## २. मेमोरी गणना और बिट हेरफेर

३२,००० पूर्णांकों के लिए मानक हैश सेट $128\text{ KB}$ मेमोरी लेगा, जो सीमा से ३२ गुना अधिक है।

प्रत्येक संख्या को एकल बिट द्वारा दर्शाने पर:
$$32,000\text{ bits} = \frac{32,000}{8 \times 1024}\text{ KB} = 3.91\text{ KB} \le 4\text{ KB}$$

## प्रोडक्शन कार्यान्वयन

```java
public class FindDuplicates {
    public static class BitSet {
        private final int[] bitset;

        public BitSet(int size) {
            this.bitset = new int[(size >> 5) + 1];
        }

        public boolean get(int pos) {
            int wordNumber = (pos >> 5);
            int bitNumber = (pos & 0x1F);
            return (bitset[wordNumber] & (1 << bitNumber)) != 0;
        }

        public void set(int pos) {
            int wordNumber = (pos >> 5);
            int bitNumber = (pos & 0x1F);
            bitset[wordNumber] |= (1 << bitNumber);
        }
    }

    public static void checkDuplicates(int[] array) {
        BitSet bs = new BitSet(32000);

        for (int i = 0; i < array.length; i++) {
            int num = array[i];
            int num0 = num - 1;

            if (bs.get(num0)) {
                System.out.println(num);
            } else {
                bs.set(num0);
            }
        }
    }
}
```

## जटिलता और मेमोरी विश्लेषण

| मापदंड | जटिलता | तकनीकी विवरण |
|---|---|---|
| समय जटिलता | `O(N)` | ऐरे पर १ क्रमिक पास और $O(1)$ बिट ऑपरेशन्स। |
| सहायक मेमोरी | `3.91 KB` | आंतरिक ऐरे में ठीक १,००० ३२-बिट पूर्णांक ($4,000\text{ bytes}$)। |

## वास्तविक दुनिया में सिस्टम इंजीनियरिंग उपयोग

### प्रोडक्शन सिस्टम आर्किटेक्चर: एम्बेडेड सिस्टम

१. **IoT सेंसर फर्मवेयर (ARM Cortex-M):** सीमित SRAM (८ KB) वाले माइक्रोकंट्रोलर्स बिटमैप का उपयोग करके डुप्लिकेट इवेंट्स को तुरंत पहचानते हैं।
२. **टीसीपी स्लाइडिंग विंडो:** नेटवर्क पैकेट अनुक्रमों की ट्रैकिंग।

## सीमा स्थितियां और प्रोडक्शन सुरक्षा

१. **सीमा तत्व ($1$ और $32,000$):** बिना किसी ओवरफ्लो के बिट इंडेक्स ० और ३१,९९९ पर मैप किए गए।
२. **एकाधिक डुप्लिकेट:** प्रत्येक बार मिलने पर सही ढंग से प्रिंट होना।
