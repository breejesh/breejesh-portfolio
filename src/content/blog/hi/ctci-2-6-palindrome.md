> **टीएल;डीआर**
> * **किताब का सवाल:** यह जांचने के लिए एक फ़ंक्शन लागू करें कि क्या कोई सिंगली लिंक्ड लिस्ट एक पैलिंड्रोम है।
> * **मुख्य समाधान:** लिस्ट के मध्य बिंदु को खोजने के लिए तेज/धीमे रनर पॉइंटर्स का उपयोग करें और पहले आधे भाग के तत्वों को स्टैक (`Stack`) में डालें। विषम लंबाई होने पर मध्य तत्व को छोड़ें, फिर स्टैक से मान पॉप करते हुए दूसरे आधे भाग से $O(N)$ समय और $O(N)$ स्पेस में तुलना करें।
> * **रियल-वर्ल्ड सिस्टम:** स्ट्रीमिंग डेटा सत्यापन, डीएनए पैलिंड्रोम खोज और नेटवर्क पेलोड समरूपता जांच।

## १. किताब का सवाल और संदर्भ

*क्रैकिंग द कोडिंग इंटरव्यू* (समस्या २.६) में पूछा गया है:

*"यह जांचने के लिए एक फ़ंक्शन लागू करें कि क्या कोई लिंक्ड लिस्ट पैलिंड्रोम है।"*

**उदाहरण:**
* `0 -> 1 -> 2 -> 1 -> 0 -> true`
* `0 -> 1 -> 2 -> 2 -> 1 -> 0 -> true`
* `0 -> 1 -> 2 -> 3 -> 0 -> false`

## २. फास्ट/स्लो रनर और स्टैक कार्यप्रणाली

पूरी लिस्ट को कॉपी किए बिना हम केवल पहले आधे भाग को प्रोसेस करते हैं:
१. एक धीमा पॉइंटर `slow` (१ कदम) और एक तेज पॉइंटर `fast` (२ कदम) रखें।
२. जब `slow` पहले आधे भाग को पार करता है, तो उसके डेटा को `Stack<Integer>` में डालें।
३. जब `fast` लिस्ट के अंत तक पहुंचता है:
   * यदि `fast != null` (विषम लंबाई), तो केंद्र के तत्व को छोड़ने के लिए `slow` को एक कदम आगे बढ़ाएं।
४. `slow` को दूसरे आधे भाग में आगे बढ़ाते हुए स्टैक से तुलना करें:
   * यदि कोई मान मेल नहीं खाता: तुरंत `false` लौटाएं।
५. यदि स्टैक पूरी तरह खाली हो जाता है: `true` लौटाएं।

## प्रोडक्शन कार्यान्वयन

```java
import java.util.Stack;

public class PalindromeList {
    public static class LinkedListNode {
        public int data;
        public LinkedListNode next;
        public LinkedListNode(int d) { this.data = d; }
    }

    /**
     * जांचता है कि क्या लिस्ट पैलिंड्रोम है।
     * समय जटिलता: O(N)
     * स्पेस जटिलता: O(N) (N/2 तत्व संग्रहीत करता है)
     */
    public static boolean isPalindrome(LinkedListNode head) {
        LinkedListNode fast = head;
        LinkedListNode slow = head;

        Stack<Integer> stack = new Stack<>();

        // पहले आधे भाग के तत्वों को स्टैक में डालें
        while (fast != null && fast.next != null) {
            stack.push(slow.data);
            slow = slow.next;
            fast = fast.next.next;
        }

        // विषम लंबाई होने पर मध्य तत्व को छोड़ें
        if (fast != null) {
            slow = slow.next;
        }

        // दूसरे आधे भाग की स्टैक से तुलना करें
        while (slow != null) {
            int top = stack.pop();

            if (top != slow.data) {
                return false;
            }
            slow = slow.next;
        }

        return true;
    }
}
```

## जटिलता और मेमोरी विश्लेषण

| मापदंड | जटिलता | तकनीकी विवरण |
|---|---|---|
| समय जटिलता | `O(N)` | `fast` पॉइंटर $N/२$ पुनरावृत्तियों में समाप्त होता है; दूसरा आधा स्कैन $N/२$ कदम लेता है। |
| सहायक मेमोरी | `O(N)` | स्टैक में ठीक $\lfloor N/२ \rfloor$ तत्व होते हैं। |

## वास्तविक दुनिया में सिस्टम इंजीनियरिंग उपयोग

### प्रोडक्शन सिस्टम आर्किटेक्चर: एकतरफा स्ट्रीम सत्यापन

१. **यूनिडायरेक्शनल नेटवर्क पार्सिंग:** संपूर्ण पेलोड को मेमोरी में लोड किए बिना सममित चेकसम की पुष्टि करना।
२. **जीनोमिक्स:** डीएनए में पैलिंड्रोमिक अनुक्रमों की पहचान।

## सीमा स्थितियां और प्रोडक्शन सुरक्षा

१. **खाली लिस्ट (`null`):** `true` लौटाता है।
२. **एकल नोड (`1`):** `fast.next == null`, स्टैक खाली, मध्य छोड़कर `true` लौटाता है।
३. **सम लंबाई पैलिंड्रोम (`1 -> 2 -> 2 -> 1`):** लूप समाप्ति पर `fast == null`, दोनों हिस्सों की सटीक तुलना।
४. **विषम लंबाई पैलिंड्रोम (`1 -> 2 -> 1`):** `fast != null` मध्य नोड को छोड़ने का ट्रिगर करता है।
