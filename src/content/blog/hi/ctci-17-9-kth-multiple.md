> **टीएल;डीआर**
> * **किताब का सवाल:** $k$-वीं ऐसी संख्या खोजने के लिए एक एल्गोरिदम डिज़ाइन करें जिसके एकमात्र अभाज्य गुणनखंड ३, ५ और ७ हों ($१, ३, ५, ७, ९, १५, २१, २५, २७, ३५, \dots$)।
> * **मुख्य समाधान:** **३-पॉइंटर मोनोटोनिक डायनामिक प्रोग्रामिंग**:
>   1. `dp[0] = 1` के साथ $k$ आकार की एक सरणी और तीन पॉइंटर $p_3 = 0, p_5 = 0, p_7 = 0$ इनिशियलाइज़ करें।
>   2. प्रत्येक चरण $i \in [1, k-1]$ पर:
>      * उम्मीदवार गुणक निकालें: $v_3 = 3 \cdot dp[p_3], v_5 = 5 \cdot dp[p_5], v_7 = 7 \cdot dp[p_7]$।
>      * न्यूनतम चुनें: $dp[i] = \min(v_3, v_5, v_7)$।
>      * न्यूनतम उत्पन्न करने वाले सभी पॉइंटर्स को आगे बढ़ाएं ताकि डुप्लीकेट संख्याएं (उदा. $१५ = ३ \times ५ = ५ \times ३$) स्वतः हट जाएं।
>   3. यह **$O(K)$ समय** और **$O(K)$ सहायक स्पेस** में चलता है।
> * **रियल-वर्ल्ड सिस्टम:** एफएफटी (FFT) सिग्नल प्रोसेसिंग में स्मूथ नंबर (Hamming Numbers) और क्रिप्टोग्राफी।

## १. किताब का सवाल और संदर्भ

*क्रैकिंग द कोडिंग इंटरव्यू* (समस्या १७.९) में पूछा गया है:

*"केवल ३, ५ और ७ अभाज्य गुणनखंडों वाली K-वीं धनात्मक संख्या को कुशलतापूर्वक उत्पन्न करने के लिए विधि लिखें।"*

## २. ३-पॉइंटर मल्टी-स्ट्रीम जनरेशन

तीनों पॉइंटर्स को एक साथ आगे बढ़ाने से बिना किसी अतिरिक्त हैशसेट के सही आरोही क्रम और डुप्लीकेट-मुक्त आउटपुट सुनिश्चित होता है।

## प्रोडक्शन कार्यान्वयन

```java
public class KthMultiple {

    /**
     * O(K) समय और स्पेस में K-वें गुणज की गणना।
     */
    public static long getKthMultiple(int k) {
        if (k <= 0) return 0;

        long[] dp = new long[k];
        dp[0] = 1;

        int p3 = 0, p5 = 0, p7 = 0;

        for (int i = 1; i < k; i++) {
            long next3 = dp[p3] * 3;
            long next5 = dp[p5] * 5;
            long next7 = dp[p7] * 7;

            long minVal = Math.min(next3, Math.min(next5, next7));
            dp[i] = minVal;

            if (minVal == next3) p3++;
            if (minVal == next5) p5++;
            if (minVal == next7) p7++;
        }

        return dp[k - 1];
    }
}
```

## जटिलता विश्लेषण

| रणनीति | समय जटिलता | सहायक स्पेस | डुप्लीकेट निष्कासन |
|---|---|---|---|
| **३-पॉइंटर DP** | **$O(K)$** | **$O(K)$** | **सहज (साझा पॉइंटर वृद्धि)** |
| **मिन-हीप (PriorityQueue)** | $O(K \log K)$ | $O(K)$ | हैशसेट की आवश्यकता |

## वास्तविक दुनिया में सिस्टम इंजीनियरिंग उपयोग

### प्रोडक्शन सिस्टम आर्किटेक्चर: एफएफटी (FFT) और स्मूथ नंबर्स

१. **फास्ट फूरियर ट्रांसफॉर्म (FFTW):** सिग्नल प्रोसेसिंग में कूली-टुकी एल्गोरिदम तब सबसे तेज काम करते हैं जब बफर का आकार ५-स्मूथ नंबर ($२^a \cdot ३^b \cdot ५^c$) होता है।
२. **आरएसए क्रिप्टोग्राफी:** द्विघात छलनी (Quadratic Sieve) में स्मूथ संख्याओं का उपयोग।

## सीमा स्थितियां और प्रोडक्शन सुरक्षा

१. **६४-बिट Long ओवरफ्लो:** $k > 1,000$ के लिए मान तेजी से बढ़ते हैं, इसलिए ६४-बिट `long` का उपयोग अनिवार्य है।
२. **$k = 1$:** सही ढंग से १ लौटाना।
