> **टीएल;डीआर**
> * **किताब का सवाल:** एक मसाज थेरेपिस्ट अपॉइंटमेंट अनुरोध प्राप्त करती है और सत्रों के बीच ब्रेक लेना आवश्यक है (वह लगातार दो अपॉइंटमेंट स्वीकार नहीं कर सकती)। दिए गए अनुरोध अवधियों की सरणी में, वह अधिकतम कितने कुल मिनट बुक कर सकती है, यह ज्ञात करें।
> * **मुख्य समाधान:** **गैर-आसन्न डायनामिक प्रोग्रामिंग और O(1) स्पेस**:
>   1. **पुनरावृत्ति संबंध**: अपॉइंटमेंट $i$ के लिए:
>      $$\text{Best}[i] = \max(\text{Best}[i-1],\, \text{Best}[i-2] + M[i])$$
>   2. **अवस्था संपीड़न**: पूरी $O(N)$ सारणी के बजाय केवल दो चर: `oneAway` ($i-1$) और `twoAway` ($i-2$) बनाए रखें।
>   3. यह सख्त **$O(N)$ समय** और **$O(1)$ सहायक स्पेस** में चलता है।
> * **रियल-वर्ल्ड सिस्टम:** IoT सेंसर ड्यूटी-साइकलिंग और सर्वर कूलिंग साइकल शेड्यूलिंग।

## १. किताब का सवाल और संदर्भ

*क्रैकिंग द कोडिंग इंटरव्यू* (समस्या १७.१६) में पूछा गया है:

*"बैक-टू-बैक अपॉइंटमेंट अवधियों की सरणी में से एक गैर-आसन्न सबसेट चुनें जो O(N) समय और O(1) स्पेस में कुल मिनट अधिकतम करे।"*

## २. DP अवस्था में कमी

चूंकि किसी भी चरण $i$ पर सर्वश्रेष्ठ परिणाम केवल दो पिछले चरणों पर निर्भर करता है, इसलिए पूरी $N$ आकार की तालिका को दो पूर्णांक चरों में संकुचित किया जा सकता है।

## प्रोडक्शन कार्यान्वयन

```java
public class MasseuseSchedule {

    /**
     * O(N) समय और O(1) स्पेस में अधिकतम बुक किए गए मिनट।
     */
    public static int maxMinutes(int[] massages) {
        if (massages == null || massages.length == 0) {
            return 0;
        }

        int oneAway = 0; // DP[i - 1]
        int twoAway = 0; // DP[i - 2]

        for (int m : massages) {
            int currentBest = Math.max(oneAway, twoAway + m);
            twoAway = oneAway;
            oneAway = currentBest;
        }

        return oneAway;
    }
}
```

## जटिलता विश्लेषण

| रणनीति | समय जटिलता | सहायक स्पेस | सरणी आवंटन |
|---|---|---|---|
| **O(1) स्पेस DP** | **$O(N)$** | **$O(1)$** | **० सरणी** |
| **पूर्ण DP तालिका** | $O(N)$ | $O(N)$ | N आकार की सरणी |
| **ब्रूट-फोर्स रिकर्शन** | $O(2^N)$ | $O(N)$ | स्टैक ओवरफ्लो |

## वास्तविक दुनिया में सिस्टम इंजीनियरिंग उपयोग

### प्रोडक्शन सिस्टम आर्किटेक्चर: सेंसर नेटवर्क में ड्यूटी-साइकलिंग

१. **IoT सेंसर स्लीप साइकल:** सौर-ऊर्जा संचालित पर्यावरण सेंसर भारी ट्रांसमिशन और अनिवार्य निष्क्रिय शीतलन अंतराल के बीच साइकल करने के लिए गैर-आसन्न DP का उपयोग करते हैं।
२. **सर्वर थर्मल प्रबंधन:** उच्च-प्रदर्शन थर्मल थ्रॉटलिंग एल्गोरिदम शीतलन अवस्थाओं के साथ उच्च-वाट कंप्यूटिंग जॉब्स को अनुक्रमित करते हैं।
