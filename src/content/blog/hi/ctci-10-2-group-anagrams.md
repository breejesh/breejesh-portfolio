> **टीएल;डीआर**
> * **किताब का सवाल:** स्ट्रिंग्स के एक ऐरे को सॉर्ट करने के लिए एक विधि लिखें ताकि सभी एनाग्राम (Anagrams) एक-दूसरे के बगल में आ जाएं।
> * **मुख्य समाधान:** **कैनोनिकल की बकेट हैशिंग**: (१) एनाग्राम्स के वर्णों को सॉर्ट करने पर समान हस्ताक्षर प्राप्त होता है (उदा. `"acre"`, `"race"`, `"care"` सभी सॉर्ट होकर `"acer"` बन जाते हैं); (२) `HashMap<String, List<String>>` में प्रत्येक शब्द को उसकी सॉर्टेड स्ट्रिंग कुंजी के तहत जोड़ें; (३) हैश मैप के बकेट्स को वापस मूल ऐरे में लिखें; (४) यह **$O(N \cdot K \log K)$ समय** और **$O(N \cdot K)$ स्पेस** में निष्पादित होता है।
> * **रियल-वर्ल्ड सिस्टम:** सर्च इंजनों में वर्तनी सुधार सुझाव और जीनोमिक्स में कोडॉन अनुक्रम वर्गीकरण।

## १. किताब का सवाल और संदर्भ

*क्रैकिंग द कोडिंग इंटरव्यू* (समस्या १०.२) में पूछा गया है:

*"स्ट्रिंग्स के एक ऐरे को पुनर्गठित करें ताकि सभी एनाग्राम एक दूसरे के निकट आ जाएं।"*

## २. कैनोनिकल की हैशिंग बनाम कंपैरेटर सॉर्ट

कस्टम `Comparator` से सॉर्ट करने पर $O(N \log N \cdot K \log K)$ समय लगता है।

प्रत्येक शब्द के सॉर्टेड रूप को हैश टेबल कुंजी बनाकर, केवल १ पास में $N$ शब्दों को सॉर्ट किया जाता है, जिससे समय घटकर **$O(N \cdot K \log K)$** हो जाता है।

## प्रोडक्शन कार्यान्वयन

```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

public class GroupAnagrams {
    /**
     * एनाग्राम्स को एक साथ समूहीकृत करता है।
     * समय जटिलता: O(N * K log K)
     * स्पेस जटिलता: O(N * K)
     */
    public static void sort(String[] array) {
        Map<String, List<String>> mapList = new HashMap<>();

        for (String s : array) {
            String key = sortChars(s);
            mapList.putIfAbsent(key, new ArrayList<>());
            mapList.get(key).add(s);
        }

        int index = 0;
        for (String key : mapList.keySet()) {
            List<String> list = mapList.get(key);
            for (String t : list) {
                array[index] = t;
                index++;
            }
        }
    }

    private static String sortChars(String s) {
        char[] content = s.toCharArray();
        Arrays.sort(content);
        return new String(content);
    }
}
```

## जटिलता और मेमोरी विश्लेषण

| मापदंड | जटिलता | तकनीकी विवरण |
|---|---|---|
| समय जटिलता | `O(N * K log K)` | अधिकतम $K$ लंबाई की $N$ स्ट्रिंग्स का अलग-अलग सॉर्टिंग। |
| सहायक मेमोरी | `O(N * K)` | समूहीकृत शब्दों की सूचियों को संग्रहीत करने वाला हैश मैप। |

## वास्तविक दुनिया में सिस्टम इंजीनियरिंग उपयोग

### प्रोडक्शन सिस्टम आर्किटेक्चर: लेक्सिकल इंडेक्स

१. **सर्च इंजन वर्तनी सुझाव:** एनाग्राम इंडेक्स द्वारा वर्ण विपर्यय (transposition) त्रुटियों को सुधारना।
२. **जीनोमिक कोडॉन हैशिंग:** डीएनए अनुक्रमों में न्यूक्लियोटाइड संयोजनों की पहचान।

## सीमा स्थितियां और प्रोडक्शन सुरक्षा

१. **रिक्त स्ट्रिंग और एकल वर्ण:** `""` कुंजी के अंतर्गत सुरक्षित रूप से समूहीकृत।
२. **केस संवेदनशीलता:** मूल स्ट्रिंग्स को बिना बदले सही क्रम में पुनर्स्थापित करना।
