> **टीएल;डीआर**
> * **किताब का सवाल:** २० बोतलें हैं। १९ में १.० ग्राम की गोलियां हैं और १ में १.१ ग्राम की। केवल एक बार वजन तौलकर भारी बोतल का पता कैसे लगाएं?
> * **मुख्य समाधान:** बोतल $i$ से $i$ गोलियां निकालें (१+२+...+२० = २१० गोलियां)। भारी बोतल का नंबर = $(\text{कुल वजन} - २१०) / ०.१$।
> * **रियल-वर्ल्ड सिस्टम:** यह विधि कंप्यूटर मेमोरी में ईसीसी (ECC) एरर करेक्शन के सिंड्रोम डिकोडिंग में उपयोग होती है।

## १. किताब का सवाल और संदर्भ

*क्रैकिंग द कोडिंग इंटरव्यू* (समस्या ६.१) में पूछा गया है:

*"आपके पास गोलियों की २० बोतलें हैं। १९ बोतलों में १.० ग्राम की गोलियां हैं, लेकिन १ बोतल में १.१ ग्राम की गोलियां हैं। एक सटीक डिजिटल तराजू के साथ, केवल एक माप से भारी बोतल कैसे खोजेंगे?"*

## २. अंकगणितीय प्रगति (Arithmetic Progression) विधि

प्रत्येक बोतल से उसके इंडेक्स के बराबर गोलियां निकालें:
* बोतल १ से १ गोली, बोतल २ से २ गोलियां, ..., बोतल २० से २० गोलियां।
* कुल गोलियां = $\frac{20 \times 21}{2} = 210$।
* यदि सभी १.० ग्राम की होतीं, तो वजन २१०.० ग्राम होता।
* प्रत्येक अतिरिक्त ०.१ ग्राम वजन सीधे भारी बोतल की संख्या दर्शाता है।

## प्रोडक्शन कार्यान्वयन

```java
public class HeavyPill {
    /**
     * केवल एक वजन माप से भारी बोतल की पहचान करता है।
     * समय जटिलता: O(1)
     * स्पेस जटिलता: O(1)
     */
    public static int findHeavyBottle(double scaleWeight, int totalBottles) {
        int expectedPills = (totalBottles * (totalBottles + 1)) / 2;
        double expectedWeight = expectedPills * 1.0;
        double excessWeight = scaleWeight - expectedWeight;
        return (int) Math.round(excessWeight / 0.1);
    }
}
```

## जटिलता और मेमोरी विश्लेषण

| मापदंड | जटिलता | तकनीकी विवरण |
|---|---|---|
| वजन माप | `१ माप` | डिजिटल तराजू का केवल एक बार उपयोग। |
| समय जटिलता | `O(१)` | सीधा अंकगणितीय सूत्र। |
| सहायक मेमोरी | `O(१)` | स्थानीय रजिस्टर गणना। |

## वास्तविक दुनिया में सिस्टम इंजीनियरिंग उपयोग

### प्रोडक्शन सिस्टम आर्किटेक्चर: ईसीसी सिंड्रोम डिकोडिंग

मेमोरी में करप्ट हुए बिट की पहचान के लिए हैमिंग कोड इसी गणितीय भारित योग (Weighted Sum) का उपयोग करता है।

## सीमा स्थितियां और प्रोडक्शन सुरक्षा

१. **फ्लोटिंग पॉइंट प्रिसिजन:** सटीक पूर्णांक बोतल संख्या प्राप्त करने के लिए `Math.round()` का उपयोग।
