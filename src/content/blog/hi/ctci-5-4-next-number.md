> **टीएल;डीआर**
> * **किताब का सवाल:** एक धनात्मक पूर्णांक दिए जाने पर, अगली सबसे छोटी और अगली सबसे बड़ी संख्या प्रिंट करें जिसमें १ की संख्या बिल्कुल समान हो।
> * **मुख्य समाधान:** (१) **अगली बड़ी (`getNext`):** स्थिति $p$ पर पहले गैर-अंतिम शून्य को खोजें। बिट $p$ को `0` से `1` में बदलें, दाईं ओर के बिट्स साफ़ करें और सबसे कम स्थानों पर $c_1 - 1$ वाले १ रखें; (२) **अगली छोटी (`getPrev`):** स्थिति $p$ पर पहले गैर-अंतिम १ को खोजें, उसे `0` बनाएं और $p$ के तुरंत दाईं ओर $c_1 + 1$ वाले १ रखें ($O(b)$ समय और $O(१)$ स्पेस)।
> * **रियल-वर्ल्ड सिस्टम:** गोस्पर का हैक (Gosper's Hack) और चेस इंजन बिटबोर्ड।

## १. किताब का सवाल और संदर्भ

*क्रैकिंग द कोडिंग इंटरव्यू* (समस्या ५.४) में पूछा गया है:

*"एक धनात्मक पूर्णांक दिए जाने पर, अगली सबसे छोटी और अगली सबसे बड़ी संख्या प्रिंट करें जिसमें बाइनरी में १s की संख्या समान हो।"*

## २. एल्गोरिदम कार्यप्रणाली

### अगली सबसे बड़ी संख्या (`getNext`)
१. अंतिम शून्य ($c_0$) और निरंतर १s ($c_1$) की गणना करें।
२. पहले गैर-अंतिम शून्य की स्थिति $p = c_0 + c_1$ है।
३. बिट $p$ को १ बनाएं: `n |= (1 << p)`।
४. $p$ के दाईं ओर के बिट्स साफ़ करें: `n &= ~((1 << p) - 1)`।
५. दाईं ओर $c_1 - 1$ वाले १ डालें: `n |= (1 << (c_1 - 1)) - 1`।

### अगली सबसे छोटी संख्या (`getPrev`)
१. अंतिम १s ($c_1$) और निरंतर ०s ($c_0$) की गणना करें।
२. पहले गैर-अंतिम १ की स्थिति $p = c_0 + c_1$ है।
३. स्थिति $p$ से साफ़ करें: `n &= ((~0) << (p + 1))`।
४. $p$ के तुरंत दाईं ओर $c_1 + 1$ वाले १ डालें: `int mask = (1 << (c_1 + 1)) - 1; n |= mask << (c_0 - 1)`।

## प्रोडक्शन कार्यान्वयन

```java
public class NextNumber {
    /**
     * समान बिट्स वाली अगली सबसे बड़ी संख्या की गणना करता है।
     * समय जटिलता: O(b) जहां b <= 32
     * स्पेस जटिलता: O(1)
     */
    public static int getNext(int n) {
        int c = n;
        int c0 = 0;
        int c1 = 0;

        while (((c & 1) == 0) && (c != 0)) {
            c0++;
            c >>= 1;
        }

        while ((c & 1) == 1) {
            c1++;
            c >>= 1;
        }

        if (c0 + c1 == 31 || c0 + c1 == 0) {
            return -1;
        }

        int p = c0 + c1;

        n |= (1 << p);
        n &= ~((1 << p) - 1);
        n |= (1 << (c1 - 1)) - 1;

        return n;
    }

    /**
     * समान बिट्स वाली अगली सबसे छोटी संख्या की गणना करता है।
     * समय जटिलता: O(b) जहां b <= 32
     * स्पेस जटिलता: O(1)
     */
    public static int getPrev(int n) {
        int temp = n;
        int c0 = 0;
        int c1 = 0;

        while ((temp & 1) == 1) {
            c1++;
            temp >>= 1;
        }

        if (temp == 0) return -1;

        while (((temp & 1) == 0) && (temp != 0)) {
            c0++;
            temp >>= 1;
        }

        int p = c0 + c1;
        n &= ((~0) << (p + 1));

        int mask = (1 << (c1 + 1)) - 1;
        n |= mask << (c0 - 1);

        return n;
    }
}
```

## जटिलता और मेमोरी विश्लेषण

| मापदंड | जटिलता | तकनीकी विवरण |
|---|---|---|
| समय जटिलता | `O(b)` | बिटवाइज़ शिफ्ट द्वारा अधिकतम ३२ बिट्स की जांच। |
| सहायक मेमोरी | `O(१)` | स्थानीय सीपीयू रजिस्टर। |

## वास्तविक दुनिया में सिस्टम इंजीनियरिंग उपयोग

### प्रोडक्शन सिस्टम आर्किटेक्चर: गोस्पर का हैक और बिटबोर्ड

१. **शतरंज इंजन (बिटबोर्ड्स):** वैध चालें उत्पन्न करने के लिए समान हैमिंग भार वाले मोहरों के विन्यास की गणना।
२. **गोस्पर का हैक (Gosper's Hack):** निश्चित आकार के सबसेट संयोजनों को निरंतर समय में उत्पन्न करना।

## सीमा स्थितियां और प्रोडक्शन सुरक्षा

१. **३२-बिट सकारात्मक श्रेणी से बाहर:** `-1` लौटाता है।
२. **२ की घात ($n = 4 \to 0100$):** `getNext` $8$ लौटाता है, `getPrev` $2$ लौटाता है।
