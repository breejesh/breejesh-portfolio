> **टीएल;डीआर**
> * **किताब का सवाल:** ताश के पत्तों के ५२ डेक को इस तरह फेरबदल करने के लिए एक विधि लिखें कि सभी ५२! क्रमपरिवर्तनों (Permutations) की संभावना बिल्कुल समान हो।
> * **मुख्य समाधान:** **फिशर-येट्स (Fisher-Yates / Knuth) इन-प्लेस एल्गोरिदम**:
>   1. सरणी में पीछे से आगे की ओर $i = N - 1$ से $1$ तक लूप चलाएं।
>   2. प्रत्येक चरण पर, $[0, i]$ श्रेणी में एक यादृच्छिक सूचकांक $k$ चुनें।
>   3. `cards[i]` को `cards[k]` के साथ बदलें (Swap करें)।
>   4. **नौसिखिया जाल**: हर बार $[0, N-1]$ से चुनने पर $N^N$ परिणाम बनते हैं, जो $N!$ से विभाजित नहीं होते, जिससे सांख्यिकीय पूर्वाग्रह उत्पन्न होता है।
>   5. यह **$O(N)$ समय** और **$O(1)$ सहायक स्पेस** में चलता है।
> * **रियल-वर्ल्ड सिस्टम:** मशीन लर्निंग में PyTorch `DataLoader` शफलिंग और प्रमाणित ऑनलाइन गेमिंग इंजन।

## १. किताब का सवाल और संदर्भ

*क्रैकिंग द कोडिंग इंटरव्यू* (समस्या १७.२) में पूछा गया है:

*"ताश के ५२ पत्तों को निष्पक्ष रूप से फेरबदल करने के लिए एल्गोरिदम लिखें ताकि प्रत्येक विन्यास की संभावना ठीक १/५२! हो।"*

## २. सांख्यिकीय एकरूपता का प्रमाण

प्रत्येक चरण $i$ पर किसी भी पत्ते के उस स्थान पर आने की संभावना $\frac{1}{N}$ होती है, जिससे कुल गुणनफल $\prod_{i=1}^N \frac{1}{i} = \frac{1}{N!}$ प्राप्त होता है।

## प्रोडक्शन कार्यान्वयन

```java
import java.util.Random;

public class DeckShuffler {

    private static final Random RNG = new Random();

    public static void shuffleArray(int[] cards) {
        if (cards == null || cards.length <= 1) return;

        for (int i = cards.length - 1; i > 0; i--) {
            int k = RNG.nextInt(i + 1); // [0, i] अंतराल
            int temp = cards[i];
            cards[i] = cards[k];
            cards[k] = temp;
        }
    }
}
```

## जटिलता और सांख्यिकीय विश्लेषण

| रणनीति | समय जटिलता | सहायक स्पेस | सांख्यिकीय एकरूपता |
|---|---|---|---|
| **फिशर-येट्स एल्गोरिदम** | **$O(N)$** | **$O(1)$** | **सटीक $1/N!$ (उत्कृष्ट)** |
| **नाइव स्वैप ($k \in [0, N-1]$)** | $O(N)$ | $O(1)$ | **पूर्वाग्रह युक्त ($N^N \nmid N!$)** |

## वास्तविक दुनिया में सिस्टम इंजीनियरिंग उपयोग

### प्रोडक्शन सिस्टम आर्किटेक्चर: डीप लर्निंग और गेमिंग

१. **PyTorch डेटालोडर:** मॉडल प्रशिक्षण में ग्रेडिएंट ओवरफिटिंग से बचने के लिए प्रत्येक युग (Epoch) की शुरुआत में डेटासेट को फिशर-येट्स द्वारा यादृच्छिक बनाया जाता है।
२. **सुरक्षित यादृच्छिकता:** ऑनलाइन पोकर में कार्ड की भविष्यवाणी को रोकने के लिए `SecureRandom` का उपयोग।
