> **टीएल;डीआर**
> * **किताब का सवाल:** असीमित संख्या में क्वार्टर (२५ सेंट), डाइम (१० सेंट), निकल (५ सेंट) और पेनी (१ सेंट) दिए जाने पर, $n$ सेंट का प्रतिनिधित्व करने के तरीकों की संख्या की गणना करने के लिए कोड लिखें।
> * **मुख्य समाधान:** **२D मेमोइज़ेशन / १D बॉटम-अप डायनामिक प्रोग्रामिंग**: (१) सिक्का मान सरणी `[25, 10, 5, 1]`; (२) २D मेमोइज़्ड तालिका `map[amount][index]`; (३) १D बॉटम-अप पुनरावृत्ति: प्रत्येक सिक्के के लिए `ways[i] += ways[i - coin]` जोड़ना, जो **$O(N)$ समय** और **$O(N)$ स्पेस** में निष्पादित होता है।
> * **रियल-वर्ल्ड सिस्टम:** पीओएस (POS) कैश रजिस्टर चेंज एल्गोरिदम और नेटवर्क पैकेट विखंडन (MTU)।

## १. किताब का सवाल और संदर्भ

*क्रैकिंग द कोडिंग इंटरव्यू* (समस्या ८.११) में पूछा गया है:

*"२५, १०, ५ और १ सेंट के असीमित सिक्कों के साथ n सेंट बनाने के कुल तरीकों की गणना करें।"*

## २. डायनामिक प्रोग्रामिंग दृष्टिकोण

१. **शीर्ष-नीचे २D मेमोइज़ेशन:** वर्तमान सिक्के के $0, 1, 2, \dots$ सिक्के चुनने के बाद शेष राशि को अगले सिक्कों के साथ हल करें।
२. **१D बॉटम-अप डायनामिक प्रोग्रामिंग:** `ways[0] = 1` सेट करें। प्रत्येक सिक्के के लिए सरणी में तरीकों को जोड़ते जाएं।

## प्रोडक्शन कार्यान्वयन

```java
public class CoinChange {
    /**
     * शीर्ष-नीचे 2D मेमोइज़ेशन विधि।
     * समय जटिलता: O(N * D) जहाँ D = 4 सिक्के हैं
     * स्पेस जटिलता: O(N * D)
     */
    public static int makeChange(int amount) {
        int[] denoms = {25, 10, 5, 1};
        int[][] map = new int[amount + 1][denoms.length];
        return makeChangeHelper(amount, denoms, 0, map);
    }

    private static int makeChangeHelper(int amount, int[] denoms, int index, int[][] map) {
        if (map[amount][index] > 0) return map[amount][index];
        if (index >= denoms.length - 1) return 1;

        int denomAmount = denoms[index];
        int ways = 0;
        for (int i = 0; i * denomAmount <= amount; i++) {
            int amountRemaining = amount - i * denomAmount;
            ways += makeChangeHelper(amountRemaining, denoms, index + 1, map);
        }

        map[amount][index] = ways;
        return ways;
    }

    /**
     * 1D बॉटम-अप डायनामिक प्रोग्रामिंग विधि।
     * समय जटिलता: O(N)
     * स्पेस जटिलता: O(N)
     */
    public static int makeChangeBottomUp(int n) {
        int[] denoms = {25, 10, 5, 1};
        int[] ways = new int[n + 1];
        ways[0] = 1;

        for (int coin : denoms) {
            for (int i = coin; i <= n; i++) {
                ways[i] += ways[i - coin];
            }
        }

        return ways[n];
    }
}
```

## जटिलता और मेमोरी विश्लेषण

| मापदंड | जटिलता | तकनीकी विवरण |
|---|---|---|
| समय जटिलता | `O(N)` | $N + 1$ आकार के ऐरे पर ठीक ४ रैखिक पास। |
| सहायक मेमोरी | `O(N)` | १D डायनामिक प्रोग्रामिंग तालिका। |

## वास्तविक दुनिया में सिस्टम इंजीनियरिंग उपयोग

### प्रोडक्शन सिस्टम आर्किटेक्चर: नैपसैक और करेंसी विभाजन

१. **पॉइंट ऑफ सेल (POS) कैश मशीनें:** भौतिक सिक्का सूची सीमाओं के तहत इष्टतम खुदरा परिवर्तन की गणना।
२. **नेटवर्क एमटीयू (MTU) सेगमेंटेशन:** बड़े डेटा बफ़र्स को मानक पैकेट आकारों में विभाजित करना।

## सीमा स्थितियां और प्रोडक्शन सुरक्षा

१. **$n = 0$ सेंट:** ठीक १ तरीका (० सिक्के चुनना)।
२. **५ से कम राशि:** ठीक १ तरीका (केवल पेनीज़)।
