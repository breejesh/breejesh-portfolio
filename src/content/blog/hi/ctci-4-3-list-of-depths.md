> **टीएल;डीआर**
> * **किताब का सवाल:** एक बाइनरी ट्री दिए जाने पर, ऐसा एल्गोरिदम डिजाइन करें जो प्रत्येक गहराई पर सभी नोड्स की एक लिंक्ड लिस्ट बनाता हो (उदाहरण के लिए, यदि पेड़ की गहराई $D$ है, तो आपके पास $D$ लिंक्ड लिस्ट होंगी)।
> * **मुख्य समाधान:** **इटरेटिव लेवल-ऑर्डर BFS**: `ArrayList<LinkedList<TreeNode>>` रखें। स्तर $i+1$ के लिए, स्तर $i$ के नोड्स को स्कैन करें और उनके बच्चों को एक नई लिस्ट में जोड़ें ($O(N)$ समय और $O(N)$ स्पेस बिना किसी बाहरी कतार संरचना के)।
> * **रियल-वर्ल्ड सिस्टम:** ब्राउज़र डीओएम (DOM) लेयर कंपोज़िटिंग और कंपाइलर एएसटी (AST) स्कोप लेयरिंग।

## १. किताब का सवाल और संदर्भ

*क्रैकिंग द कोडिंग इंटरव्यू* (समस्या ४.३) में पूछा गया है:

*"एक बाइनरी ट्री दिए जाने पर, ऐसा एल्गोरिदम डिजाइन करें जो प्रत्येक गहराई पर सभी नोड्स की एक लिंक्ड लिस्ट बनाता हो।"*

## २. लेवल-ऑर्डर ट्रैवर्सल (बिना बाहरी कतार के)

चूंकि स्तर $i$ की सूची में स्तर $i+१$ के सभी माता-पिता नोड्स होते हैं:
१. रूट नोड के साथ `current = new LinkedList<TreeNode>()` शुरू करें।
२. जब तक `current` खाली न हो:
   * `current` को परिणाम सूची में जोड़ें।
   * बच्चों के लिए नई खाली लिस्ट बनाएं।
   * `current` के प्रत्येक नोड के लिए:
     * यदि बायां बच्चा मौजूद है, तो नई लिस्ट में जोड़ें।
     * यदि दायां बच्चा मौजूद है, तो नई लिस्ट में जोड़ें।
   * `current` को बच्चों की लिस्ट से बदलें।

## प्रोडक्शन कार्यान्वयन

```java
import java.util.ArrayList;
import java.util.LinkedList;
import java.util.List;

public class ListOfDepths {
    public static class TreeNode {
        public int val;
        public TreeNode left;
        public TreeNode right;
        public TreeNode(int x) { this.val = x; }
    }

    /**
     * प्रत्येक गहराई स्तर पर नोड्स की लिंक्ड लिस्ट बनाता है।
     * समय जटिलता: O(N)
     * स्पेस जटिलता: O(N)
     */
    public static List<LinkedList<TreeNode>> createLevelLinkedList(TreeNode root) {
        List<LinkedList<TreeNode>> result = new ArrayList<>();
        if (root == null) return result;

        LinkedList<TreeNode> current = new LinkedList<>();
        current.add(root);

        while (!current.isEmpty()) {
            result.add(current); // पिछला स्तर जोड़ें
            LinkedList<TreeNode> parents = current;
            current = new LinkedList<>();

            for (TreeNode parent : parents) {
                if (parent.left != null) {
                    current.add(parent.left);
                }
                if (parent.right != null) {
                    current.add(parent.right);
                }
            }
        }

        return result;
    }
}
```

## जटिलता और मेमोरी विश्लेषण

| मापदंड | जटिलता | तकनीकी विवरण |
|---|---|---|
| समय जटिलता | `O(N)` | पेड़ का प्रत्येक नोड ठीक एक बार देखा जाता है और लिस्ट में जुड़ता है। |
| सहायक मेमोरी | `O(N)` | परिणामी संरचना में सभी $N$ नोड्स संग्रहीत होते हैं। |

## वास्तविक दुनिया में सिस्टम इंजीनियरिंग उपयोग

### प्रोडक्शन सिस्टम आर्किटेक्चर: पदानुक्रमित लेयरिंग

१. **वेब ब्राउज़र डीओएम रेंडरिंग:** जीपीयू कंपोज़िटिंग के लिए लेयर लिस्ट का निर्माण।
२. **कंपाइलर सिंटैक्स ट्री (AST):** लेक्सिकल स्कोपिंग लेयर प्रबंधन।

## सीमा स्थितियां और प्रोडक्शन सुरक्षा

१. **खाली पेड़:** खाली लिस्ट लौटाता है।
२. **असंतुलित रैखिक पेड़:** $O(N)$ में १-१ नोड वाली $N$ लिस्ट बनाता है।
