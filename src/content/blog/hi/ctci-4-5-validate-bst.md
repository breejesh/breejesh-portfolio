> **टीएल;डीआर**
> * **किताब का सवाल:** एक ऐसा फ़ंक्शन लागू करें जो जांचे कि क्या कोई बाइनरी ट्री एक वैध बाइनरी सर्च ट्री (BST) है।
> * **मुख्य समाधान:** **मिन/मैक्स रेंज पास-डाउन**: प्रत्येक नोड को शर्त $\text{min} < \text{node.val} \le \text{max}$ को संतुष्ट करना होगा। पेड़ में सीमाओं को नीचे की ओर पास करें: बाएं बच्चे को $(\text{min}, \text{node.val}]$ और दाएं बच्चे को $(\text{node.val}, \text{max})$ सीमा मिलती है ($O(N)$ समय)।
> * **रियल-वर्ल्ड सिस्टम:** पोस्टग्रेएसक्यूएल में बी-ट्री डेटाबेस इंडेक्स पेजों की अखंडता जांच (`amcheck`) और फाइल सिस्टम डायरेक्टरी ट्री।

## १. किताब का सवाल और संदर्भ

*क्रैकिंग द कोडिंग इंटरव्यू* (समस्या ४.५) में पूछा गया है:

*"यह जांचने के लिए एक फ़ंक्शन लागू करें कि क्या कोई बाइनरी ट्री एक बाइनरी सर्च ट्री है।"*

**परिभाषा:** बाइनरी सर्च ट्री के लिए आवश्यक है कि प्रत्येक नोड के लिए सभी बाएं वंशज $\le \text{node.val} <$ सभी दाएं वंशज हों।

## २. केवल तात्कालिक बच्चों की जांच करने का भ्रम

एक सामान्य गलती केवल यह जांचना है कि `node.left.val <= node.val && node.right.val > node.val`। यह उन पेड़ों के लिए विफल हो जाता है जहां बाएं सबट्री का एक दायां वंशज रूट से बड़ा होता है (उदा. रूट २०, बायां १०, १० का दायां बच्चा २५)।

*इष्टतम एल्गोरिदम:* रिकर्सिव ट्रैवर्सल के दौरान वैध श्रेणियों $(min, max)$ को नीचे की ओर पास करें, जिससे सत्यापित होता है कि प्रत्येक नोड सभी पूर्वजों द्वारा स्थापित वैश्विक सीमाओं का पालन करता है।

## प्रोडक्शन कार्यान्वयन

```java
public class ValidateBST {
    public static class TreeNode {
        public int val;
        public TreeNode left, right;
        public TreeNode(int v) { this.val = v; }
    }

    public static boolean checkBST(TreeNode root) {
        return checkBST(root, null, null);
    }

    private static boolean checkBST(TreeNode node, Integer min, Integer max) {
        if (node == null) return true;

        // यदि नोड न्यूनतम या अधिकतम सीमा का उल्लंघन करता है
        if ((min != null && node.val <= min) || (max != null && node.val > max)) {
            return false;
        }

        // बाएं बच्चे <= node.val होने चाहिए; दाएं बच्चे > node.val होने चाहिए
        return checkBST(node.left, min, node.val) && checkBST(node.right, node.val, max);
    }
}
```

## जटिलता और मेमोरी विश्लेषण

| मापदंड | जटिलता | तकनीकी विवरण |
|---|---|---|
| समय जटिलता | `O(N)` | प्रत्येक नोड ठीक एक बार देखा जाता है। |
| सहायक मेमोरी | `O(\log N \text{ से } N)` | पेड़ की ऊंचाई के बराबर स्टैक गहराई। |

## वास्तविक दुनिया में सिस्टम इंजीनियरिंग उपयोग

### प्रोडक्शन सिस्टम आर्किटेक्चर: डेटाबेस इंडेक्स पेजों का सत्यापन

पोस्टग्रेएसक्यूएल में `amcheck` जैसी इंडेक्स यूटिलिटीज हार्डवेयर बिट रॉट के कारण बी-ट्री पॉइंटर भ्रष्टाचार का पता लगाने के लिए मिन/मैक्स स्कैन चलाती हैं।

## सीमा स्थितियां और प्रोडक्शन सुरक्षा

१. `Integer.MIN_VALUE` / `Integer.MAX_VALUE`: प्रिमिटिव सेंटिनल मानों के बजाय `Integer` ऑब्जेक्ट्स का उपयोग करके सुरक्षित।
२. डुप्लिकेट मान: पुस्तक के नियम का पालन (`बायां <= रूट < दायां`)।
