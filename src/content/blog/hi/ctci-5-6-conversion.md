> **टीएल;डीआर**
> * **किताब का सवाल:** पूर्णांक A को पूर्णांक B में बदलने के लिए आपको कितने बिट्स को फ्लिप करने की आवश्यकता होगी, यह निर्धारित करने के लिए एक फ़ंक्शन लिखें।
> * **मुख्य समाधान:** $C = A \oplus B$ (XOR) की गणना करें। $C$ में प्रत्येक १-बिट उस स्थिति को दर्शाता है जहाँ $A$ और $B$ भिन्न हैं। **ब्रायन कर्निंगन के एल्गोरिदम** (`c = c & (c - 1)`) का उपयोग करके इन १-बिट्स को गिनें, जो $O(k)$ समय (जहाँ $k$ भिन्न बिट्स की संख्या है, $k \le 32$) और $O(१)$ स्पेस में निष्पादित होता है।
> * **रियल-वर्ल्ड सिस्टम:** ईसीसी मेमोरी (ECC Memory) में हैमिंग दूरी गणना और सर्च इंजन डुप्लिकेट डिटेक्शन (SimHash)।

## १. किताब का सवाल और संदर्भ

*क्रैकिंग द कोडिंग इंटरव्यू* (समस्या ५.६) में पूछा गया है:

*"पूर्णांक A को B में बदलने के लिए आवश्यक बिट फ्लिप की संख्या निर्धारित करने के लिए एक फ़ंक्शन लिखें।"*

**उदाहरण:**
* इनपुट: `29` (`11101_2`), `15` (`01111_2`)
* आउटपुट: `2` (स्थिति १ और ४ पर बिट्स को पलटना होगा)।

## २. XOR और ब्रायन कर्निंगन एल्गोरिदम

१. XOR ऑपरेशन $A \oplus B$ उन सभी स्थितियों पर १ देता है जहाँ $A$ और $B$ के बिट्स भिन्न होते हैं।
२. ३२ बार शिफ्ट करने के बजाय, ब्रायन कर्निंगन का ऑपरेशन `c = c & (c - 1)` हर चरण पर सबसे निचले १ को साफ़ करता है, जिससे लूप केवल $k$ बार चलता है।

## प्रोडक्शन कार्यान्वयन

```java
public class BitConversion {
    /**
     * पूर्णांक a को b में बदलने के लिए आवश्यक बिट फ्लिप की संख्या लौटाता है।
     * समय जटिलता: O(k) जहां k भिन्न बिट्स की संख्या है (k <= 32)।
     * स्पेस जटिलता: O(1)
     */
    public static int bitSwapRequired(int a, int b) {
        int count = 0;
        for (int c = a ^ b; c != 0; c = c & (c - 1)) {
            count++;
        }
        return count;
    }
}
```

## जटिलता और मेमोरी विश्लेषण

| मापदंड | जटिलता | तकनीकी विवरण |
|---|---|---|
| समय जटिलता | `O(k)` | ठीक $k$ पुनरावृत्तियां जहां $k$ हैमिंग दूरी है ($k \le 32$)। |
| सहायक मेमोरी | `O(१)` | स्थानीय सीपीयू रजिस्टर। |

## वास्तविक दुनिया में सिस्टम इंजीनियरिंग उपयोग

### प्रोडक्शन सिस्टम आर्किटेक्चर: हैमिंग दूरी और फॉल्ट टॉलरेंस

१. **ईसीसी मेमोरी (ECC RAM):** भौतिक मेमोरी में कॉस्मिक किरणों से पलटने वाले बिट्स का पता लगाने के लिए हैमिंग दूरी की गणना।
२. **सिमहाश (SimHash Deduplication):** वेब पेजों के ६४-बिट फिंगरप्रिंट्स की तुलना करके डुप्लिकेट सामग्री की पहचान।

## सीमा स्थितियां और प्रोडक्शन सुरक्षा

१. **समान पूर्णांक ($A == B$):** $A \oplus B = 0$, ० लौटाता है।
२. **कॉम्प्लिमेंट पूर्णांक ($A == \sim B$):** ३२ लौटाता है।
