> **टीएल;डीआर**
> * **किताब का सवाल:** C में `my2DAlloc` नामक एक फ़ंक्शन लिखें जो दो-आयामी (2D) ऐरे आवंटित करता है। `malloc` के कॉल्स की संख्या को न्यूनतम करें और सुनिश्चित करें कि मेमोरी को `arr[i][j]` संकेतन द्वारा एक्सेस किया जा सके।
> * **मुख्य समाधान:** **एकल आवंटन सतत २डी मैट्रिक्स**: (१) सामान्य दृष्टिकोण में $R + 1$ अलग `malloc()` कॉल्स की आवश्यकता होती है (जो हीप को खंडित करता है); (२) पूरी संरचना को **१ एकल malloc कॉल** में आवंटित करें: `total = rows * sizeof(int*) + rows * cols * sizeof(int)`; (३) बफर के आरंभिक भाग को रो पॉइंटर्स के ऐरे `int** row_ptrs` के रूप में उपयोग करें; (४) प्रत्येक रो पॉइंटर `row_ptrs[i]` को उसके डेटा ऑफसेट की ओर इंगित करें: `(int*)(row_ptrs + rows) + i * cols`; (५) यह मानक `arr[i][j]` इंडेक्सिंग का समर्थन करता है; (६) एक ही `free(arr)` कॉल द्वारा पूरी मेमोरी मुक्त हो जाती है।
> * **रियल-वर्ल्ड सिस्टम:** उच्च-प्रदर्शन BLAS लीनियर अलजेब्रा लाइब्रेरी और GPU फ़्रेमबफ़र।

## १. किताब का सवाल और संदर्भ

*क्रैकिंग द कोडिंग इंटरव्यू* (समस्या १२.११) में पूछा गया है:

*"C में my2DAlloc फ़ंक्शन लागू करें जो malloc कॉल्स को न्यूनतम करते हुए arr[i][j] सिंटैक्स के साथ 2D मैट्रिक्स आवंटित करता है।"*

## २. मेमोरी में सतत लेआउट

रो पॉइंटर्स ऐरे और वास्तविक मैट्रिक्स डेटा को एक ही सतत ब्लॉक में जोड़ना:
$$\text{कुल आकार} = (\text{पंक्तियाँ} \times \text{sizeof(int*)}) + (\text{पंक्तियाँ} \times \text{कॉलम} \times \text{sizeof(int)})$$

## प्रोडक्शन कार्यान्वयन

```c
#include <stdio.h>
#include <stdlib.h>

/**
 * एकल मैलॉक कॉल में २डी मैट्रिक्स आवंटित करता है।
 * समय जटिलता: O(rows) इनिशियलाइज़ेशन
 * स्पेस जटिलता: O(rows * cols)
 */
int** my2DAlloc(int rows, int cols) {
    if (rows <= 0 || cols <= 0) return NULL;

    size_t header_size = rows * sizeof(int*);
    size_t data_size = (size_t)rows * cols * sizeof(int);

    // एकल malloc कॉल
    int** row_ptrs = (int**)malloc(header_size + data_size);
    if (!row_ptrs) return NULL;

    int* data_start = (int*)(row_ptrs + rows);

    // प्रत्येक पंक्ति पॉइंटर को डेटा ऑफसेट पर सेट करें
    for (int i = 0; i < rows; i++) {
        row_ptrs[i] = data_start + (i * cols);
    }

    return row_ptrs;
}

/**
 * एकल कॉल में पूरी मैट्रिक्स को मुक्त करता है।
 */
void my2DFree(int** arr) {
    free(arr);
}
```

## संरचनात्मक तुलना

| मापदंड | सामान्य बहु-मैलॉक ($R + 1$ कॉल्स) | इष्टतम एकल मैलॉक (१ कॉल) |
|---|---|---|
| **हीप आवंटन** | $R + 1$ अलग ब्लॉक | **ठीक १ आवंटन** |
| **कैश लोकैलिटी** | हीप पर बिखरे हुए टुकड़े | **L1/L2 प्रीफेचिंग के साथ सतत ब्लॉक** |
| **विमुक्ति (Deallocation)** | $R$ कॉल्स का लूप | **एकल `free(arr)` कॉल** |

## वास्तविक दुनिया में सिस्टम इंजीनियरिंग उपयोग

### प्रोडक्शन सिस्टम आर्किटेक्चर: GPU डायरेक्ट मेमोरी एक्सेस (DMA)

१. **हाई-स्पीड DMA ट्रांसफर:** सतत मेमोरी ब्लॉक होने के कारण `cudaMemcpy2D` द्वारा मैट्रिक्स को बिना किसी अतिरिक्त बफर के सीधे GPU VRAM में भेजा जाता है।
२. **BLAS मैट्रिक्स गुणा:** रो-मेजर क्रम में सतत मेमोरी सीपीयू कैश मिस को समाप्त करती है।
