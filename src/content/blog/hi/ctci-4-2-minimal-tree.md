> **टीएल;डीआर**
> * **किताब का सवाल:** अद्वितीय पूर्णांक तत्वों के साथ एक क्रमबद्ध (बढ़ते क्रम) एरे दिए जाने पर, न्यूनतम ऊंचाई वाला बाइनरी सर्च ट्री (BST) बनाने के लिए एक एल्गोरिदम लिखें।
> * **मुख्य समाधान:** **विभाजित करें और जीतें (Divide and Conquer)**: एरे का मध्य तत्व रूट नोड बन जाता है। बाएं सब-एरे से बाएं सबट्री और दाएं सब-एरे से दाएं सबट्री का रिकर्सिव निर्माण $O(N)$ समय और $O(\log N)$ स्टैक स्पेस में करें।
> * **रियल-वर्ल्ड सिस्टम:** डेटाबेस स्टोरेज इंजन में बल्क-लोडिंग बी-ट्री इंडेक्स और कंप्यूटर ग्राफिक्स में केडी-ट्री।

## १. किताब का सवाल और संदर्भ

*क्रैकिंग द कोडिंग इंटरव्यू* (समस्या ४.२) में पूछा गया है:

*"अद्वितीय पूर्णांक तत्वों के साथ एक क्रमबद्ध (बढ़ते क्रम) एरे दिए जाने पर, न्यूनतम ऊंचाई वाला बाइनरी सर्च ट्री बनाने के लिए एक एल्गोरिदम लिखें।"*

**गणितीय अवधारणा:**
पेड़ की ऊंचाई को न्यूनतम करने के लिए, बाएं सबट्री में नोड्स की संख्या दाएं सबट्री के नोड्स के जितना संभव हो सके करीब होनी चाहिए। इसलिए, प्रत्येक सबट्री का रूट हमेशा उसके संबंधित एरे खंड का **मध्य तत्व** होना चाहिए।

## २. विभाजित करें और जीतें रिकर्सिव कार्यप्रणाली

एरे `arr[start ... end]` के लिए:
१. आधार स्थिति: यदि `end < start`, तो `null` लौटाएं।
२. मध्य बिंदु खोजें: `mid = (start + end) / 2`।
३. रूट नोड बनाएं: `TreeNode n = new TreeNode(arr[mid])`।
४. बायां सबट्री बनाएं: `n.left = createMinimalBST(arr, start, mid - 1)`।
५. दायां सबट्री बनाएं: `n.right = createMinimalBST(arr, mid + 1, end)`।
६. `n` लौटाएं।

## प्रोडक्शन कार्यान्वयन

```java
public class MinimalTree {
    public static class TreeNode {
        public int val;
        public TreeNode left;
        public TreeNode right;

        public TreeNode(int x) {
            this.val = x;
        }
    }

    /**
     * क्रमबद्ध एरे से न्यूनतम ऊंचाई वाला BST बनाता है।
     * समय जटिलता: O(N)
     * स्पेस जटिलता: O(log N) स्टैक स्पेस
     */
    public static TreeNode createMinimalBST(int[] array) {
        if (array == null || array.length == 0) return null;
        return createMinimalBST(array, 0, array.length - 1);
    }

    private static TreeNode createMinimalBST(int[] arr, int start, int end) {
        if (end < start) {
            return null;
        }

        int mid = (start + end) / 2;
        TreeNode n = new TreeNode(arr[mid]);
        n.left = createMinimalBST(arr, start, mid - 1);
        n.right = createMinimalBST(arr, mid + 1, end);
        return n;
    }
}
```

## जटिलता और मेमोरी विश्लेषण

| मापदंड | जटिलता | तकनीकी विवरण |
|---|---|---|
| समय जटिलता | `O(N)` | एरे का प्रत्येक तत्व ठीक एक बार नोड में परिवर्तित होता है। |
| सहायक मेमोरी | `O(\log N)` | संतुलित पेड़ की ऊंचाई के बराबर रिकर्सिव स्टैक गहराई ($\lceil \log_2 N \rceil$)। |

## वास्तविक दुनिया में सिस्टम इंजीनियरिंग उपयोग

### प्रोडक्शन सिस्टम आर्किटेक्चर: डेटाबेस इंडेक्स बल्क लोडिंग

१. **डेटाबेस बी-ट्री बल्क लोडिंग (PostgreSQL):** क्रमबद्ध डेटासेट पर इंडेक्स बनाते समय मीडियन विभाजन बिना रोटेशन के संतुलित इंडेक्स पेज बनाता है।
२. **रे ट्रेसिंग में केडी-ट्री:** ज्यामितीय स्थानिक विभाजन $O(\log N)$ क्वेरी समय सुनिश्चित करता है।

## सीमा स्थितियां और प्रोडक्शन सुरक्षा

१. **खाली या नल एरे:** $O(१)$ में `null` लौटाता है।
२. **एकल तत्व एरे:** एकल लीफ नोड लौटाता है।
३. **सम संख्या में तत्व:** पूर्णांक विभाजन निचला मीडियन चुनता है और संतुलन बनाए रखता है।
