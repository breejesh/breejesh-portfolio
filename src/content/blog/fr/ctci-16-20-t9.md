> **TL;DR**
> * **Le Problème du Livre:** Sur les claviers téléphoniques traditionnels, les chiffres correspondent à des lettres ($2 \to \text{abc}, 3 \to \text{def}, \dots$). Étant donné une séquence de chiffres (ex. `"8733"`) et un dictionnaire, retournez tous les mots valides correspondants (ex. `["tree", "used"]`).
> * **Les Solutions Optimales :**
>   1. **HashMap Précalculée (Idéale en Production)** :
>      * Prétraiter le dictionnaire en convertissant chaque mot en empreinte numérique T9.
>      * Stocker dans une structure `Map<String, List<String>>`.
>      * Répondre aux requêtes en **temps strict $O(L)$** ($L = \text{longueur de la séquence}$).
>   2. **Arbre Trie avec Élagage** :
>      * Indexer le dictionnaire dans un Trie 26-aire et ne visiter que les branches compatibles avec chaque chiffre.
> * **Réalité en Production:** Moteur de numérotation rapide Android (AOSP Dialer) et serveurs vocaux interactifs (SVI / IVR).

## 1. Formulation du Problème du Livre

Dans *Cracking the Coding Interview* (Problème 16.20), l'énoncé est :

*"Identifiez l'ensemble des mots d'un dictionnaire correspondant a une sequence de touches numeriques saisies sur un clavier T9."*

## 2. Empreinte Numérique Directe

L'indexation préalable par signature numérique réduit la recherche à une simple consultation de table de hachage sans explorer de combinaisons de lettres exponentielles.

## Implémentation de Production

```java
import java.util.*;

public class T9Lookup {

    private static final int[] CHAR_TO_DIGIT = {
        2, 2, 2,  // a, b, c
        3, 3, 3,  // d, e, f
        4, 4, 4,  // g, h, i
        5, 5, 5,  // j, k, l
        6, 6, 6,  // m, n, o
        7, 7, 7, 7, // p, q, r, s
        8, 8, 8,  // t, u, v
        9, 9, 9, 9  // w, x, y, z
    };

    public static String wordToDigits(String word) {
        StringBuilder sb = new StringBuilder();
        for (char c : word.toLowerCase().toCharArray()) {
            if (c >= 'a' && c <= 'z') {
                sb.append(CHAR_TO_DIGIT[c - 'a']);
            }
        }
        return sb.toString();
    }

    public static Map<String, List<String>> initializeT9Map(String[] dictionary) {
        Map<String, List<String>> map = new HashMap<>();
        for (String word : dictionary) {
            String digits = wordToDigits(word);
            map.computeIfAbsent(digits, k -> new ArrayList<>()).add(word);
        }
        return map;
    }

    public static List<String> getValidWords(String digits, Map<String, List<String>> t9Map) {
        return t9Map.getOrDefault(digits, Collections.emptyList());
    }
}
```

## Analyse de Complexité

| Phase | Algorithme | Complexité Temporelle | Espace Mémoire |
|---|---|---|---|
| **Prétraitement** | Indexation Dictionnaire | $O(W \cdot K)$ | $O(W \cdot K)$ table de hachage |
| **Requête Runtime** | Consultation HashMap | **$O(L)$** | **$O(1)$** |

## Ingénierie des Systèmes en Production

### Architecture Système : Numéroteur Android et Serveurs SVI

1. **Recherche T9 dans Android :** Le numéroteur téléphonique AOSP indexe les contacts dans SQLite avec leur projection numérique T9 pour filtrer instantanément le carnet d'adresses.
2. **Serveurs Vocaux Interactifs (IVR) :** Décodage des entrées de touches téléphoniques (DTMF).

## Cas Limites et Robustesse

1. **Séquence Sans Correspondance :** Renvoie `Collections.emptyList()` sans exception.
